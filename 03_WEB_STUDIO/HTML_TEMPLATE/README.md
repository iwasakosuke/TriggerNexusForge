# HTML_TEMPLATE — HTML基本テンプレート

<!-- すべてのWeb制作の出発点になるHTMLボイラープレート。meta/OGP/構造化の抜け漏れを防ぐ -->

新規ページ制作の出発点になるHTMLテンプレートです。
SEO・OGP・アクセシビリティの必須項目を最初から備えています。

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | ボイラープレート本体(`{{変数}}` を書き換えて使う) |

## 使い方

1. `index.html` を案件フォルダにコピーする
2. `{{ }}` のプレースホルダをすべて置換する(検索して残っていないか確認)
3. `CSS_TEMPLATE` の3ファイルを `css/` に配置して読み込む
4. 納品前チェック(下記)を実施する

## 納品前チェックリスト

- [ ] `{{ }}` プレースホルダの置換漏れがない
- [ ] title / description がページごとに固有になっている
- [ ] OGP画像(1200×630px)を設定した
- [ ] 全imgにalt属性がある
- [ ] スマホ実機(または開発者ツール)で表示確認した
- [ ] Lighthouseでパフォーマンス・アクセシビリティを確認した
