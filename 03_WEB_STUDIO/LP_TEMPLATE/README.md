# LP_TEMPLATE — ランディングページテンプレート

<!-- 受注案件・自社サービスのLPを高速に立ち上げるためのテンプレート。構成は王道のセールスフロー -->

1ページ完結型LPのテンプレートです。
「FV → 課題共感 → 解決策 → ベネフィット → 実績 → 料金 → FAQ → CTA」の王道構成を実装済みで、コピーを差し替えるだけで形になります。

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | LP本体(セクション構造+プレースホルダ) |
| `css/style.css` | LP固有スタイル(`CSS_TEMPLATE` の上に載せる) |

※ `css/tokens.css` `css/reset.css` `css/components.css` は `../CSS_TEMPLATE/` からコピーして配置する

## 制作フロー(推奨)

1. **コピー設計**: `02_CONTENT_FACTORY/02_PROMPTS/LP.md` の Prompt 1〜2 でLP構成とコピーを生成する
2. **流し込み**: このテンプレートの `{{ }}` に確定コピーを流し込む
3. **業種調整**: `INDUSTRY_TEMPLATES/` の該当業種メモで訴求・写真トーンを調整する
4. **デザイン調整**: クライアントのブランドカラーがあれば `tokens.css` の変数を差し替える
5. **チェック**: `HTML_TEMPLATE/README.md` の納品前チェックリストを実施する

## セクション構成と役割

| # | セクション | 目的 |
|---|-----------|------|
| 1 | FV(ファーストビュー) | 3秒で「自分に関係ある」と思わせる |
| 2 | 課題共感 | 「そうそう、それで困ってる」を言語化 |
| 3 | 解決策(サービス紹介) | 課題への答えを提示 |
| 4 | ベネフィット | 導入後の変化を3つで見せる |
| 5 | 実績・お客様の声 | 信頼の証拠(事実のみ掲載) |
| 6 | 料金 | 松竹梅3プラン+おすすめ明示 |
| 7 | FAQ | 購入阻害要因の先回り解消 |
| 8 | 最終CTA | 行動ハードルを下げた一押し |

## ルール

- CTAボタンは必ず3箇所(FV・中盤・最下部)。文言は行動ハードルの低いものに(「申し込む」より「まずは無料で相談する」)
- お客様の声・実績数字は事実のみ。ダミーのまま公開しない
- 「絶対」「100%」「業界No.1」等の表現禁止(→ `Brand.md`)
