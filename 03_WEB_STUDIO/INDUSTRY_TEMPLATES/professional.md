# 士業テンプレート(税理士・行政書士・社労士など)

<!-- 士業の相談獲得LP・事務所サイトの設計テンプレート。「信頼」と「相談ハードルの低さ」の両立が核 -->

## ターゲット心理

- 依頼者は**困りごとが具体的**(相続が発生した、会社を設立したい、税務調査が来る)
- 最大の不安:「費用がいくらかかるか分からない」「怒られそう/説教されそう」「何を相談していいか分からない」
- 「専門性」と同じくらい「話しやすさ」で選ばれる

## 訴求軸(優先順)

1. **業務の絞り込み** — 「何でもやります」より「相続専門」。1LP=1業務
2. **料金の透明性** — 料金表の明示が最大の差別化になる業界
3. **先生の顔と人柄** — 顔写真+経歴+「なぜこの仕事をしているか」
4. **相談ハードルの低さ** — 初回無料・オンライン対応・「まだ依頼を決めてなくてOK」

## 構成の型(基本形からの差分)

```
FV(困りごと呼びかけ+対応の約束+初回相談CTA)
→ 課題共感(「こんな状況ではありませんか」を具体的に)★シーン描写が効く
→ 放置するとどうなるか(期限・罰則・損失を事実ベースで)※煽らず正確に
→ 解決の流れ(相談→見積→着手→完了の4ステップ図)★重要
→ 選ばれる理由(専門特化・実績件数・対応スピード)
→ 先生紹介(顔写真・経歴・人柄が伝わる一言)
→ 料金表(基本料金+よくあるケースの総額目安)
→ お客様の声(同じ困りごとだった人の声)
→ FAQ(費用・期間・必要書類・オンライン可否)
→ 最終CTA(電話+フォーム+可能ならLINE)
```

## コピー例

| 用途 | 例 |
|------|-----|
| FVキャッチ | 「相続の手続き、何から始めればいいか分からない方へ。」(困りごと直球) |
| 安心訴求 | 「『こんなこと聞いていいのかな』という段階のご相談が、いちばん多いです。」 |
| 流れの見出し | 「ご相談から完了まで、最短2週間です」(数字で示す) |
| CTA | 「初回相談は無料です(オンライン対応可)|相談日を予約する」 |

## デザイントーン

- 配色:信頼感のある寒色ベース(ネイビー・深緑)+温かみのアクセント1色。`--color-secondary` を主役にし、`--color-primary` は控えめに使う
- 写真:先生本人の写真が最重要。プロ撮影を推奨(スーツ+柔らかい表情)。素材写真の多用は信頼を下げる
- 全体:装飾は最小限。文字を大きく、行間を広く(依頼者の年齢層が高いケースが多い)

## CTA設計

- 電話とフォームを並列(年配層は電話、現役世代はフォーム)
- 営業時間と「土日対応の有無」をCTA近くに明記
- フォームの入力項目は最小限に(名前・連絡先・相談内容の3つで十分)

## よくある要注意ポイント

- 士業ごとの広告規制・業際(扱える業務の範囲)を必ず確認する(例:行政書士は紛争性のある案件不可)
- 「必ず節税できます」等の成果保証はNG
- 料金表は「〜円から」で終わらせず、よくあるケースの総額目安まで書く(不安解消のため)
