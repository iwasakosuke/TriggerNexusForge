# オンライン講座・スクールテンプレート

<!-- オンライン講座・スクール・教材の販売LP設計テンプレート。「再現性の証明」と「誠実な期待値設定」が核 -->

## ターゲット心理

- 「学びたい」の裏にある本当の目的は**変化**(収入を増やしたい・転職したい・自分で作れるようになりたい)
- 最大の不安:「自分にもできるか(再現性)」「怪しくないか」「途中で挫折しないか」「値段に見合うか」
- 情報商材への警戒心が強い層。**誇大表現は逆効果**であり、誠実さが最大の差別化になる

## 訴求軸(優先順)

1. **講師の実践の証拠** — 「教える人が実際にやっている」こと。制作物・実績・過程の公開
2. **カリキュラムの具体性** — 「何ができるようになるか」を章ごとに明示
3. **受講生の変化** — ゼロからの人がどうなったか(スタート地点を明記した事例)
4. **挫折対策** — 質問サポート・添削・コミュニティなど「一人にしない」仕組み

## 構成の型(基本形からの差分)

```
FV(誰が・何ができるようになる講座か+実績+CTA)
→ 課題共感(独学の挫折・情報の多さへの迷い)
→ なぜ独学では難しいのか(構造の説明。煽らず論理で)
→ 講座の全体像(何を・どの順で・どこまで学ぶか)★カリキュラム表が核
→ この講座で作れるもの/できるようになること(成果物ベースで見せる)★核
→ 講師紹介(実践の証拠:実績・制作物・発信)
→ 受講生の声(開始時のレベルを明記した事例)
→ サポート内容(質問・添削・コミュニティ・期間)
→ 料金(分割・返金条件も明記)
→ FAQ(必要な前提知識・時間・PCスペック・返金)
→ 最終CTA
```

## コピー例

| 用途 | 例 |
|------|-----|
| FVキャッチ | 「3ヶ月後、自分の手でLPを1本つくれるようになる講座です。」(できるようになることを直球で) |
| 誠実な期待値設定 | 「楽して稼げる系の講座ではありません。週5時間の学習時間は必要です。」 |
| 再現性の担保 | 「受講生の8割は、プログラミング未経験からのスタートです。」(事実の場合のみ) |
| CTA | 「カリキュラムの詳細を見る」「無料説明会に参加する」 |

## デザイントーン

- 配色:知的で信頼感のあるベース(ネイビー・白)+行動を促すアクセント。`tokens.css` デフォルト(ネイビー×オレンジ)がそのまま使いやすい業種
- 写真・図版:講座画面のスクリーンショット、カリキュラム図、成果物の実例。「中身が見える」ほど成約率が上がる
- 情報量:多めでOK(高額・比較検討型の商材は長いLPが機能する)。ただし見出しだけで流れが分かる構成に

## CTA設計

- 高額講座は**2段階CTA**(いきなり購入ではなく「無料説明会」「無料体験」を挟む)
- 低額教材は直接購入+返金条件の明記
- 締切・限定を使う場合は事実のみ(偽のカウントダウンは信頼を破壊する)

## よくある要注意ポイント

- 収入・成果の保証表現は絶対にNG(「月10万稼げる」等)。実例も「個人の結果」の域を守る
- 特定商取引法に基づく表記ページを必ず用意する(販売LPでは法的必須)
- 受講生の声は実在+許可済みのみ。スクリーンショットの偽造は論外
- `Brand.md` のNGワード(「誰でも簡単に」)がもっとも出やすい業種なので、コピー生成後に必ずチェック
