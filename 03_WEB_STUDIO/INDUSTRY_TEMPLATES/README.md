# INDUSTRY_TEMPLATES — 業種別テンプレート

<!-- 業種ごとの「勝ちパターン」をまとめた設計テンプレート。LP_TEMPLATEと組み合わせて使う -->

業種ごとのWeb制作(主にLP・店舗サイト)の設計テンプレートです。
ターゲット心理・訴求軸・構成の型・コピー例・デザイントーンを業種別にまとめています。

## テンプレート一覧

| ファイル | 業種 | 主な制作物 |
|---------|------|-----------|
| [restaurant.md](restaurant.md) | 飲食店 | 店舗サイト・予約LP |
| [beauty_salon.md](beauty_salon.md) | 美容室・サロン | 予約LP・店舗サイト |
| [professional.md](professional.md) | 士業(税理士・行政書士など) | 相談獲得LP・事務所サイト |
| [fitness.md](fitness.md) | パーソナルジム・フィットネス | 体験申込LP |
| [online_school.md](online_school.md) | オンライン講座・スクール | 講座販売LP・無料登録LP |

## 使い方

1. 案件の業種に近いテンプレートを開く
2. 「訴求軸」「構成の差分」を参考に、`02_CONTENT_FACTORY/02_PROMPTS/LP.md` のプロンプトに素材として渡す
3. `LP_TEMPLATE/` をベースに実装し、「デザイントーン」の項目で `tokens.css` を調整する
4. 案件完了後、学んだ勝ちパターンをテンプレートに追記して育てる

## 共通の型(全業種のベース)

```
FV(誰向け・何が得られる・CTA)
→ 課題共感 → 解決策 → ベネフィット → 実績・声 → 料金 → FAQ → 最終CTA
```

各業種ファイルには、この基本形からの**差分**(順序変更・追加セクション・重視ポイント)を書いています。
