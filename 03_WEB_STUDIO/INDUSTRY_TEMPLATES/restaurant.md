# 飲食店テンプレート

## ターゲット心理

- 来訪者の大半は「今日/近日中に行く店を探している」状態。**検討時間は数十秒**
- 知りたい順:①どんな料理か(写真)②価格帯 ③場所・営業時間 ④予約できるか
- 不安要素:「入りにくくないか」「子連れ/大人数OKか」「駐車場はあるか」

## 訴求軸(優先順)

1. **料理の写真** — 文章より1枚のシズル写真。FVは看板メニューの寄り写真一択
2. **価格帯の明示** — 「予算:昼1,000円/夜4,000円〜」を早い位置に
3. **場所とアクセス** — 駅からの徒歩分数、駐車場の有無
4. こだわり(産地・製法)は上記3つの後。語りすぎない

## 構成の型(基本形からの差分)

```
FV(看板メニュー写真+店名+一言コンセプト+予約CTA)
→ メニュー(写真+価格。カテゴリ3つまで)
→ こだわり(1〜2つに絞る)
→ 店内・雰囲気(写真で「入りにくさ」を消す)
→ 店舗情報(地図・営業時間・定休日・支払い方法)★飲食は必須&重要
→ 予約CTA(電話とWeb予約の両方)
```

- 「課題共感」セクションは不要(悩み訴求は飲食に合わない)
- FAQの代わりに「店舗情報」を充実させる(営業時間・席数・個室・喫煙・駐車場・子連れ可否)

## コピー例

| 用途 | 例 |
|------|-----|
| FVキャッチ | 「炭火で90秒。頼むべきは、まずこの一串。」(商品名+こだわりを一言で) |
| 予約CTA | 「席だけ予約もOK|今夜の空席を見る」 |
| こだわり見出し | 「毎朝、市場でその日の魚を決めています」(実践ベース・体言止めしない) |

## デザイントーン

- 配色:料理写真が主役。UIは無彩色寄り+アクセント1色(暖色系推奨)。`tokens.css` の `--color-primary` を店の業態に合わせる(和食=深緋、カフェ=テラコッタ等)
- 写真:暗め背景+料理にライティングの「シズル感」。素材写真の使用は最小限に
- フォント:業態に合わせて可変(和食=明朝系も検討。その場合 `--font-heading` を差し替え)

## CTA設計

- 電話予約とWeb予約(ぐるなび/食べログ/自社フォーム)を**並列で置く**(年齢層で好みが分かれる)
- スマホでは電話番号タップ発信(`tel:`リンク)必須
- 営業時間外の流入に備え「Web予約は24時間受付」を明記

## よくある要注意ポイント

- メニュー価格の税込/税別表記を統一する
- 食べログ等の外部評価を勝手に転載しない(規約確認)
- 「日本一」「究極」等の根拠なき最上級表現は使わない(`Brand.md` と同基準)
