## ターゲット心理

- 動機は明確(痩せたい・体力をつけたい・健康診断で指摘された)だが、**過去に挫折経験がある**人が大半
- 最大の不安:「続けられるか」「きつすぎないか」「高い買い物にならないか」「体型を見られるのが恥ずかしい」
- 比較検討が長い(複数ジムのLPを見比べている前提で作る)

## 訴求軸(優先順)

1. **ビフォーアフター(数字つき)** — 「3ヶ月で-8kg」など事実の変化。体重だけでなく体脂肪率・ウエストも
2. **挫折させない仕組み** — 食事サポート・オーダーメイドメニュー・トレーナーの伴走
3. **トレーナーの人柄** — 「怖くない」「バカにしない」が伝わる写真と言葉
4. **料金の正当化** — 総額を隠さず、1日あたり換算や他の出費との比較で示す

## 構成の型(基本形からの差分)

```
FV(ターゲット+変化の約束+体験オファー+CTA)
→ 課題共感(挫折経験の言語化:「ジムに入会したけど3ヶ月で行かなくなった」)★核
→ 挫折の原因分析(意志の問題ではなく仕組みの問題、と再定義する)
→ 解決策(このジムの仕組み:パーソナル指導・食事管理・進捗管理)
→ ビフォーアフター事例(年代・性別別に3例以上、数字つき)★核
→ トレーナー紹介(資格・実績+人柄の伝わる一言)
→ 体験の流れ(カウンセリング→体験トレーニング→説明。「その場で契約を迫りません」)
→ 料金(総額明示+1日あたり換算+返金保証があれば明記)
→ FAQ(きつさ・服装・手ぶらOK・女性トレーナー指名可否)
→ 最終CTA(体験申込)
```

## コピー例

| 用途 | 例 |
|------|-----|
| FVキャッチ | 「『続かなかった』を、最後にする。」(挫折経験への共感) |
| 再定義 | 「痩せられなかったのは、意志が弱いからではありません。仕組みがなかったからです。」 |
| 体験CTA | 「まずは60分の体験から(当日入会の必要はありません)」 |
| 料金の正当化 | 「1回あたり8,000円。飲み会1回分で、専属トレーナーがつきます。」 |

## デザイントーン

- 配色:エネルギーと清潔感。ダーク背景+ビタミンカラーのアクセント(オレンジ・イエロー)は `tokens.css` デフォルトと相性が良い。女性向けはベースを明るく
- 写真:実際のジム内観+トレーニング風景。トレーナーは笑顔の写真を必ず入れる(威圧感の中和)
- 数字の見せ方:Before/Afterの数字は大きくタイポグラフィで見せる(`--font-heading` + `--color-primary`)

## CTA設計

- CTAは「入会」ではなく必ず**「体験申込」**に(コミットメントを最小化)
- 「無理な勧誘をしない」宣言をCTA直下に置く
- 残枠表示(今月の体験枠:残り○名)は事実の場合のみ使用

## よくある要注意ポイント

- ビフォーアフターは本人許可+「結果には個人差があります」の注記が必須(景表法対策)
- 「必ず痩せる」「リバウンドしない」等の断定は法的リスク。数字は実例の事実のみ
- 総額(入会金+月額×期間)を分かりにくくしない。誠実な料金表示は長期的な信頼になる
