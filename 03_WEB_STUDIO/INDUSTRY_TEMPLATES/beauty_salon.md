# 美容室・サロンテンプレート

<!-- 美容室・エステ・ネイル等の予約LP設計テンプレート。「失敗したくない」不安の解消が核 -->

## ターゲット心理

- 最大の感情は**「失敗したくない」**(仕上がり・お店の雰囲気・スタッフとの相性)
- 「自分に似合うか」「自分のようなタイプ(髪質・年代)の実例があるか」を探している
- 初回来店のハードル:料金の不透明さ、勧誘への警戒、入りづらさ

## 訴求軸(優先順)

1. **ビフォーアフター/スタイル写真** — 「自分と同じ悩みの人がこう変わった」が最強の証拠
2. **スタッフの顔と人柄** — 誰にやってもらうかが分かる安心感
3. **明朗会計** — 初回料金・追加料金の有無を隠さない
4. **勧誘しない宣言** — エステ・脱毛系では特に効く

## 構成の型(基本形からの差分)

```
FV(ターゲット明示+変化の約束+初回オファー+予約CTA)
→ 課題共感(髪質・年代・過去の失敗体験の言語化)★重要
→ 選ばれる理由(技術・カウンセリング・雰囲気から3つ)
→ ビフォーアフター事例(悩みタイプ別に3〜6例)★このセクションが核
→ スタッフ紹介(顔写真+得意分野+一言)
→ 料金(初回/通常を明確に。追加料金の有無も明記)
→ 店舗情報・FAQ(勧誘への不安・施術時間・支払い方法)
→ 予約CTA
```

## コピー例

| 用途 | 例 |
|------|-----|
| FVキャッチ | 「『扱いにくいくせ毛』が、朝5分でまとまる髪に。」(悩み→変化) |
| ターゲット呼びかけ | 「カラーを繰り返して、髪のダメージが気になり始めた30代の方へ」 |
| 不安解消 | 「カウンセリングだけのご来店も歓迎です。当日の施術の強要はしません。」 |
| 予約CTA | 「空き状況を見てみる(24時間ネット予約)」 |

## デザイントーン

- 配色:清潔感と柔らかさ。ベースは白〜ベージュ、アクセントは彩度低めの1色(ローズ、モーブ、セージ等)。`--color-primary` を差し替え、`--shadow-card` は柔らかく
- 写真:自然光・明るめ。モデルは実際の顧客層と同年代を使う(若すぎるモデルは逆効果)
- 余白:多めに。詰め込むほど安っぽくなる業種

## CTA設計

- ホットペッパー等の予約導線と自社予約を併記(掲載中の場合)
- 「初回限定オファー」はFVと料金セクションの2箇所に
- LINE登録を中間CTAにするのも有効(即予約への心理ハードルが高い業種のため)

## よくある要注意ポイント

- ビフォーアフター写真は本人の掲載許可を必ず取る
- エステ・脱毛は効果の断定表現が広告規制に触れやすい(「必ず痩せる」等はNG)。体験談も「個人の感想」の域を守る
- メニュー名は業界用語を避けて悩みベースに(「髪質改善」より「くせ毛・広がりに」)
