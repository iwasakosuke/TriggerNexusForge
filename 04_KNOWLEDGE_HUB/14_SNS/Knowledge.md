# SNS Knowledge(要点版)

## 1枚で思い出す要点

1. **アルゴリズム攻略ではなく滞在への貢献**(読まれる・保存される・会話が生まれる)
2. **追う指標は媒体ごとに1つ** — X=ブックマーク率 / IG=保存率 / Threads=リプ率 / YT=維持率
3. **発信の軸を守る** — AI活用×一人会社×制作ノウハウ。軸の外は発信しない
4. **1週1仮説** — 同時に複数変えると学びが消える
5. **投稿ボタンは人間が押す** — ドラフトまでがAIの仕事
6. **数字の観測は2週間** — 単日で方針を変えない。噂で動かない

## コンテンツ3層のバランス

実践レポート(信頼): ノウハウ(保存): 等身大(共感)をバランス配分。
月次で偏りを診断する(→ customer_journey.md の配置診断)。
