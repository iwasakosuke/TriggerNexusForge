# SALES Knowledge(要点版)

## 1枚で思い出す要点

1. **課題起点** — 「LPが欲しい」の裏の「問い合わせが足りない」を掴む(御用聞きにならない)
2. **価値ベース価格** — かかる時間ではなく、生む価値で値付けする
3. **松竹梅+おすすめ明示** — 「買うか」ではなく「どれを買うか」の構造にする
4. **期待値調整は受注前** — できないこと・追加費用の条件は契約前に文書で
5. **値引きにはスコープ調整** — 価格だけ下げない
6. **継続を設計** — 納品後の関係(運用・改善)まで提案に含める

## 営業プロセス(状態定義)

リード → ヒアリング → 提案 → 交渉 → 受注(→PM_AIへ)/ 失注(→振り返り→資産化)

## 断りの3パターン(関係を壊さない)

- 予算不一致 → スコープ再設計の代案を出す
- スコープ外 → 正直に「専門外」+可能なら紹介
- ビジョン不適合 → 感謝+理由を誠実に(嘘の理由を作らない)
