# DAY20 — 商談準備キット

Week3:Proposal Builder / 営業資料|所要目安:2時間

## 今日のSprint名
Sprint 3-6「商談を怖くなくする準備キット」

## 今日の目的
初商談を想定した準備一式(ヒアリングシート・想定問答・デモ手順)を完成させる。

## 完成条件
- 商談キットが完成:ヒアリングシート(BANT+課題の言語化)/想定問答10問/
  デモ手順(Core Engineをその場で動かす台本)
- 30分商談の進行表(挨拶→ヒアリング→デモ→次のステップ)がある

## Claude Codeに貼る指示
```text
00_COMPANY/CLAUDE.md 確認後、Sales_AIとして:
1. 05_AUTOMATION/01_CLIENT_INTAKE/intake_sheet.md をベースに
   商談用ヒアリングシートを作成
2. 想定問答10問を作成(価格・納期・実績が少ない・AIで作って大丈夫?・
   他社との違い・修正・支払い・キャンセル・保守・効果保証を求められたら)
   ※「効果保証」への回答は誠実に「保証しない+できることを示す」型で
3. Core Engineのデモ台本(3分:業種を聞く→その場で生成→提案につなぐ)
4. 保存先:07_CLIENTS/_sales_kit/meeting_kit.md
```

## テスト方法
セルフ商談:想定問答をAIに「意地悪なクライアント役」として質問させ、口頭で答えるロールプレイを1周。

## レビュー方法
答えに詰まった質問をメモし、回答を書き直してキットに反映。

## GitHub保存方法
meeting_kit.md をコミット→push→CHANGELOG追記。

