# DAY26 — 見込み客リストとアプローチ

Week4:Automation / GitHub運用 / 初案件化|所要目安:2〜3時間

## 今日のSprint名
Sprint 4-5「最初の10人に声をかける準備」

## 今日の目的
初案件の可能性がある相手をリスト化し、アプローチ文を用意して、実際に声をかけ始める(送信は自分の手で)。

## 完成条件
- 見込み客リスト10件(知人・SNSのつながり・地元の事業者など。個人情報の扱いは最小限に)
- 相手タイプ別アプローチ文3種(知人向け/SNSのつながり向け/紹介依頼)
- 最低1件、実際に送信した ★送信は人間

## Claude Codeに貼る指示
```text
00_COMPANY/CLAUDE.md 確認後、Sales_AIとして:
1. 見込み客リストのテンプレートを作成(列:相手/関係/業種/困っていそうなこと/
   アプローチ文タイプ/状態)。保存先:07_CLIENTS/_sales_kit/prospect_list.md
   ※氏名等の個人情報はイニシャル・通称で記録する運用ルールを冒頭に明記
2. アプローチ文3種を作成。ルール:
   - 売り込みではなく「近況+こんなことを始めた+役に立てそうなら」の距離感
   - 初回体験オファー(モニター価格等)の設計もセットで提案
   - 保存先:sales_messages.md に追記
```

## テスト方法
アプローチ文を自分に送ったつもりで読む:「友人からこれが来たら嫌か?」で判定。

## レビュー方法
CEO_AIにモニター価格の壁打ち(安売りとの境界線:モニターは「実績と声をもらう取引」と定義できているか)。

## GitHub保存方法
リスト+文面をコミット→push→CHANGELOG追記(実名・連絡先はコミットしない)。

## 推奨コミットメッセージ
```
Day26: 見込み客リストとアプローチ文を整備(初回送信済み)
```

## 実案件での使い方
ここからが本番。返信が来たら Day20 の商談キット→ Day16 の提案書へ。
