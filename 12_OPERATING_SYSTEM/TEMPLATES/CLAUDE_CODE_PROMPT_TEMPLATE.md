## 基本形(コピーして使う)

```text
# 前提
このリポジトリは Trigger Nexus Forge の会社OSです。
作業前に 00_COMPANY/CLAUDE.md を確認し、そのルールに従ってください。

# タスク
【やること】(1行で)

【完了条件】(何がどうなったら完了か。測れる形で)

【対象・参照】(触ってよいファイル/参照すべきファイルのパス)

【制約】
- 既存のテンプレート・正典は直接編集せず、コピーして使う(改善提案は別途)
- 事実(実績・数字)を捏造しない。不明箇所は【要記入】で残す
- 認証情報・機密をファイルに書かない

【完了時】
- 変更内容の要約と、確認方法(どう動かせば確認できるか)を報告してください
- コミットメッセージ案を提示してください(実行は私が確認後)
```

## コツ

- 完了条件が書けない依頼はまだ依頼できる状態ではない(タスクを分割する)
- 参考例があれば貼る(「こんな感じ」の言語化より例1つ)
- 大きな作業は「計画を先に見せて」と付ける(実行前に方向を確認できる)
