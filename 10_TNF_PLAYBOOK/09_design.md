## デザインの三層構造(判断はこの順)

```
00_COMPANY/Brand.md(憲法:TNFの値と世界観)
 → DESIGN_ENGINE(判断ロジック:10エンジン)
  → 各制作物(エンジンを参照するだけ。ルールをコピーしない)
```

## 日常の手順

| 場面 | 手順 |
|------|------|
| 新しい制作物の配色 | Color Engine の生成ロジック(業種定石×ペルソナ補正)→ コントラスト検証 |
| レイアウトに迷う | Layout Engine(視線パターン選択・余白リズム)へ |
| バナー・サムネ | Grid Engine の標準キャンバス+セーフエリア |
| 公開前 | Accessibility(09)チェックリスト → Export Rules(10)の品質ゲート |

## 守るべき一線(非交渉)

- アクセシビリティAA(コントラスト4.5:1・タップ44px)は美観と交換しない
- 1画面の主役は1つ/オレンジ(Primary)の大面積使用禁止
- ブランド逸脱は「事前提案+理由」なしにやらない

## クライアント案件

- 先方ブランドがある → theme スキーマで値だけ差し替え(エンジンのロジックは共通)
- 先方の要望が品質基準と衝突 → 代案+理由で提案し、最終判断は記録に残す
