# 10_TNF_PLAYBOOK — 会社運営の完全手順書

<!-- TNFのDNA(その1)。「誰が・どのAIが来ても、同じ品質で会社を運営できる」ための手順書 -->

> **AIが変わっても、人が忘れても、会社は同じように動く。**
> Playbook は Trigger Nexus Forge の全業務の「やり方」を1箇所に集約した運営手順書です。
> 読者は「明日からこの会社を運営する誰か(人間でもAIでも)」— その人が迷わないことだけを目的に書かれています。

## 設計原則

1. **AI非依存** — 特定のAI・ツールの名前に依存する手順は、必ず「役割」で書く(例:「Claude」ではなく「作業AI」)
2. **正典分離** — 詳細ルールの本体は各所の正典にあり、Playbookは「入口と要点」を持つ(重複させない)
3. **手順は再現可能に** — 「頑張る」「意識する」を禁止。誰がやっても同じ結果になる粒度で書く
4. **生きた文書** — 実態とズレた章は月次で直す。直せないなら実態が間違っているかを疑う

## 使い方

- **日常**: 迷った業務の章を開く → 要点と手順に従う → 詳細は正典リンクへ
- **新しい運営者(人・AI)のオンボーディング**: 01 → 02 → 該当業務の章、の順で読む
- **月次メンテナンス**: 実態とズレた記述を直す(CEO_AI の月次レビューの議題に含める)

## 上位文書

Playbook は「How(やり方)」の正典。「Why/What」は `00_COMPANY/`(Vision・Mission・Brand・Roadmap)が上位。
矛盾したら 00_COMPANY が勝つ。
