## ルール

- 状態変更・重要イベントは**1行で**記録する(重い記録は続かない。詳細は案件シートへ)
- 障害・ヒヤリとした事象は必ず記録する(なかったことにしない)
- 月次でログを見返し、詰まりやすい工程を特定する(→ 改善は README の自動化表へ反映)
