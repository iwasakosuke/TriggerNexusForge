## 工程

```
レビュー承認済み → 納品物の整理(PM_AI)→ 納品書・報告文ドラフト
→ ★人が納品実行(送付・公開・引き渡し)→ 先方検収 → 08_INVOICE へ
```

## 原則

- 納品は「ファイルを送る」ではなく「使える状態を渡す」(手順書・権限・素材まで)
- 納品と同時に請求フローを起動する(請求漏れは納品直後の処理で防ぐ)
