# Delivery Checklist — 納品チェック+納品書

## 納品前チェック

- [ ] 全成果物がレビュー承認済み(06_REVIEW 完走)か
- [ ] 完了定義(案件シート)を満たしているか
- [ ] 納品物リストと実物が一致しているか(数・形式・命名)
- [ ] クライアントが「使える状態」か(権限・パスワード・手順書・元データ)
- [ ] Web案件:本番公開の最終確認(06_WEB/Checklist)を通したか
- [ ] 検収方法と期限を伝える文面になっているか
- [ ] 納品後サポートの範囲(期間・内容)を明記したか

## 納品書テンプレート

```markdown
# 納品書:(案件名)

(クライアント名)様

下記のとおり納品いたします。ご確認(検収)をお願いいたします。

## 納品物
| # | 納品物 | 形式・場所 |
|---|--------|-----------|
| 1 | | |

## ご確認のお願い
- 検収期限:MM月DD日(納品から◯営業日)
- 期限までにご連絡がない場合、検収完了とさせていただきます

## 納品後サポート
- 期間:納品後◯日間
- 範囲:(軽微な修正・不具合対応 など)
- 範囲外のご依頼:別途お見積もり

## 引き渡し情報
- (管理画面URL・アカウント・手順書の場所)

(会社名・連絡先)
```
