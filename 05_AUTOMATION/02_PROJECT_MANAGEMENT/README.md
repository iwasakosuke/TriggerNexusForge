受注後の案件管理を担当します。担当:**PM_AI**。

| ファイル | 内容 |
|---------|------|
| [project_sheet.md](project_sheet.md) | 案件シート(1案件=1シート。状態管理の正) |

## 工程

```
Sales_AI から引き継ぎ(受付シート+確定条件)
→ 案件シート作成(キックオフ)→ WBS・スケジュール確定
→ 以降、状態変更のたびにシートを更新(このシートが常に「正」)
```

## ルール

- 案件シートは `07_CLIENTS/(クライアント名)/project.md` に置く(ここはテンプレの原本)
- 状態は `00_WORKFLOWS/master_flow.md` の10ステート定義に従う
- 同時進行案件が3件を超えたら、新規受注の前に PM_AI が負荷判定を出す
- 毎朝の日次ブリーフィング(PM_AI)はこのシート群から生成する
