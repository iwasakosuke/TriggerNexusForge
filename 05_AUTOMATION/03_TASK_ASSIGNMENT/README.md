# 03_TASK_ASSIGNMENT — タスク分配

WBSのタスクをAI社員に分配する工程です。担当:**PM_AI**。

| ファイル | 内容 |
|---------|------|
| [assignment_matrix.md](assignment_matrix.md) | 分配マトリクス(作業種別×担当AI)と発注テンプレ |

## 原則

- **AIは並行、人間は直列** — AI社員への発注は同時に複数、オーナーのレビューは1つずつ
- **餅は餅屋** — 各AIの苦手分野(Identity.md 記載)の仕事を振らない。迷ったらマトリクスへ
- 発注は必ず「完了定義・素材・期限」の3点セットで渡す
