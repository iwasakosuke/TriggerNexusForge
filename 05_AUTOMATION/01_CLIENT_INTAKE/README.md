## 工程

```
問い合わせ受信 → 24h以内に一次返信(ドラフト:Sales_AI ★送信:人)
→ 受付シート作成 → ヒアリング(商談)→ 提案方針の決定 → 02へ
```

## ルール

- 一次返信は**24時間以内**(内容が固まらなくても「受け取りました+いつ返すか」を返す)
- 受付シートなしで提案に進まない(情報の抜けは後工程で10倍のコストになる)
- 明らかなスパム・対象外の問い合わせも記録は残す(1行でよい)
