完了案件(closed)の格納ルールを定義します。担当:**PM_AI**。

## クローズの条件(すべて完了で closed)

- [ ] 入金確認済み
- [ ] 振り返り(KPT)実施済み → 教訓は `09_KNOWLEDGE_HUB/18_CASE_STUDY/` へ
- [ ] 再利用できる成果物をテンプレートに還元済み
- [ ] クライアントフォルダ(07_CLIENTS)内の機密整理(不要な認証情報の削除)
- [ ] 実績公開の可否を確認・記録済み

## 格納ルール

- 案件データは `07_CLIENTS/(クライアント名)/` に置いたまま、案件シートの状態を closed にする(移動しない。検索性優先)
- 年に1回、完全に取引が終了したクライアントのフォルダに `_archived_YYYY` サフィックスを付ける
- 保存期間:契約・請求関連は法定保存期間に従う(削除はオーナー判断)

## 再開時(リピート受注)

- 既存フォルダに新しい案件シートを追加する(1クライアント複数案件の構造)
- 前回の振り返り・教訓を読み返してから提案する(同じ失敗をしない)
