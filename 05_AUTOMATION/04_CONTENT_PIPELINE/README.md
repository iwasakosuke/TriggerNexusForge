コンテンツ制作(記事・SNS・LINE・メルマガ等)の生産ラインです。
**製造装置の実体は `02_CONTENT_FACTORY/`**。このフォルダは案件フローとの接続を定義します。

## 接続フロー(案件 → Content Factory → 案件)

```
案件シート(production 状態)
   ↓ PM_AI がタスク分配
02_CONTENT_FACTORY/01_INPUT/ の入力シートを記入(クライアント案件用)
   ↓
04_WORKFLOWS/content_pipeline.md の9ステップで生産
   ↓ (STEP 6 のレビューに「クライアントのレギュレーション確認」を追加)
成果物 → 05_OUTPUTS/(業種)/ に保存
   ↓
クライアント確認(★人が送る)→ 06_REVIEW → 07_DELIVERY へ
```

## クライアント案件での上乗せルール

- 入力シートの「8. 制約・注意」にクライアントの規制・レギュレーションを必ず記入
- 検品に業種別の法規制チェック(`00_RULES/prohibitions.md` の業種表)を追加
- 公開・投稿の実行は、クライアント承認+オーナー実行の2段階
- 実績としての公開(ポートフォリオ化)は契約時に許可を確認しておく
