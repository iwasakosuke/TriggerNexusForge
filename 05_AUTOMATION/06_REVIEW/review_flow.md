# Review Flow — レビュー手順

## 3段階レビュー

```
1. AI検品(内容)   : 生成していないAIがチェックリストで検品
2. PM_AI(工程)    : メタ情報・チェックリスト完了・スコープ適合の確認
3. オーナー(最終) : 品質3条件(価値・誠実・らしさ)で承認 ★
```

## ルール

- **生成した本人(同セッション)に検品させない**(→ 10_AI のレビュー原則)
- 差し戻しは「✗項目+修正指示」のセットで返す(「なんか違う」禁止)
- 差し戻し2回で構成・設計まで戻る判断をする(小手先修正で粘らない)
- クライアント案件は、社内承認→クライアント確認の順(逆にしない)

## 差し戻し基準(1つでも該当なら差し戻し)

- 禁止事項(prohibitions.md)に抵触/【要確認】タグが残っている
- 完了定義・スコープとズレている
- チェックリストに未完了項目がある

## 記録

- レビュー結果(承認/差し戻し・理由)は案件シートの工程ログへ1行
- 繰り返し出る✗項目は、上流(プロンプト・テンプレ)への反映を提案する
