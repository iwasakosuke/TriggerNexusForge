# Invoice Flow — 請求フロー

## 工程

```
納品完了(07)→ 請求書ドラフト(Sales_AI)→ ★人:金額・振込先確認→送信
→ 入金期日ウォッチ(PM_AI)→ 入金確認(★人)→ 案件シート更新 → 09へ
   └ 期日超過:リマインドドラフト(Sales_AI)→ ★人が送信
```

## 請求書に必ず入れる項目

- 請求番号(INV-YYYYMM-01)/ 発行日 / 支払期限(例:月末締め翌月末払い)
- 品目(案件名・内訳)/ 金額(税別・消費税・税込)
- 振込先 / 振込手数料の負担(先方負担が一般的。契約時に合意)
- 適格請求書発行事業者番号(該当する場合)

## 入金リマインドの文面ルール(Sales_AI)

- 期日+3営業日で1回目:事務的に、確認のトーンで(「行き違いでしたらご容赦ください」)
- +2週間で2回目:期日を切って明確に。以降はオーナーが直接対応
- 感情的・威圧的な文面は書かない(関係の維持と回収の両立)
