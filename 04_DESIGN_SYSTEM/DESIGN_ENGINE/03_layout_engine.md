# 03 Layout Engine — レイアウトエンジン

<!-- 「何をどこに、どの順で、どれだけの余白で置くか」の判断ロジック -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | 制作物の目的(1行)/ 情報の優先順位リスト / 媒体 |
| 出力 | レイアウト仕様(視線パターン・セクションリズム・余白設計) |

## 原則

1. **1画面(1面)1メッセージ** — 詰め込みは全要素の死
2. **階層は「サイズ→余白→色」の順で作る** — 色に頼るのは最後
3. **余白は関係の表現** — 近い=関係が深い(近接)。迷ったら空ける
4. **視線の着地点を1つ設計する** — 全要素が主役=主役不在

## 視線パターンの選択ロジック

| 制作物 | パターン | 適用 |
|--------|---------|------|
| LP・バナー(訴求) | **Z型** | 左上(キャッチ)→右上→左下→右下(CTA) |
| 記事・ドキュメント | **F型** | 見出しと段落冒頭に情報を前置き |
| カード一覧・料金表 | **グリッド型** | 等価な選択肢は等価に見せる(おすすめだけ差別化) |
| 図解 | **フロー型** | 視線の順番を矢印・番号で明示的に制御 |

## 余白システム(8px基準)

| トークン | 値 | 用途 |
|---------|-----|------|
| space-1〜2 | 8 / 16px | 要素内(ラベルと値・アイコンと文字) |
| space-3〜4 | 24 / 32px | 要素間(カード内の段落・ボタン周り) |
| space-6〜8 | 48 / 64px | ブロック間(見出しと本文群) |
| space-12 | 96px | セクション間(LP標準。モバイル64px) |

**リズム則**: セクション間 > ブロック間 > 要素間 を必ず守る(逆転=構造の崩壊)。

## セクションリズム(LP・長尺ページ)

- 背景色の交互(base → white → base…)で「進んでいる感」を作る
- ダークセクション(secondary)は1ページ2回まで(解決策・最終CTAなど山場に)
- CTAの手前は余白を広めに(呼吸させてから行動を求める)

## 出力形式

```yaml
layout:
  pattern: Z型 / F型 / グリッド / フロー
  focal_point: "(視線の着地点=最重要要素)"
  sections: [{ name: , bg: base/white/dark, note: }]
  spacing_notes: "(標準リズムからの変更があれば理由つき)"
```
