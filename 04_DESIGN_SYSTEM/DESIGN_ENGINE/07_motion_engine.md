# 07 Motion Engine — モーションエンジン

<!-- 動きの判断ロジック。「気づかれない動きが最上」(Apple原則)を全製品で徹底する -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | 動かしたい要素+動かす目的 |
| 出力 | モーション仕様(種類・時間・イージング)or「動かさない」判定 |

## 大原則

> **目的のない動きは、すべてノイズ。**
> モーションの用途は2つだけ:①状態変化のフィードバック ②視線誘導。
> 「かっこいいから」は理由にならない。

## モーショントークン

| トークン | 値 | 用途 |
|---------|-----|------|
| duration-fast | 150ms | ホバー・小さな状態変化 |
| duration-base | 200ms | 標準(ボタン・カード) |
| duration-slow | 300ms | セクション表示・大きめの変化 |
| easing | ease-out | 標準(登場・変化) |
| easing-in-out | ease-in-out | 位置移動(往復するもの) |

300msを超えるUIモーションは原則禁止(待たせる演出は離脱を生む)。

## 許可パターン(この4つ以外は要相談)

| パターン | 仕様 | 用途 |
|---------|------|------|
| Hover浮き | translateY(-2px) + 影 | ボタン・カード(どちらか1種に統一) |
| 色の深まり | brightness(0.94) or 濃色へ | ボタン(浮きと併用しない) |
| フェードイン | opacity 0→1 + 8px上昇 / 300ms | セクションのスクロール登場(LPのみ・全セクションにはかけない) |
| 開閉 | details の展開(CSSのみ) | FAQ・アコーディオン |

## 禁止パターン

- 自動再生カルーセル / 無限ループアニメ / 点滅・バウンド連発
- パララックスの多用 / スクロールジャック(スクロール量の乗っ取り)
- テキストのタイプライター演出(読ませたい文章を遅らせない)

## 必須対応

```css
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```

酔い・前庭障害への配慮。全製品のCSSに同梱する(→ 09 Accessibility)。

## 判定フロー

```
動かしたい → 目的は①フィードバック/②視線誘導のどちらか? 
  → どちらでもない → 動かさない(静止が正解)
  → どちらか → 許可パターンから選ぶ → トークンの値を使う
```
