# 06 Icon Engine — アイコンエンジン

<!-- アイコンの統一基準。バラバラのアイコンは「素人感」の最大の発生源 -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | 用途(UI補助 / 図解 / 装飾)+必要な概念のリスト |
| 出力 | アイコン仕様(スタイル・サイズ・色)+調達指示 |

## スタイル規格(全製品共通)

| 項目 | 規格 |
|------|------|
| スタイル | **ラインアイコン**(線画)で統一。塗り(Fill)との混在禁止 |
| 線の太さ | 1.5〜2px相当(セット内で統一) |
| 角 | 丸め(rounded)。トゲトゲしいアイコンは世界観に合わない |
| 色 | 単色のみ。text色 or secondary。強調時のみ primary |
| 多色・グラデ | 禁止(イラストの領域になり、統一が崩れる) |
| 絵文字 | **禁止**(🔥🚀⚙️等をUIアイコン代わりに使わない。必ずSVGに置き換える) |

## サイズシステム

| トークン | サイズ | 用途 |
|---------|-------|------|
| icon-sm | 16px | 文中・ラベル横 |
| icon-md | 24px | UI標準(ボタン内・リスト先頭) |
| icon-lg | 32px | カード見出し・図解 |
| icon-xl | 48px | ベネフィットセクション等の主役使い |

- 光学調整:文字とアイコンの縦中央を揃える(ベースライン揃えにしない)

## 使用ルール

1. **1セット主義** — 1つの制作物では1つのアイコンセットだけを使う(混ぜない)
2. **意味の一貫** — 同じ概念には常に同じアイコン(電話=常に同じ受話器)
3. **装飾に使わない** — アイコンは意味の圧縮装置。飾りで散らさない
4. **aria対応** — 意味を持つアイコンには aria-label、装飾は aria-hidden(→ 09)

## 調達の優先順位

```
1. オープンソースのラインアイコンセット(ライセンス確認:商用可・帰属条件)
2. 既存セットにない概念 → 同じ線幅・角丸で自作(またはAI生成→ ImagePrompt.md の
   「白背景・単色・フラット」指定)
3. どうしても見つからない → テキストラベルで代替(無理に変なアイコンを使わない)
```

## 出力形式

```yaml
icons:
  set: "(使用セット名+ライセンス)"
  style: { type: line, stroke: 2, corner: rounded, color: text }
  usage: [{ concept: 電話, icon: phone, size: md }]
```

概念からアイコンセットを探す場合は `09_KNOWLEDGE_HUB/02_UI_UX/REFERENCE/IconSets.md` を参照する。
