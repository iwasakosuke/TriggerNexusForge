# 10 Export Rules — 書き出しルール

<!-- 成果物を「外に出す」ときの形式・命名・品質ゲート。出口の規格が揃うと全製品の納品が揃う -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | 完成した設計(テーマ+各エンジンの出力) |
| 出力 | 製品別の納品形式(下記)+品質ゲート通過の確認 |

## 出力形式の規格

### A. テーマファイル(全製品共通の中間形式)

```
theme.yaml   — README のテーマスキーマに準拠(設計値の正)
tokens.css   — theme.yaml をCSS変数に変換したもの(実装用)
```

- theme.yaml が正、tokens.css はその写し(食い違ったら yaml に合わせる)

### B. Web系(LP Builder / Corporate Builder)

| 成果物 | 規格 |
|--------|------|
| HTML | 1ファイル自己完結 or テンプレ準拠。{{ }}・【要記入】残りゼロで納品 |
| CSS | tokens(変数)+スタイルの2層。!important 禁止 |
| 画像 | WebP優先・表示幅2倍まで・`loading="lazy"`・alt必須 |
| メタ | title / description / OGP(1200×630)/ favicon をセットで |

### C. 画像系(Banner Builder / Content Factory)

| 項目 | 規格 |
|------|------|
| 形式 | 写真系=JPG(品質80)/ 図解・文字主体=PNG / Web掲載=WebP |
| カラー | sRGB(CMYKは印刷案件のみ) |
| 容量 | SNS投稿 1MB以下 / OGP 500KB以下を目安 |
| 書き出しサイズ | 掲載サイズの2倍(Retina対応)。→ 04 Grid の標準キャンバス表 |

### D. WordPress系

- 標準ブロックのみのテキスト構成(→ LP Builder `Templates/wordpress.md`)
- ボタンにリンク先併記・画像に代替テキスト併記

## 命名規則(ファイル)

```
(案件/テーマID)_(用途)_(サイズ)_(版).拡張子
例:LP-20260705-01_ogp_1200x630_v2.png
   gym-trial_lp_v1.html
```

- 小文字英数とハイフン(日本語ファイル名は納品物には使わない)
- 版は v1, v2…(「最終」「fix」「本当の最終」を禁止)

## 品質ゲート(書き出し前の最終確認)

```
1. 09 Accessibility のチェックリストを通過したか
2. プレースホルダ({{ }}・【要記入】・仮画像)の残りがゼロか
3. 命名規則に従っているか
4. 権利確認(フォント・画像・アイコンのライセンス、声・写真の掲載許可)は済みか
5. 実機(スマホ)確認は済みか
```

1つでも未通過なら書き出さない。ゲートを通ったものだけが「納品物」と呼ばれる。
