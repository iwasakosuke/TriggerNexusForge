# 01 Color Engine — カラーエンジン

<!-- 「この案件の色」を決める判断ロジック。色は感覚ではなく、役割×業種×ペルソナから導出する -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | 業種 / ペルソナ(警戒・好み)/ 既存ブランドカラー(あれば) |
| 出力 | `theme.color`(役割ベースのパレット+検証結果) |

## 原則(全製品共通)

1. **色は機能** — 各色は役割を1つだけ持つ。Primary=行動、Secondary=構造、Base=背景
2. **比率 70:20:10** — Base 70% / Secondary 20% / Primary+Support 10%
3. **1画面の主役は1色** — Primaryが指す場所=ユーザーの取るべき行動
4. **コントラスト検証必須** — テキスト4.5:1 / UI部品3:1(→ 09 Accessibility)

## 生成ロジック(業種→カラー方向)

```
1. 既存ブランドカラーがある → それをPrimaryかSecondaryに配置して残りを設計(勝手に変えない)
2. ない → 業種の連想×ペルソナの心理でカラー方向を決定:
   - 業種の定石(下表)を出発点にする
   - ペルソナの警戒(例:圧の強い訴求への警戒→彩度を落とす)で補正する
3. 3色(primary/secondary/base)を確定し、コントラスト比を概算検証する
4. 代替案を1方向だけ添える(選択肢は2つまで。並べすぎない)
```

## 業種カラーの定石(出発点)

| 業種系統 | 方向 | 例(primary系統) |
|---------|------|-----------------|
| 健康・治療(整体・医療) | 信頼・回復 | 緑・青緑 |
| 美容・サロン | 柔らかさ・清潔 | ローズ・モーブ・ベージュ |
| 士業・金融 | 信頼・堅実 | ネイビー・深緑 |
| フィットネス | 活力(圧に注意) | テラコッタ・オレンジ(彩度控えめ) |
| 教育・講座 | 知性・前進 | 青・ネイビー×暖色アクセント |
| 飲食 | 食欲・温度 | 暖色(写真が主役。UIは無彩色寄り) |

※定石は出発点であって正解ではない。ペルソナ補正を必ず通す。

## 出力形式

```yaml
color:
  primary: "#XXXXXX"    # 行動(CTA)
  secondary: "#XXXXXX"  # 構造(見出し・ダーク面)
  base: "#XXXXXX"       # 背景
  text: "#26282B"       # 本文(真っ黒禁止・共通デフォルト)
  muted: "#5B6472"      # 補足(共通デフォルト。旧#6B7280は白背景比4.44:1でAA未達のため2026-07-08修正)
  border: "#E5E1DB"     # 罫線(共通デフォルト・装飾用途のみ)
  border-strong: "#9F9280"  # 入力欄など機能的境界線(白背景比3:1以上・非text要素の必須基準)
  semantic: { success: "#1F9D55", error: "#D64545" }  # 共通デフォルト
  checks: { primary_on_white: "4.6:1 AA", white_on_primary: "◯/△" }
  rationale: "(選定理由1〜2行)"
```

**コントラスト検証は数値で行う**(目視判断しない)。WCAG相対輝度式で算出し、本文4.5:1・UI部品3:1を下回るペアは採用しない。
`primary`をボタン背景に白文字で使う場合、ブランドの彩度が高いほど不足しやすい(例:TNF `#F25C05`は白文字だと3.33:1でAA未達 → `#C94A02`相当まで暗くして採用。実例:Core Engine v0.1、2026-07-08)。

## 業種カラーが定石表にない場合

`09_KNOWLEDGE_HUB/01_DESIGN/REFERENCE/ColorPalettes.md`(96パレット)から近い製品タイプ・業種を探して出発点にする。

## 禁止

- 虹色・多色主義(役割のない色を増やさない)/ 彩度MAXの原色ベタ
- Primaryの大面積使用 / 根拠なき配色変更(既存ブランドの無視)
