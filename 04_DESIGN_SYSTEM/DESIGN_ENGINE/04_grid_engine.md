# 04 Grid Engine — グリッドエンジン

<!-- すべての座標の土台。Web(カラム)とキャンバス(バナー・サムネ)の両方を規定する -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | 媒体(Web / バナー / 図解 / スライド)+サイズ |
| 出力 | グリッド仕様(単位・カラム・マージン・セーフエリア) |

## 基本単位:8pxグリッド(全媒体共通)

- すべての余白・サイズは8の倍数(例外:1px罫線、4px微調整のみ許可)
- 「なんとなく37px」を禁止する装置。迷ったら8の倍数に丸める

## Webグリッド

| 項目 | 仕様 |
|------|------|
| カラム | 12カラム(分割の柔軟性最大) |
| コンテンツ幅 | 標準1080px / 読み物720px |
| ガター | 24px(モバイル16px) |
| カード列 | `repeat(auto-fit, minmax(280px, 1fr))`(枚数可変に強い) |

## キャンバスグリッド(バナー・サムネイル・図解)

### 標準キャンバス

| 用途 | サイズ | セーフエリア(全周) |
|------|--------|---------------------|
| OGP・ブログアイキャッチ | 1200×630 | 60px(SNSでの見切れ対策) |
| X投稿画像 | 1600×900(16:9) | 80px |
| Instagramフィード | 1080×1350(4:5) | 80px+下部200px(UI被り) |
| Instagramカルーセル | 1080×1350 | 同上+左右は隣枚との連続性考慮 |
| YouTubeサムネ | 1280×720 | 右下は再生時間表示を避ける |

### キャンバス分割ロジック

```
1. キャンバスを3×3に分割する(三分割法)
2. 主役(タイトル/人物/商品)を交点または中央帯に置く
3. テキストはセーフエリア内・最大2ブロックまで
4. 余白最低20%(埋め尽くしたバナーは読み飛ばされる)
```

## 図解グリッド

- 型(比較表/フロー/マトリクス)を先に決め、型のグリッドに従う
- フロー:等間隔・等サイズの箱(大きさの差=重要度の差に見えるため、意図がなければ揃える)

## 出力形式

```yaml
grid:
  media: web / canvas / diagram
  unit: 8
  web: { columns: 12, container: 1080, gutter: 24 }
  canvas: { size: "1200x630", safe_area: 60, division: "3x3", focal: "左1/3交点" }
```
