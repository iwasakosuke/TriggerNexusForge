# 09 Accessibility — アクセシビリティ(非交渉)

<!-- 全エンジンを横断する品質基準。ここだけは「他のエンジンより優先」される -->

## 位置づけ

> **アクセシビリティは機能ではなく前提。美観と交換しない。**
> 他のエンジン(色・文字・モーション)の判断がここと衝突したら、常にこちらが勝つ。

## 基準(WCAG 2.1 AA 準拠を最低ライン)

### 1. コントラスト

| 対象 | 基準 |
|------|------|
| 本文テキスト | 4.5:1 以上 |
| 大テキスト(24px+/太字19px+) | 3:1 以上 |
| UI部品・図形の境界 | 3:1 以上 |

- Color Engine の出力は必ずこの検証を通す(「おしゃれな薄グレー文字」の禁止)

### 2. 操作

- タップ領域 44×44px 以上
- キーボードだけで全操作が可能(Tab移動・Enter実行)
- フォーカスリング必須(`:focus-visible`。消すのは禁止)

### 3. 知覚

- **色だけで情報を伝えない**(エラー=赤+文言、グラフ=色+ラベル)
- 全画像に意味のある `alt`(装飾は `alt=""`+`aria-hidden`)
- 動画・アニメには `prefers-reduced-motion` 対応(→ 07 Motion)

### 4. 構造

- 見出し階層を飛ばさない(h2→h4禁止)
- ランドマーク(main/nav/header/footer)を持つ
- リンクテキストは行き先が分かる(「こちら」禁止)
- フォームは label 紐付け+エラーは「直し方」を文言で

## 製品別の適用

| 製品 | 特に見る点 |
|------|-----------|
| LP Builder | CTA コントラスト・フォーム・FAQ(details のキーボード操作) |
| Banner Builder | 文字と背景のコントラスト・スマホ実寸での可読性 |
| Corporate Builder | 構造(見出し・ランドマーク)・ナビのキーボード操作 |
| Content Factory(図解) | 色に依存しない情報設計・文字サイズ下限14px相当 |

## 検証チェックリスト(全製品の出力前)

- [ ] コントラスト比:本文4.5:1 / UI 3:1 を満たすか
- [ ] タップ領域44px・隣接間隔8pxを満たすか
- [ ] キーボードのみで操作できるか・フォーカスが見えるか
- [ ] 色以外でも情報が伝わるか
- [ ] alt・aria-label は適切か
- [ ] 見出し階層・ランドマークは正しいか
- [ ] prefers-reduced-motion に対応しているか
