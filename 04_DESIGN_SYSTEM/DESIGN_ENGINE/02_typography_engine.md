# 02 Typography Engine — タイポグラフィエンジン

<!-- 文字まわりの全判断。書体・スケール・行間を媒体と読者に合わせて決定する -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | 媒体(LP/バナー/図解/サイト)/ トーン(theme.meta)/ 読者の年齢層 |
| 出力 | `theme.typography`(書体・スケール・行間・字間) |

## 標準書体セット(TNFデフォルト)

| 用途 | 和文 | 欧文 | ウェイト |
|------|------|------|---------|
| 見出し | Noto Sans JP | Montserrat | 700 / 800 |
| 本文 | Noto Sans JP | Inter | 400 / 500 |
| 数値・コード | — | JetBrains Mono | 400 |

- ウェイトは**3段まで**(400/500/700系)。階層はサイズと余白で作る
- 差し替え規則:トーンが「高級・情緒」→ 明朝系見出しを検討可。ただし本文はゴシック維持

## タイプスケール(1.25倍率ベース)

```
44 / 32 / 24 / 18 / 16(基準)/ 14 / 12  [px]
```

### 媒体別の補正ロジック

| 媒体 | 補正 |
|------|------|
| LP・Webサイト | 標準スケールのまま。モバイルはH1を1.9rem相当へ縮小(clamp使用 → 08 Responsive) |
| バナー・サムネ | 最小可読サイズが支配する:スマホ実寸で読める=キャンバス幅の1/10目安。要素は3階層まで |
| 図解 | 本文14px相当を下限。1枚に文字階層3つまで |
| 高年齢層向け | 本文16→18px、行間1.8→1.9に引き上げ |

## 和文組版ルール

- 本文行間 **1.8**(見出し1.3)/ 1行 **35〜40字**(container narrow 720px)
- 見出し字間 -0.01em / 英大文字ラベル +0.1em
- 強調は1段落1箇所まで。長文の両端揃え禁止

## 出力形式

```yaml
typography:
  heading: "Montserrat, Noto Sans JP"
  body: "Inter, Noto Sans JP"
  scale: [44, 32, 24, 18, 16, 14, 12]
  leading: { heading: 1.3, body: 1.8 }
  adjustments: "(媒体・読者による補正内容)"
```

## 禁止

- 4段以上のウェイト / 1つの制作物に3書体以上 / 12px未満の本文
- 文字の変形(長体・平体)/ 過度な字間広げによる「オシャレ薄字」
