## リリースの手順

1. 製品の Roadmap.md の完了条件を満たしたことを確認する
2. 社内資産からの差分反映(汎用化)と第三者視点の通しテストを行う
3. `release_log.md` に記録し、製品READMEの「状態」を更新する
4. v1.0 以降のリリースは `09_MARKETING`(販売ページ更新)と `10_FEEDBACK`(告知)に連携する

## ルール

- リリースは「完了条件ベース」(日付ベースで無理に出さない)
- 販売中製品の破壊的変更(構成変更)は、購入者への案内文とセットでリリースする
