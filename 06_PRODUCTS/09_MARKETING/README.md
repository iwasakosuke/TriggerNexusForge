# 09_MARKETING — 製品マーケティング

<!-- 製品を「売る」ための管理場所。価格・販売ページ・訴求を製品ごとに揃える -->

製品の販売活動(価格・販売ページ・訴求・導線)を管理します。

## ここで管理するもの

| 対象 | 内容 |
|------|------|
| 価格設計 | 製品ごとの価格・根拠(価値ベース)・プラン構成 |
| 販売ページ | LP・note販売ページの原稿(制作は Content Factory + LP Builder を使う=自社製品で自社製品を売る) |
| 訴求・実績 | ビフォーアフターの数字・利用者の声(事実のみ) |
| 販売導線 | SNS→note/LP→購入→サポート の動線設計 |

## 販売の原則(Brand.md 準拠)

- 誠実な期待値設定(「誰でも簡単に稼げる」系の訴求は絶対にしない)
- 実績数字は自社・許可済み事例のみ。「個人の結果です」の域を守る
- 価格は価値ベースで設計し、根拠(削減時間・受注実績)を言語化する
- 販売開始前チェック:`02_CONTENT_FACTORY/07_CHECKLIST/` + 特商法表記の確認
