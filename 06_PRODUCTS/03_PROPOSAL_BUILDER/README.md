# Proposal Builder — 提案書・見積ジェネレーター

<!-- ヒアリングメモから、提案書・見積書(松竹梅)を生成する製品 -->

## 製品概要

| 項目 | 内容 |
|------|------|
| 一言 | ヒアリングメモを貼ると、課題起点の提案書と松竹梅の見積書ドラフトが出てくるツール |
| 解決する課題 | 「提案書に毎回3時間かかる」「見積の出し方が我流で失注する」「安売りしてしまう」 |
| 対象ユーザー | フリーランス / 一人会社 / 小規模制作会社の営業担当 |
| 形態 | プロンプト+提案書/見積書テンプレート+ヒアリングシートのパッケージ(Markdown) |

## 3つの利用モード

| モード | 使い方 |
|--------|--------|
| ① 自社利用 | TNFの営業(Sales_AI)の標準装備。提案作成を3時間→30分に |
| ② クライアント利用 | 営業支援・営業資料整備の受託案件で納品物として使う |
| ③ 販売 | 「受注率を上げる提案の型」キットとして販売 |

## パッケージ内容(v1.0想定)

- ヒアリングシート(BANT+課題の言語化)
- 提案書生成プロンプト(課題→解決→進め方→価格→次のステップの型)
- 見積設計プロンプト(松竹梅3プラン+スコープ・修正回数の明文化)
- 断り文・値引き対応・フォローアップの文例集
