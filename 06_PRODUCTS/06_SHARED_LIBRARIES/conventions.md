# Conventions — プロダクト共通規約

## 変数規約(全製品のプロンプト共通)

| 変数 | 意味 |
|------|------|
| {会社名} | 導入先の会社・屋号 |
| {商材} | 提供している商品・サービス(価格帯込み) |
| {ターゲット} | 想定顧客(悩み込み) |
| {テーマ} | コンテンツ・制作物の主題 |
| {素材} | 使ってよい事実・一次体験・数字 |
| {ゴール} / {CTA} | 目的・させたい行動 |
| {基準} | 導入先のブランド基準・レギュレーション |

- 変数は `{日本語}` 形式で統一(視認性と説明不要性を優先)
- 記入されなかった変数は「勝手に補完せず、確認を求める」動作を全プロンプトに入れる

## バージョン規約

- `v0.1` 自社利用 / `v0.5` 案件投入 / `v0.9` 汎用化 / `v1.0` 販売 / `v1.x` 拡張
- 変更はすべて `07_RELEASES/release_log.md` に記録(製品名・版・内容・日付)

## ファイル構成規約(製品フォルダ)

- 必須5ファイル:README / Roadmap / Requirements / Prompt / Workflow
- 追加ファイルは自由。ただし必須5ファイルからリンクされていること(迷子ファイル禁止)

## 共通プロンプト部品

### 自己検品ブロック(全製品の生成系プロンプト末尾に付ける)

```text
出力後、次を自己チェックし、問題があれば【要確認】を付けて報告する:
①事実でない数字・体験が混ざっていないか ②誇大表現(絶対/100%/誰でも簡単に)がないか
③記入されていない変数を勝手に補完していないか
```

### 免責・思想ブロック(全製品のREADME・手順書に含める)

```text
- 本製品はドラフト(下書き)を作るツールです。送信・公開の前に必ず人間がご確認ください
- 成果(売上・受注・フォロワー等)を保証するものではありません
```
