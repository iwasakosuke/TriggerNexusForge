# 06_SHARED_LIBRARIES — 共有部品

<!-- 全プロダクト共通の部品と規約。「同じものを2度作らない」ための置き場 -->

全プロダクトで共有する部品・規約を管理します。

| ファイル | 内容 |
|---------|------|
| [conventions.md](conventions.md) | 共通規約(変数・バージョン・ファイル構成) |

## ここに置くもの

- **変数規約**: 全製品のプロンプトで共通の変数名({会社名}{ターゲット}等)
- **共通プロンプト部品**: 自己検品ブロック・誇大表現禁止ブロックなど、複数製品で使う定型文
- **共通テンプレート部品**: レポートのヘッダー・免責文・サポート案内の定型

## ルール

- 2つ以上の製品で同じ記述が必要になったら、ここに部品化して各製品から参照する
- 部品を変更したら、利用中の全製品への影響を確認してからリリースに載せる
