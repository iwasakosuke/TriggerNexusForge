# LP Builder — LP自動設計キット

<!-- 入力3項目(業種・商品・ターゲット)から、LPの構成・コピー・実装雛形までを生成する製品 -->

## 製品概要

| 項目 | 内容 |
|------|------|
| 一言 | 業種・商品・ターゲットを入れると、LPの構成→コピー→実装雛形まで一気通貫で作れるキット |
| 解決する課題 | 「LPを作りたいが、何をどの順で書けばいいか分からない」「制作会社に頼む予算がない」 |
| 対象ユーザー | 小規模事業者 / 駆け出しWeb制作者 / 一人会社 |
| 形態 | プロンプト集+HTMLテンプレート+業種別プレイブックのパッケージ(Markdown+コード) |

## 3つの利用モード

| モード | 使い方 |
|--------|--------|
| ① 自社利用 | TNFのLP制作(自社サービスLP)の標準ツールとして使う |
| ② クライアント利用 | 受託LP案件の制作エンジンとして使う(制作時間の短縮=粗利改善) |
| ③ 販売 | 「自分でLPを作りたい人」向けのキットとして販売(テンプレ+プロンプト+手順書) |

## パッケージ内容(v1.0想定)

- 構成設計プロンプト・コピー生成プロンプト(FVキャッチ10案 等)
- 8セクションLPテンプレート(HTML+CSS、デザイントークン差し替え式)
- 業種別プレイブック5種(飲食・美容・士業・ジム・講座)
- 公開前チェックリスト+手順書
