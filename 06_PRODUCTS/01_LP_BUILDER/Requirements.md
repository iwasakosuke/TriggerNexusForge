# LP Builder — Requirements(要件定義)

## 機能要件

| # | 要件 | 優先度 |
|---|------|:---:|
| F1 | 入力3項目(業種・商品・ターゲット)からLP全体構成を生成できる | 必須 |
| F2 | セクション別コピー(FV・課題・解決・料金・FAQ・CTA)を生成できる | 必須 |
| F3 | 生成コピーを流し込めるHTML/CSSテンプレートが付属する | 必須 |
| F4 | 業種別の訴求・構成調整ガイド(5業種以上)が付属する | 必須 |
| F5 | 公開前チェックリストが付属する | 必須 |
| F6 | 既存LPの改善診断プロンプトが付属する | 推奨 |

## 非機能要件(製品三原則)

### 再利用性
- ブランド固有値(色・フォント・社名・トーン)は `tokens.css` と変数プレースホルダに集約。本文への直書き禁止
- プロンプトの変数は `06_SHARED_LIBRARIES` の変数規約({テーマ}{ターゲット}等)に準拠

### 販売可能性
- 前提知識:HTML初級(コピペと文字編集ができる)を想定。専門用語には補足必須
- 購入者が最初の1本を作るまでの想定時間:半日。それを超える複雑さは削る
- 法規面の注意(業種規制・NG表現)を必ず同梱する(購入者を守る=返品・クレームを防ぐ)

### 拡張性
- 業種の追加=プレイブック1ファイル追加で完結する構造
- セクションの追加=テンプレートにHTMLブロック追加で完結(既存の書き換え不要)

## 制約・非対応(明文化)

- サーバー・ドメイン取得の代行はスコープ外(手順書での案内のみ)
- 効果保証はしない(実績数字は「TNFでの結果」として提示)
