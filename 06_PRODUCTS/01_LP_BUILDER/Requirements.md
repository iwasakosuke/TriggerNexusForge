## 機能要件(10機能と受け入れ基準)

| # | 機能 | 受け入れ基準(これを満たせば合格) |
|---|------|--------------------------------|
| F1 | 業種入力 | 業種名1語だけで全STAGEが完走する |
| F2 | ターゲット入力 | 空欄時:3案+推奨を提案する/入力時:入力を優先する |
| F3 | USP生成 | 競合の共通項(差別化にならない要素)を除外した上で3案+推奨が出る |
| F4 | キャッチコピー生成 | 型の異なる10案+サブコピー+推奨TOP3が出る |
| F5 | LP構成生成 | 8セクション構成表(目的・心理状態つき)+承認ゲートで停止する |
| F6 | セクション文章生成 | 全セクションの本文が「です・ます」60字/文で出る |
| F7 | CTA生成 | ボタン文言3案+不安解消コピー+3箇所の配置指示が出る |
| F8 | HTML生成 | lp.html 準拠の完成HTMLが1ファイルで出力される |
| F9 | CSS生成 | style.css 前提の3変数差し替え指定+選定理由が出る |
| F10 | WordPress対応文章生成 | wordpress.md 形式(標準ブロックのみ)で全セクションが出る |

## 品質要件(全機能共通)

| 要件 | 基準 |
|------|------|
| 事実の非捏造 | 未入力の実績・数字・声は必ず【要記入】枠になる(勝手に埋めたら不合格) |
| 誇大表現ゼロ | 「絶対」「100%」「誰でも簡単に」「必ず治る/痩せる」が出力に含まれない |
| 規制への配慮 | 業種規制に触れうる表現に【規制注意】+代替案が付く |
| 自己検品 | 最終出力に【要記入】【規制注意】の残数レポートが付く |

## 非機能要件(MVP)

### 再利用性
- テンプレートは自己完結(社内資産への参照なしで動く)
- CSSカスタマイズ面は3変数に限定(--color-primary / secondary / base)

### 販売可能性
- 前提知識:「コピペとテキスト編集ができる」以上を要求しない
- 初回完走の想定時間:90分以内
- 免責・思想(ドラフトツールである/成果保証しない)を README に明記

### 拡張性
- 業種対応の強化=業種プレイブックの追加(エンジン本体の改変不要)
- 実行例の追加=Examples に1ファイル追加

## スコープ外(明文化)

- 画像生成/フォーム設置/サーバー・ドメイン作業/効果測定ツールの設定
- 法規制の最終判断(【規制注意】は注意喚起であり、法務チェックの代替ではない)
