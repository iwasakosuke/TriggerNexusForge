# Module 10 — WordPress向けコンテンツ生成

<!-- HTMLを使わない人のために、WordPressブロックエディタに貼れる形式で全コンテンツを出力する -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | `project.copy` + `cta` + `faq` |
| 出力 | WP貼り付けキット(ページ設定+セクション別ブロック構成)。形式は `Templates/wordpress.md` 準拠 |

## プロンプト

```text
あなたはWordPress入稿の専門家です。確定した文章を、
WordPressのブロックエディタに標準ブロックだけで貼れる形式に変換してください。

# 入力
(project.copy / cta / faq を貼る)

# 手順
1. ページ設定を出力する:
   ページタイトル / パーマリンク(英語ケバブケース)/ メタディスクリプション(120字)
2. セクションごとに、使うブロックと内容を出力する:
   - 見出しブロック(H2)/ 段落ブロック / リストブロック / ボタンブロック(リンク先つき)
   - 画像位置は「画像ブロック+代替テキスト」で指定
3. 貼り付け手順(3行)と公開前の注意(スマホプレビュー確認)を添える

# ルール
- ショートコード・カスタムHTML・特定テーマの機能を前提にしない
- ボタンには必ずリンク先を併記(未定なら【要記入:URL】)
- 電話番号を載せる場合は tel: リンクの設定方法を1行添える

# 出力形式
Templates/wordpress.md のフォーマットに従う
```
