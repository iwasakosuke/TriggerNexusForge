# Module 02 — ペルソナ生成

<!-- 入力からLPの「たった1人の読者」を確定する。以降の全コピーはこのペルソナに向けて書かれる -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | `project.input`(Module 01 の出力) |
| 出力 | `project.persona`(1人のペルソナ+検討度) |

## プロンプト

```text
あなたはLPのターゲット設計の専門家です。
入力情報から、このLPが狙うべき「たった1人のペルソナ」を確定してください。

# 入力
(ここに Module 01 の出力 project.input を貼る)

# 手順
1. target の記述と industry の特性から、ペルソナ候補を3案作る。各案:
   - 名前(仮)・年齢・状況(職業・家族・生活)
   - 悩み(本人が頭の中で使っている言葉で3つ)
   - これまで試したこと・挫折経験
   - 行動の引き金(何があれば申し込むか)/ ブレーキ(何が不安で申し込まないか)
2. goal(成約させたい行動)に最も近い位置にいる1案を推奨し、理由を述べる
3. 推奨ペルソナの「検討度」を判定する:
   - 低(悩みはあるが解決策を探していない)/ 中(解決策を比較中)/ 高(どこにするか選ぶ段階)

# ルール
- 悩みは「◯◯に課題」のような抽象語ではなく、本人の独り言レベルの具体語で書く
- input.strengths と噛み合わないペルソナは推奨しない(強みが刺さる相手を選ぶ)

# 出力形式(YAML)
persona:
  name: / age: / situation:
  pains: [3つ・本人の言葉]
  tried: [試したこと・挫折]
  trigger: / brake:
  consideration: 低 / 中 / 高
  alternatives: [不採用2案の1行要約]
```

## サンプル入力

Module 01 のサンプル出力(パーソナルジム)をそのまま貼る。

## サンプル出力

```yaml
persona:
  name: 佐藤美咲(仮)
  age: 36
  situation: 在宅勤務の会社員。夫と5歳の子。平日は保育園送迎で自分の時間は夜のみ
  pains:
    - "産後から戻らない体型のまま、もう5年たってしまった"
    - "ジムに入会したのに3ヶ月で行かなくなった。私は意志が弱い"
    - "男性トレーナーに体型を見られるのも、隣で若い子が走ってるのも無理"
  tried: [24時間ジム(3ヶ月で幽霊会員), YouTubeの宅トレ(1週間), 糖質制限(リバウンド)]
  trigger: "『続けさせてくれる仕組み』と『恥ずかしくない環境』が両方あると確信できたら"
  brake: "また続かなかったらお金が無駄。きつい食事制限をさせられそう"
  consideration: 中(パーソナルジムという解決策は知っており、比較を始めた段階)
  alternatives:
    - "40代・健康診断で指摘された男性(→強み『女性のみ』が刺さらない)"
    - "20代・結婚式前の短期集中(→食事LINEサポートの継続価値が活きない)"
```
