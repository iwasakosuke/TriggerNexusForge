# Module 06 — CTA生成

<!-- 「行動の一歩」を設計する。ボタン文言・不安解消・配置・導線の4点セット -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | `project.input.goal` + `persona` + `copy`(fv / last_cta) |
| 出力 | `project.cta`(ボタン文言・マイクロコピー・配置・導線) |

## プロンプト

```text
あなたはCVR改善の専門家です。このLPのCTA一式を設計してください。

# 入力
(input.goal / persona / copy の fv・last_cta を貼る)

# 手順
1. ボタン文言を5案作る:
   - goal の行動を、ペルソナの心理的ハードルが最も低い動詞に言い換える
   - 「申し込む」より「空きを見る」「試してみる」の方向へ
2. 推奨1案を選ぶ(persona.brake を最も刺激しない表現)
3. ボタン直下のマイクロコピー(不安解消1行)を作る(brake に直接応答する)
4. 配置を指示する:FV直下 / 中盤(ベネフィット後)/ 最下部 の3箇所
5. 導線を判定する:この業種・ペルソナに電話導線は必要か。
   LINE導線(心理ハードル最小)を追加すべきか

# ルール
- ボタン文言は15字以内・動詞で終わる
- 偽の緊急性(「残り3名」等、事実でないもの)は禁止
- CTAは全箇所同じゴール(goal)に向ける(複数ゴール禁止)

# 出力形式(YAML)
cta:
  button: / button_candidates: [5案]
  micro: (不安解消1行)
  placements: [3箇所の位置と文脈]
  channels: { web: 必須, line: 要否+理由, tel: 要否+理由 }
```

## サンプル入力

Module 01〜05 のサンプル出力を貼る。

## サンプル出力

```yaml
cta:
  button: "初回体験の空きを見てみる"
  button_candidates:
    - "初回体験の空きを見てみる"   # 推奨:申込ではなく「見る」= 最小ハードル
    - "60分の体験を予約する"
    - "まずは体験から始める"
    - "カウンセリングだけ受けてみる"
    - "LINEで気軽に相談する"
  micro: "体験後の勧誘は一切ありません。合わなければそのままお帰りください。"
  placements:
    - "FV直下(キャッチ+安心要素の直後。まだ迷い中なので micro を必ず添える)"
    - "ベネフィット直後(『私にもできるかも』の温度が最も高い位置)"
    - "最下部(FAQで不安を消し切った直後。ボタンは大きめ)"
  channels:
    web: "必須(24時間受付の予約フォーム)"
    line: "推奨(『相談だけ』の受け皿。食事サポートがLINEなので導線としても自然)"
    tel: "不要(ペルソナは30代・電話は心理ハードルが高い。番号表記のみ小さく)"
```
