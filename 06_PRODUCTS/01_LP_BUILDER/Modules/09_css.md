# Module 09 — CSSテンプレート生成

<!-- Templates/style.css を前提に、業種×ペルソナに合わせた「3変数の色指定」を生成する -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | `project.input.industry` + `persona` |
| 出力 | CSS変数指定(3変数+選定理由)。`Templates/style.css` の `:root` に貼る |

## 設計思想

CSSは**生成しない。選ばせない。** スタイル本体(style.css)は検証済みの固定資産とし、
AIが決めるのは「業種とペルソナに合う3色」だけ。これが初心者の完成率と品質を両立させる。

## プロンプト

```text
あなたはWebデザイナーです。このLPのブランドカラー3色を決めてください。
スタイル本体は決定済みで、あなたが決めるのは色だけです。

# 入力
(input.industry / persona を貼る)

# 手順
1. 業種の色の定石と、ペルソナの好み・警戒(例:ジリジリした赤系は圧が強い)を考慮して
   カラー方向を1つ決める(理由つき)
2. 3変数を確定する:
   --color-primary   : CTA・アクセント(行動の色。背景に対しコントラスト比4.5:1以上)
   --color-secondary : 見出し・ダークセクション(信頼の色。暗め)
   --color-base      : ページ背景(明るく、真っ白よりわずかに温度のある色)
3. 白文字を primary に載せた場合のコントラスト比を概算で確認する
4. 代替案を1方向だけ添える(クライアント確認用)

# ルール
- 出力はCSSコードブロック+理由。style.css の他の部分の変更は提案しない
- 彩度の高すぎる原色・視認性の悪い組み合わせは避ける

# 出力形式
:root { 3変数 } のコードブロック+選定理由+代替案1つ
```

## サンプル入力

`industry: パーソナルジム` + persona(佐藤美咲=36歳女性・圧の強い訴求に警戒)

## サンプル出力

```css
:root {
  --color-primary: #D96C4F;   /* テラコッタ:行動を促す暖色。ジム定番の赤より圧が柔らかい */
  --color-secondary: #3E3A47; /* 墨がかった紫グレー:落ち着きと上質感。個室の静けさを表現 */
  --color-base: #FAF7F4;      /* 生成りホワイト:清潔感+体温。真っ白の緊張感を避ける */
}
```

**選定理由**: ペルソナは「結果コミット系の圧」に警戒があるため、燃焼系の赤・黒を避け、
「静かで安心できる個室」の世界観を色で先に伝える。テラコッタ×白のコントラスト比は約4.6:1でAA基準を満たす。

**代替案**: 落ち着いた緑系(`#4A7C6F` / `#2F4640` / `#F6F8F6`)— 健康・回復のイメージを優先する場合。

→ `Templates/style.css` の `:root` 冒頭3行を差し替えて完了
