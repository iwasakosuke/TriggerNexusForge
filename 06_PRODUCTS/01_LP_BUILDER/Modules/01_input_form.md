# Module 01 — 入力フォーム

<!-- パイプラインの入口。ここの記入品質が全出力の品質を決める。Webアプリ化時はHTMLフォームになる -->

## 役割

ユーザーから4項目(業種・ターゲット・目的・強み)+任意情報を受け取り、`project.input` を確定する。

## フォーム定義(Webアプリ化時のフォーム仕様を兼ねる)

| 項目 | キー | 必須 | 形式 | 検証ルール |
|------|-----|:---:|------|-----------|
| 業種 | `industry` | ✅ | 短文 | 空欄不可 |
| ターゲット | `target` | — | 自由記述 | 空欄可(Module 02 が提案) |
| 目的 | `goal` | ✅ | 選択式 | 体験申込 / 問い合わせ / 購入 / 資料請求 / 予約 のいずれか1つ |
| 強み | `strengths` | ✅ | 箇条書き(1〜5個) | **事実のみ**(願望・誇張は書かない) |
| オファー | `offer` | — | 短文 | 空欄可(Module 02 が定番を提案) |
| 実績・お客様の声 | `facts` | — | 箇条書き | **事実のみ**。空欄可(出力に【要記入】枠) |

## 入力フォーム(コピーして記入する)

```yaml
input:
  industry: ""      # 必須:業種(例:パーソナルジム)
  target: ""        # 任意:誰に売りたいか(分かる範囲で)
  goal: ""          # 必須:体験申込 / 問い合わせ / 購入 / 資料請求 / 予約
  strengths:        # 必須:強み(事実のみ・1〜5個)
    - ""
  offer: ""         # 任意:商品・価格(例:初回体験3,000円)
  facts:            # 任意:実績・お客様の声(事実のみ)
    - ""
```

## 記入ガイド(フォームの下に表示するヘルプ文)

- **強みは「事実」で書く** — ×「丁寧な接客」→ ○「女性トレーナーのみ・完全個室」(名詞で書けるものは強い)
- **目的は1つだけ** — 「体験も問い合わせも」はLPが弱くなる。迷ったら金額の低い行動を選ぶ
- **ターゲットが曖昧でもOK** — 次のモジュールがペルソナ3案を提案する

## サンプル入力(以降の全モジュールで共通の題材)

```yaml
input:
  industry: "パーソナルジム"
  target: "30〜40代の女性。運動が続かなかった経験がある人"
  goal: "体験申込"
  strengths:
    - "トレーナーは全員女性"
    - "完全個室(他の利用者と会わない)"
    - "食事指導つき(LINEで毎日サポート)"
    - "駅から徒歩3分"
  offer: "初回体験60分 3,000円"
  facts:
    - ""   # 未記入 → 以降のモジュールでは【要記入】枠になる
```
