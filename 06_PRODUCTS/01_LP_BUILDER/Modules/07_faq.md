## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | `project.input` + `persona`(特に brake / tried) |
| 出力 | `project.faq`(5〜7問の質問と回答) |

## プロンプト

```text
あなたはCVR改善の専門家です。購入直前の読者が抱える不安を先回りするFAQを作ってください。

# 入力
(project.input / persona を貼る)

# 手順
1. persona.brake と tried(挫折経験)から「申込みを止めている不安」を洗い出す
2. 業種の定番不安を加える(価格・時間・持ち物・支払い方法・キャンセル)
3. 5〜7問に絞る。順番は「不安の大きい順」(最初の2問が勝負)
4. 回答を書く。ルール:
   - 正直に答える(できないことは「できません」+代替案)
   - 回答の最後は安心で終える(ただし誇大にしない)
   - 1回答100字以内

# ルール
- 「よくある質問」の体裁をした自慢話にしない(不安に答える、が唯一の目的)
- input.facts にない実績・数字を回答に入れない
- 効果に関する回答は断定しない【規制注意】

# 出力形式(YAML)
faq:
  - q: / a:
```

## サンプル入力

Module 01〜02 のサンプル出力(パーソナルジム/佐藤美咲)を貼る。

## サンプル出力

```yaml
faq:
  - q: "運動が続いたことがありません。それでも大丈夫ですか?"
    a: "続かなかった方のためのジムです。毎回の予約をトレーナーと一緒に決めるので、『いつでも行ける→行かない』が起きにくい仕組みです。"
  - q: "きつい食事制限をさせられませんか?"
    a: "極端な制限は行いません。今の食生活をLINEで拝見しながら、続けられる範囲の調整を一緒に決めていきます。"
  - q: "体型に自信がなく、見られるのが恥ずかしいです"
    a: "完全個室で、担当するのは女性トレーナーだけです。他のお客様と顔を合わせることはありません。"
  - q: "体験に行くと、入会を勧誘されませんか?"
    a: "体験後の勧誘は行っていません。その場で決めていただく必要はなく、後日LINEでのご質問も歓迎です。"
  - q: "持ち物は何が必要ですか?"
    a: "動きやすい服と室内シューズのみです。タオルとお水は無料でご用意しています。"
  - q: "支払い方法は選べますか?"
    a: "クレジットカード・口座振替に対応しています。【要記入:実際の対応方法を確認】"
```
