# Module 08 — HTMLテンプレート生成

<!-- 確定コピーを Templates/lp.html に流し込み、公開可能なHTMLを出力する -->

## 入出力契約

| 方向 | 内容 |
|------|------|
| 入力 | `project.copy` + `cta` + `faq`(すべて確定済み) |
| 出力 | 完成HTML 1ファイル(`Templates/lp.html` の構造準拠) |

## プロンプト

```text
あなたはフロントエンド実装者です。確定した文章をHTMLテンプレートに流し込み、
公開可能な完成HTMLを出力してください。

# 入力
(project.copy / cta / faq を貼る)
(Templates/lp.html の内容を貼る ※Webアプリ化時はサーバー側で保持)

# 手順
1. copy / cta / faq の各値を、lp.html の {{プレースホルダ}} に対応させる
   対応表(| プレースホルダ | 流し込む値 |)を先に出力する
2. structure に「標準8セクションにないセクション」(例:挫折の再定義)がある場合、
   既存セクションの HTML 構造をコピーして同じ作法で追加する
3. 完成HTMLを1ファイルで出力する

# ルール
- テンプレートの構造・class名は変えない(追加セクションも既存の class を再利用)
- 【要記入】の値はそのまま HTML に残す(勝手に埋めない。公開前の目印になる)
- title / meta description / OGP も copy から生成して埋める
- FAQ は <details> 構造(JS不要)を維持する

# 出力形式
1. プレースホルダ対応表
2. 完成HTML(コードブロック1つ)
3. 残作業リスト(【要記入】箇所・画像差し込み位置・リンク先URL)
```
