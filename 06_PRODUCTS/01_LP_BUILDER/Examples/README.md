## 実行例の読み方

- 実行例は「業種:整体院」**の1語だけ**を入力した場合の出力(=最小入力での実力)
- 実績・お客様の声が未入力のため、出力には【要記入】枠が残る。**これが正しい動作**
  (LP Builder は事実を捏造しない。枠を作り、埋めるのは利用者)
- 実運用ではターゲット・オファー・実績を入力するほど出力の精度が上がる
