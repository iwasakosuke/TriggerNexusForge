## 作り方(他のexample_seitai.mdとの違い)

`example_seitai.md` はLP Builderのモジュール/STAGEパイプラインの出力例(構成→コピー→HTML、承認ゲートあり)。
本例はデザインの方向性そのものが依頼の核(「遊び心と親しみやすさ」)だったため、`ui-ux-pro-max` スキルの
`--design-system` でスタイル・配色・フォントを先に決定してから、TNFのアクセシビリティ基準(WCAG AA)を
満たすよう調整して1枚のHTMLに実装した。ビジネス名・料金・お客様の声は架空/未確定のため【要記入】枠にしている
(事実の捏造はしない、というLP Builder共通ルールに準拠)。

## デザインシステム(ui-ux-pro-maxの提案)

```
python3 .claude/skills/ui-ux-pro-max/scripts/search.py \
  "pet grooming service playful friendly local business" --design-system -p "Pet Grooming LP"
```

- **スタイル**: Claymorphism(厚いボーダー・二重シャドウ・丸み16〜24px。子供向け/カジュアル向けの定番スタイル)
- **フォント**: 見出し Fredoka(丸みのある親しみやすい書体)/ 本文 Nunito + Noto Sans JP
- **配色(提案そのまま)**: Primary `#F97316`(オレンジ)/ Secondary `#FB923C` / CTA `#2563EB`(信頼のブルー)/ Background `#FFF7ED`

## TNFアクセシビリティ基準による調整(重要)

スキルの提案をそのまま使うと、白文字ボタンの背景に Primary(`#F97316`)を使った場合コントラスト比が **2.80:1 でAA未達**
(Secondaryの`#FB923C`は2.26:1でさらに悪い)。これはCore Engine・LP Builder標準テンプレートで見つかったのと同じ
「ブランド色が明るいほど白文字コントラストが不足する」パターン。

対応:提案に最初から含まれていた **CTA色(`#2563EB`、白文字5.17:1でAA適合)を予約ボタンに採用**し、
Primary/Secondaryのオレンジ系は装飾(バッジ・アイコン・カードの縁取り)専用にとどめた。
本文色も `#9A3412`(白背景7.31:1)を採用し、見た目の温かみとコントラストを両立させている。

## 構成(6セクション)

| # | セクション | 内容 |
|---|-----------|------|
| 1 | FV | キャッチ+安心要素3点+予約CTA(ページ内リンク`#booking`) |
| 2 | グルーミングメニュー | サービス4種をカード表示(SVGアイコン。絵文字は不使用) |
| 3 | 選ばれる理由 | 3つの安心ポイント(オレンジの背景セクションで気分転換) |
| 4 | 料金プラン | 【要記入】枠付きの単一プランカード |
| 5 | お客様の声 | 【要記入】枠×2 |
| 6 | FAQ+最終CTA | 人見知り・シニア対応・キャンセル等5問+予約ボタン再掲 |

## 検証済み事項(Playwright)

- 全セクション・カード・FAQ(5問・開閉動作)が正常表示、JSエラー0件
- デスクトップ(1280px)・モバイル(390px)双方でレイアウト崩れなし
- CTAボタンの実背景色を計算で確認(`rgb(37, 99, 235)` = `#2563EB`)
- `prefers-reduced-motion` 対応済み
