# Templates — LP Builder 実装テンプレート

<!-- STAGE 6〜7 の出力先。自己完結(このフォルダだけで動く)がMVPの設計方針 -->

| ファイル | 役割 | 対応機能 |
|---------|------|---------|
| [lp.html](lp.html) | LP本体(8セクション+meta/OGP、{{プレースホルダ}}式) | ⑧ HTML生成 |
| [style.css](style.css) | スタイル一式(1ファイル自己完結。差し替えは3変数のみ) | ⑨ CSS生成 |
| [wordpress.md](wordpress.md) | WordPressブロックエディタ向け出力の形式定義 | ⑩ WP対応文章 |

## 使い方

1. `lp.html` と `style.css` を同じフォルダにコピーする
2. STAGE 6 の出力(完成HTML)で `lp.html` を置き換える(または {{ }} を手動置換)
3. STAGE 6 の色指定に従い、`style.css` の `:root` 3変数だけを差し替える
4. ブラウザで開いて確認 → {{ }} の残りゼロを確認して公開

## 設計方針(MVP)

- **自己完結**: 社内資産(03_WEB_STUDIO)への参照なしで動く。外部CDN依存はGoogle Fontsのみ
- **カスタマイズ面を絞る**: 色は3変数だけ。選択肢を減らすことが初心者の完成率を上げる
- **JS不要**: FAQは `<details>`、スムーススクロールはCSS。壊れる部品を持たない
