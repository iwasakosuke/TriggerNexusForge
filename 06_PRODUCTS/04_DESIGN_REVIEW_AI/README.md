# Design Review AI — デザインレビューAI

<!-- LP・バナー・スライドを、基準に沿って診断・改善提案するレビューAI製品 -->

## 製品概要

| 項目 | 内容 |
|------|------|
| 一言 | LP・バナー・資料のスクショや構成を渡すと、基準に沿って診断し改善案を返すレビューAI |
| 解決する課題 | 「デザインの良し悪しが判断できない」「外注品の検収ができない」「なんとなくダサいが理由が分からない」 |
| 対象ユーザー | デザイナー不在の事業者 / 発注側の担当者 / 駆け出しデザイナー |
| 形態 | レビュープロンプト+診断基準書+改善パターン集(Markdown) |

## 3つの利用モード

| モード | 使い方 |
|--------|--------|
| ① 自社利用 | TNF制作物のセルフ検品(Designer_AI のレビュー機能) |
| ② クライアント利用 | デザイン診断サービス(単体商品化しやすい:LP診断◯円) |
| ③ 販売 | セルフレビューキットとして販売(発注者の検収ツールとしても) |

## パッケージ内容(v1.0想定)

- レビュープロンプト(総合診断+観点別:FV/配色/文字/CTA/信頼感)
- 診断基準書(視覚階層・コントラスト・アクセシビリティの判定基準)
- 改善パターン集(よくあるNG→改善例)
- 診断レポートテンプレート(そのまま納品書式になる)
