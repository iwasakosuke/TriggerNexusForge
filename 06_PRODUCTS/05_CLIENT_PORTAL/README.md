# Client Portal — クライアント進行ポータルキット

<!-- 案件の進捗・納品物・やり取りをクライアントと共有する運用キット -->

## 製品概要

| 項目 | 内容 |
|------|------|
| 一言 | 案件の進捗・納品物・確認事項をクライアントと1箇所で共有する「進行ポータル」の運用キット |
| 解決する課題 | 「今どうなってますか?」の往復 / メール・チャットに散らばる確認事項 / 検収の曖昧さ |
| 対象ユーザー | 受託業のフリーランス・小規模チーム(とそのクライアント) |
| 形態 | ポータルのテンプレート一式+運用ルール(Markdown。Notion等への移植手順つき) |

## 3つの利用モード

| モード | 使い方 |
|--------|--------|
| ① 自社利用 | TNFのクライアント案件の進行共有に使う(信頼&手戻り削減) |
| ② クライアント利用 | 案件開始時にポータルを開設して先方に提供(体験価値=差別化) |
| ③ 販売 | 受託業向け「顧客体験キット」として販売 |

## パッケージ内容(v1.0想定)

- ポータルテンプレート(案件概要/進捗ボード/納品物リスト/確認事項/議事メモ)
- 運用ルール(更新頻度・書き方・NGコミュニケーション)
- クライアント向け案内文(ポータルの使い方説明)
- Notion等への移植手順

## 元になった社内資産

`05_AUTOMATION/`(案件フロー・案件シート・納品チェック)のクライアント公開版
