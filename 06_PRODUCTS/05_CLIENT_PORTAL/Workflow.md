# Client Portal — Workflow(使用手順)

## 案件開始時(30分)

```
STEP 1 開設: ポータルテンプレートをコピーし、案件概要(スコープ・納期・完了定義)を記入
STEP 2 案内: クライアント向け案内文で使い方を共有(「ここを見れば全部わかります」)
STEP 3 合意: 更新頻度(週1)と確認事項の返答期限の目安を先方と合意する
```

## 週次運用(5〜15分)

```
1. 案件シート(社内)を更新する ※順番が大事:社内が正、ポータルはその写し
2. 中核プロンプトで週次更新文をドラフト
3. 人間が確認して転記・送信 ★(内部情報の漏れ・トーンを最終チェック)
```

## 入出力の定義

| 項目 | 内容 |
|------|------|
| 入力 | 案件シート+今週の動きメモ |
| 出力 | ポータル更新文(サマリー/進捗/依頼事項/次週予定) |

## 品質ゲート

- 内部専用情報(原価・社内メモ・他クライアント情報)が混ざっていないか
- 先方への依頼に期限があるか/ボールの所在が明確か
