# Content Factory PRO — コンテンツ工場・汎用版

<!-- TNFのContent Factory(1テーマ→10媒体)を、誰でも導入できる形にした製品 -->

## 製品概要

| 項目 | 内容 |
|------|------|
| 一言 | 1つのテーマから note・X・Instagram・ブログ・LINE・メルマガ等10媒体のコンテンツを量産する工場一式 |
| 解決する課題 | 「発信が続かない」「媒体ごとに毎回ゼロから作っている」「品質がばらつく」 |
| 対象ユーザー | 一人社長 / 発信で集客したい事業者 / コンテンツ制作者 |
| 形態 | フォルダ構造+プロンプト集+テンプレート+検品チェックリストのパッケージ(Markdown) |

## 3つの利用モード

| モード | 使い方 |
|--------|--------|
| ① 自社利用 | TNFの発信の生産設備そのもの(`02_CONTENT_FACTORY` が現物) |
| ② クライアント利用 | コンテンツ制作代行・発信内製化支援の納品物として導入する |
| ③ 販売 | 「会社の発信工場」導入キットとして販売(TNFの看板商品候補) |

## パッケージ内容(v1.0想定)

- 10フォルダ構造一式(RULES / INPUT / PROMPTS / TEMPLATES / WORKFLOWS / OUTPUTS / KNOWLEDGE / CHECKLIST / EXAMPLES / ARCHIVE)
- 媒体別プロンプト10種+テンプレート8種+検品リスト8種
- 導入ガイド(自社のブランド・トーンの設定手順=変数の埋め方)
- 運用ガイド(週1テーマの回し方・数字の見方)

## 元になった社内資産

`02_CONTENT_FACTORY/` 一式(このリポジトリで実運用中のものが常に最新の実証版)
