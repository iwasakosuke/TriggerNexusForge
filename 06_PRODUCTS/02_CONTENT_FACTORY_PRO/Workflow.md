# Content Factory PRO — Workflow(使用手順)

## 導入フロー(購入者向け・半日)

```
STEP 1 環境準備(30分) : AIツールの用意・フォルダ一式の配置
STEP 2 ブランド設定(60分): brand_config を記入(社名・軸・トーン・NGワード)
STEP 3 試運転(90分)   : サンプルテーマで1媒体だけ生成→検品→修正を体験
STEP 4 初回生産(〜1週間): 自分のテーマで入力シート→9ステップを一周
```

## 週次運用フロー(導入後)

```
金:入力シート記入(テーマ・ターゲット・目的)
月:軸コンテンツ生成(構成→承認→本文)
火:派生生成(SNS・LINE・メルマガ)+検品
水:最終確認・承認
木〜:公開(媒体ごとに時間差)→ 数字の記録
```

## 入出力の定義

| 項目 | 内容 |
|------|------|
| 入力 | 入力シート1枚(テーマ/ターゲット/悩み/目的/媒体/CTA) |
| 出力 | チェックした媒体のコンテンツ一式(テンプレート形式・検品済み) |
| 副産物 | 勝ちパターン記録(EXAMPLES)・改善ログ(ARCHIVE) |

## 品質ゲート

- 全コンテンツが公開前チェックリスト(master)を通過すること
- 「事実でない体験・数字」の混入はどの利用モードでも一発差し戻し
