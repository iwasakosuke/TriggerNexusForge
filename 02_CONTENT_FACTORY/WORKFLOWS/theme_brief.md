# Theme Brief — テーマブリーフ(工場への発注書)

<!-- 1テーマの生産を始める前に必ず書く1枚。これをコピーして使う。曖昧なまま生成を始めない -->

コピーして `OUTPUTS/テーマID/_brief.md` として保存し、記入してから生産を開始する。

---

```markdown
# テーマブリーフ:(テーマを1行で)

## 基本情報
| 項目 | 内容 |
|------|------|
| テーマID | T-YYYYMMDD-01 |
| 起票日 | YYYY-MM-DD |
| 状態 | 企画中 / 生産中 / レビュー中 / 公開済 |
| 公開目標日 | |

## テーマの中身
### 一次体験(このテーマの原材料。なければ生産しない)
(実際にやったこと・起きたこと・使ったもの)

### 数字・事実(使ってよい実数のみ)
(例:制作時間 3日→3時間 / 費用 ◯円 / 12件中9件)

### 読者
(誰が・どんな状況で・何に困っている人か)

### 読者のゴール(読後にどうなってほしいか)
(1つだけ。例:「自分もできそう」と思い、プロフィールを見に来る)

## 展開計画
| 媒体 | 形式 | 担当AI | 優先度 | 状態 |
|------|------|--------|:---:|------|
| Blog / note | 軸コンテンツ | Copywriter_AI | 高 | 未着手 |
| X | スレッド | SNS_AI | 高 | 未着手 |
| X | 単発×3 | SNS_AI | 中 | 未着手 |
| Threads | 連投 or 単発 | SNS_AI | 中 | 未着手 |
| Instagram | カルーセル | SNS_AI+Designer_AI | 中 | 未着手 |
| LP | (売る物がある場合のみ) | Copywriter_AI | - | - |

## 制約・注意
(クライアント関連の許可・規制・触れないこと。なければ「なし」)

## 参考
(過去の類似テーマ・競合コンテンツ・参考URL)
```

---

## 記入のコツ

- **一次体験が空欄なら生産しない** — 借り物の知識でコンテンツを作らない(Value: 一次体験>借り物)
- **読者のゴールは1つに絞る** — 「認知もCVも」と欲張ると全部ぼやける
- **全媒体展開は義務ではない** — テーマとの相性で選ぶ(→ `content_pipeline.md` の媒体選定の目安)
