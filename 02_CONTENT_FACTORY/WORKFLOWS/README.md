# WORKFLOWS — 生産工程

<!-- コンテンツ工場の工程書。入力→生成→レビュー→出力の流れをここで定義する -->

コンテンツ制作の「工程」を管理します。何をどの順で、誰(どのAI)がやるかの手順書です。

## ファイル一覧

| ファイル | 内容 |
|---------|------|
| [content_pipeline.md](content_pipeline.md) | メインパイプライン(入力→生成→レビュー→出力の詳細手順) |
| [theme_brief.md](theme_brief.md) | テーマブリーフ(工場への「発注書」テンプレート) |

## 基本の流れ(サマリー)

```
1. 入力   : theme_brief.md に沿ってテーマを1枚に定義する
2. 生成   : ブリーフを PROMPTS/ の媒体別プロンプトに流し、AI社員が並行生成
3. レビュー: KNOWLEDGE/ の基準で検品 → オーナーが最終承認
4. 出力   : TEMPLATES/ の形式で OUTPUTS/ に保存 → 各媒体へ公開
```

詳細は `content_pipeline.md` を参照。
