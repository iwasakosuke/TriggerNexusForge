## 生成フロー(サマリー)

```
テーマ入力(01_INPUT)
  ↓
競合分析 ─ 同じテーマの上位・人気コンテンツを確認
  ↓
SEO分析 ─ 検索意図・キーワードの確定(Blog展開時)
  ↓
構成作成 ─ 軸コンテンツの骨組み → オーナー承認
  ↓
本文 ─ 軸コンテンツの執筆(Copywriter_AI)
  ↓
レビュー ─ 07_CHECKLIST で検品
  ↓
改善 ─ 差し戻し反映・推敲
  ↓
媒体変換 ─ 10媒体へ展開(SNS_AI / Designer_AI)
  ↓
完成 ─ 05_OUTPUTS 保存 → オーナー承認 → 公開 → 記録
```

詳細は `content_pipeline.md` を参照。
