# SEO Checklist — SEO検品

<!-- Blog記事専用。根拠は 00_RULES/seo_rules.md と 06_KNOWLEDGE/seo.md -->

- [ ] 1記事1キーワードになっているか
- [ ] タイトル32字以内・キーワード前方・具体性があるか
- [ ] メタディスクリプション(120字)を書いたか
- [ ] リード文で検索意図に答えているか(結論を隠していないか)
- [ ] 一次体験(Experience)のセクションがあるか
- [ ] 見出しだけ読んで流れが分かるか(H2は3〜6個)
- [ ] 手順はリスト・比較は表になっているか
- [ ] 内部リンクを双方向で設計したか(既存記事の更新も)
- [ ] 画像にaltを付けたか
- [ ] URLスラッグは英語ケバブケースか
- [ ] 公開後の計測予定(1ヶ月・3ヶ月)をテンプレートに記入したか
