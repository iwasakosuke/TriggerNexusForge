# CTA Checklist — CTA検品

<!-- CTAを持つ全コンテンツ対象。根拠は 00_RULES/copywriting_rules.md -->

- [ ] CTAは1つに絞られているか(複数ゴールになっていないか)
- [ ] 入力シートの「目的」とCTAが一直線か(目的=販売なのにCTA=フォロー等のズレがないか)
- [ ] 文言は行動ハードルの低い動詞か(「申し込む」より「まずは無料で相談する」)
- [ ] 「こちら」「詳細」単独のリンク文言になっていないか
- [ ] CTA直下に不安解消の1行があるか(LP・セールス文)
- [ ] 誘導先URLは正しいか(実際にタップして確認)
- [ ] CTAの位置は適切か(LP=3箇所/記事=末尾+自然な中間/SNS=プロフィール導線)
- [ ] 押し込み型の圧力表現(今すぐ決めて等)がないか
