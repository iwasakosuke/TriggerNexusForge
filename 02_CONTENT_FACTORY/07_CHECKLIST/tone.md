# Tone Checklist — トーン検品

<!-- 全公開物対象。「声」が正しいかの検品。根拠は 00_RULES/brand_rules.md -->

## ボイスの核

- [ ] 「一歩先を行く実践者」の声に聞こえるか(先生・評論家になっていないか)
- [ ] 読者を見下ろしていないか(「〜すべき」の連発・説教臭)
- [ ] 実践者テスト:この文は「やった人」にしか書けないか

## 4原則

- [ ] 結論から書いているか(前置き・自分語りで始まっていないか)
- [ ] 実践ベースか(「〜らしい」「〜と言われています」がないか)
- [ ] 数字で示しているか(「多くの」「かなり」を数字に置換したか)
- [ ] 煽っていないか(不安を人質にしていないか)

## 媒体の温度感(→ 00_RULES/brand_rules.md の媒体別トーン調整表)

- [ ] Blog/LP: 落ち着いた実務者の声か(軽すぎないか)
- [ ] X/Threads: 等身大の声か(硬すぎ・宣伝臭くないか)
- [ ] note: 体温があるか(事務的すぎないか)
- [ ] LINE/メルマガ: 1人に宛てた手紙になっているか(「皆さん」と書いていないか)

## 最終テスト

- [ ] 翌朝テスト:明日読み返して恥ずかしくないか
- [ ] 誠実テスト:この内容を、目の前の読者本人に口頭で言えるか
