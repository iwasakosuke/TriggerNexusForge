# Proofreading Checklist — 誤字脱字・事実確認検品

<!-- 公開直前の最終校正。「1つの誤字が全体の信頼を下げる」 -->

## 誤字脱字

- [ ] 全文を音読(または読み上げ)したか
- [ ] 固有名詞のスペル・表記を確認したか(Trigger Nexus Forge / クライアント名 / ツール名)
- [ ] 数字の桁・単位を再確認したか(万と億、%と倍)
- [ ] 変換ミスの頻出パターンを検索したか(以外/意外、制作/製作、対象/対照)
- [ ] {変数}・【画像:】・(ここに◯◯)などのプレースホルダ残りがないか

## 事実確認

- [ ] すべての数字に出所があるか(自分の記録・公式情報)
- [ ] 日付・期間・価格は現時点で正しいか
- [ ] 引用・参照は原典を確認したか
- [ ] 【要確認】タグがゼロか
- [ ] スクリーンショットに個人情報・機密情報が写り込んでいないか

## リンク・表示

- [ ] 全リンクを実際に開いて確認したか
- [ ] (メール・LINE)テスト送信して表示を確認したか
- [ ] (Web)OGP画像・タイトルの表示を確認したか
