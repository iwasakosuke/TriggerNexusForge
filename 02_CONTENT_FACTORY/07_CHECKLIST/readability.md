# Readability Checklist — 可読性検品

<!-- 「読みやすさ」の構造チェック。スマホでの見た目を基準にする -->

- [ ] スマホ実寸で確認したか(制作はPCでも、読者の8割はスマホ)
- [ ] 冒頭3行で「読む理由」が分かるか
- [ ] 適切な位置に空行・改行があるか(壁のような文章ブロックがないか)
- [ ] 見出し・箇条書き・表を使って流し読みに耐えるか
- [ ] 強調(太字)は1段落1箇所以内か(強調だらけ=強調ゼロ)
- [ ] 図解・画像を入れるべき箇所に入っているか(3スクロール文字だけが続いていないか)
- [ ] リンクだと分かる表記になっているか
- [ ] (SNS)1画面目に情報が詰まりすぎていないか
- [ ] (LP・Web)コントラスト・文字サイズはアクセシビリティ基準か(→ Brand.md AA基準)
