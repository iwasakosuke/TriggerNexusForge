# Brand Checklist — ブランド適合検品

<!-- 全公開物対象。「TNFが出すものとして恥ずかしくないか」。根拠は 00_COMPANY/Brand.md -->

## 内容面

- [ ] 発信の軸(AI活用×一人会社×制作ノウハウ)の中にあるか ※自社発信の場合
- [ ] 一次体験に基づいているか(借り物の一般論になっていないか)
- [ ] 約束していることは、TNFとして守れる範囲か
- [ ] 競合・他者への批判になっていないか

## 表記・表現面

- [ ] 社名表記が正しいか(Trigger Nexus Forge / TNF / TriggerNexusForge の使い分け)
- [ ] NGワードゼロか(→ `00_RULES/prohibitions.md`)
- [ ] 絵文字ルールを守っているか(SNS3つまで/LP・文書は使わない)

## ビジュアル面(画像・図解がある場合)

- [ ] ブランドカラーの用途が正しいか(オレンジ=行動・強調のみ、大面積NG)
- [ ] 禁止表現(ネオン・SF調・AIロボット・虹色)がないか
- [ ] フォントは規定(Montserrat/Inter/Noto Sans JP)か
- [ ] 図解は3色以内か

## クライアント案件の場合

- [ ] クライアントのブランドガイドライン・レギュレーションを確認したか
- [ ] 業種の規制(薬機法・景表法等)チェックを通したか
