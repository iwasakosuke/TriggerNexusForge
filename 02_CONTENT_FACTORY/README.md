# 02_CONTENT_FACTORY — TNF Content Factory

<!-- Trigger Nexus Forge のコンテンツ生産システム。1テーマから全媒体のコンテンツを生成するAI制作工場 -->

> **1つのテーマから、あらゆるコンテンツを。**
> テーマ・ターゲット・目的を入力すると、note / Threads / Instagram / X / ブログ / LP /
> LINE / メルマガ / CTA / 画像生成プロンプトまでを生産する工場です。

## Content Factory とは

Trigger Nexus Forge のコンテンツ制作を担う**生産システム**です。
属人的な「頑張って書く」を廃止し、**入力 → 生成 → レビュー → 出力**の工程と品質基準をすべて型化しています。

- テーマ(一次体験)は最も高価な原材料。1媒体で使い捨てにしない
- 生成はAI社員が並行で、レビューは人間が直列で(AI First, Human Final)
- 工程・基準・実例をすべてMarkdownで管理し、使うほど賢くなる工場にする

## 目的

1. **生産量**: 1テーマから10種類のコンテンツを生成し、発信量を10倍にする
2. **品質**: どの媒体でも「TNFらしい」トーンと品質基準(→ `00_RULES`)を守る
3. **資産化**: 成果が出た型を `08_EXAMPLES` に蓄積し、勝率を上げ続ける
4. **移植性**: この工場ごとクライアント・プロダクトに展開できる構造にする(2028年の商品化を見据える)

## フォルダ構成

```
02_CONTENT_FACTORY/
├── README.md        # 本ファイル(全体設計)
├── 00_RULES/        # ルール — 文章・ブランド・SEO・コピー・禁止事項・品質基準
├── 01_INPUT/        # 入力 — テーマ・ターゲット・目的の入力テンプレート
├── 02_PROMPTS/      # 生成エンジン — 媒体別プロンプト(10媒体)
├── 03_TEMPLATES/    # 成果物の型 — 媒体別テンプレート(状態管理付き)
├── 04_WORKFLOWS/    # 生産工程 — 入力から完成までの9ステップ
├── 05_OUTPUTS/      # 出力倉庫 — 業種別の制作物保存場所
├── 06_KNOWLEDGE/    # 知識ベース — SEO・コピー・マーケ・心理学・SNS
├── 07_CHECKLIST/    # 検品所 — 公開前の品質確認リスト
├── 08_EXAMPLES/     # 実例集 — 売れた・伸びたコンテンツの記録
└── 09_ARCHIVE/      # 記録庫 — 改善履歴・アップデート履歴
```

## ワークフロー(概要)

```
[入力]                [分析・設計]           [生成]
01_INPUT に記入  →  競合分析 → SEO分析  →  構成 → 本文
(テーマ・ターゲット・目的)                      │
                                              ▼
[完成]                [展開]               [品質管理]
05_OUTPUTS 保存 ←  媒体変換(10媒体)  ←  レビュー → 改善
→ 公開・記録                            (07_CHECKLIST)
```

詳細手順は [`04_WORKFLOWS/content_pipeline.md`](04_WORKFLOWS/content_pipeline.md) を参照。

## 使用方法(最短ルート)

1. **入力**: `01_INPUT/input_template.md` をコピーして記入する(5分)
2. **生成**: 入力シートを `02_PROMPTS/` の媒体別プロンプトに渡してAI社員に生成させる
3. **検品**: `07_CHECKLIST/` のリストで確認し、オーナーが承認する
4. **出力**: `03_TEMPLATES/` の形式で `05_OUTPUTS/業種/テーマID/` に保存 → 公開する
5. **学習**: 反応が良ければ `08_EXAMPLES/` に記録し、改善は `09_ARCHIVE/` に残す

## AI社員との連携

各工程は `01_AI_EMPLOYEES/` の社員が担当する。各社員の `Prompt.md` で起動し、この工場の資材を渡す。

```
Sales_AI      → テーマ決定(顧客の悩み・売れる切り口の選定)
     ↓
Copywriter_AI → 記事生成(構成・本文・LP・メルマガ・LINE)
     ↓
Designer_AI   → 画像指示(図解・サムネイル・画像生成プロンプト)
     ↓
SNS_AI        → SNS展開(X・Threads・Instagram への媒体変換)
     ↓
PM_AI         → レビュー(工程・チェックリスト完了の確認)
     ↓
CEO_AI        → 最終承認(戦略整合の確認。公開ボタンはオーナー)
```

| 工程 | 担当 | 使う資材 |
|------|------|---------|
| テーマ決定 | Sales_AI + オーナー | `01_INPUT/` |
| 競合・SEO分析 | Copywriter_AI | `06_KNOWLEDGE/seo.md` `marketing.md` |
| 構成・本文 | Copywriter_AI | `02_PROMPTS/` `00_RULES/` |
| 画像・図解 | Designer_AI | `02_PROMPTS/ImagePrompt.md` |
| 媒体変換 | SNS_AI | `02_PROMPTS/X.md` ほかSNS系 |
| レビュー | PM_AI(工程)+ 各AI(内容) | `07_CHECKLIST/` |
| 最終承認・公開 | CEO_AI → **オーナー(人間)** | — |

## 将来の拡張方法

この工場は「増築しやすさ」を優先して設計している。拡張は以下の手順で行う。

| 拡張したいもの | 手順 |
|--------------|------|
| **新しい媒体**(例:Podcast) | ①`02_PROMPTS/` にプロンプト追加 → ②`03_TEMPLATES/` に型追加 → ③`04_WORKFLOWS/` の媒体変換表に1行追加 |
| **新しい業種** | `05_OUTPUTS/` に業種フォルダ追加+`03_WEB_STUDIO/INDUSTRY_TEMPLATES/` に業種知見を追加 |
| **新しい知識** | `06_KNOWLEDGE/` にファイル追加し、関連する `00_RULES/`・`02_PROMPTS/` に反映 |
| **新しいAI社員との接続** | 社員定義(`01_AI_EMPLOYEES/`)の Workflow.md にこの工場の担当工程を追記 |
| **自動化**(2027年〜) | `05_AUTOMATION/` にスクリプト化。対象:入力→生成の一括実行、公開後の数字収集 |
| **商品化**(2028年〜) | この工場ごとテンプレート化し `06_PRODUCTS/` へ(汎用化の際は TNF 固有値を変数化) |

## 運用原則

1. **入力なしに生成しない** — `01_INPUT` が空のまま工場を動かさない
2. **検品なしに公開しない** — `07_CHECKLIST` を通らないものは世に出さない
3. **公開したら記録する** — 数字と学びを残さないコンテンツは半分無駄になる
4. **月1回、工場自体を改善する** — 改善は `09_ARCHIVE/improvement_log.md` に記録する
