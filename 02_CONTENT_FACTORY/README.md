# 02_CONTENT_FACTORY — コンテンツ制作

<!-- コンテンツ量産の工場。記事・SNS投稿・動画台本などの制作物とテンプレートを管理するフォルダ -->

ブログ記事・SNS・動画などのコンテンツを効率的に量産するための制作拠点です。

## このフォルダで管理するもの

- ブログ・記事の原稿と執筆テンプレート
- SNS投稿(X、Instagram、YouTubeなど)の企画・原稿
- 動画台本・シナリオ
- コンテンツカレンダー・企画リスト
- コンテンツ生成プロンプト集(→ `PROMPTS/`)

## フォルダ構成

| フォルダ | 内容 |
|---------|------|
| [PROMPTS/](PROMPTS/) | 媒体別のコンテンツ生成プロンプト集(note / Threads / Instagram / X / Blog / LP) |

## 制作フロー

1. `PROMPTS/` から媒体に合ったプロンプトを選ぶ
2. `{変数}` を埋めてAIに実行させ、ドラフトを生成する
3. オーナーがレビュー・修正する(AI First, Human Final)
4. 完成品はこのフォルダ配下に媒体別に保存し、資産として蓄積する
