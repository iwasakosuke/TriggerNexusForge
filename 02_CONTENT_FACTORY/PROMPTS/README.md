# PROMPTS — コンテンツ生成プロンプト集

<!-- 各媒体向けのコンテンツをAIで生成するためのプロンプト集。コピペ→変数を埋める→実行で使う -->

Trigger Nexus Forge の各媒体向けコンテンツを生成するプロンプトを管理します。

## プロンプト一覧

| ファイル | 媒体 | 生成できるもの |
|---------|------|--------------|
| [note.md](note.md) | note | 体験記事・ノウハウ記事・有料note |
| [Threads.md](Threads.md) | Threads | 単発投稿・連投・共感系ポスト |
| [Instagram.md](Instagram.md) | Instagram | フィード投稿・カルーセル(図解)・リール台本 |
| [X.md](X.md) | X(Twitter) | 単発ポスト・スレッド・図解ポスト |
| [Blog.md](Blog.md) | ブログ | SEO記事の構成・本文・リライト |
| [LP.md](LP.md) | LP | LP全体構成・セクション別コピー・改善案 |

## 使い方

1. 作りたいコンテンツの媒体ファイルを開く
2. プロンプト内の `{変数}` を埋める(共通変数は下記参照)
3. AIに貼り付けて実行し、出力をオーナーがレビューする
4. 完成品は `02_CONTENT_FACTORY/` 配下の媒体別フォルダに保存する

## 共通変数

すべてのプロンプトで使う基本情報。毎回コピペで使い回せます。

```text
{テーマ}     = 投稿・記事のテーマ(例:Claude CodeでLP制作を自動化した話)
{ターゲット} = 想定読者(例:AI活用に興味がある個人事業主)
{ゴール}     = 読後にとってほしい行動(例:プロフィールへのアクセス、問い合わせ)
{素材}       = 元ネタ・一次情報(実際の体験、数字、制作物など)
```

## 全プロンプト共通ルール(Brand.md 準拠)

各プロンプトには組み込み済みですが、独自プロンプトを作るときも必ず守ること。

- **結論から書く** / **実践ベースで語る** / **数字で示す** / **煽らない**
- NGワード:「絶対」「100%」「誰でも簡単に」「業界No.1」「AIが全部やってくれる」
- 事実でない体験・数字の捏造は禁止
- 生成物は必ず人間がレビューしてから公開する(AI First, Human Final)

## 運用ルール

- プロンプトを改善したら、該当ファイルを直接更新してコミットする(このリポジトリが常に最新版)
- 成果が良かった出力例は、各ファイル末尾の「出力例ストック」に追記して資産化する
