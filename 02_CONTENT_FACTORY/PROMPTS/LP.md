# LP(ランディングページ)生成プロンプト集

<!-- LPの構成・コピーを生成するプロンプト。LPは「1ページで1つの行動をさせる」説得の設計図 -->

## 媒体の特性(前提知識)

- LPのゴールは常に1つ(問い合わせ/購入/登録)。**1LP=1ゴール=1ターゲット**
- ファーストビュー(FV)で「自分に関係ある」と3秒で伝わらなければ離脱する
- 構成の基本形:FV → 共感(課題)→ 解決策 → ベネフィット → 実績・証拠 → 不安の解消 → CTA
- コピーは機能(何ができる)ではなくベネフィット(どう変わる)で語る
- デザインは `Brand.md` / `04_DESIGN_SYSTEM` に従う(実装は `03_WEB_STUDIO`)

## Prompt 1: LP全体構成の設計(ワイヤーフレーム前に実行)

```text
あなたはAI制作会社「Trigger Nexus Forge」のセールスコピーライターです。
LPの全体構成(ストーリー設計)を作ってください。

# 商品・サービス
{素材}(何を・いくらで・誰に提供するか)

# ターゲット
{ターゲット}(悩み・検索行動・購入の決め手まで具体的に)

# LPのゴール(1つだけ)
{ゴール}(例:無料相談の申し込み)

# 訴求の根拠になる素材
{素材}(実績・事例・お客様の声・保証など)

# 設計ルール
- 構成の型はターゲットの検討度で選ぶ:
  - 課題自覚が浅い → PASONA型(問題提起から)
  - 比較検討中 → QUEST型(絞り込みから)
- 各セクションに「読者の心理状態」と「次のセクションへ進ませる仕掛け」を書く
- CTAは3箇所(FV直下・中盤・最下部)に配置する
- 「不安の解消」セクションで想定される購入阻害要因を3つ以上潰す

# 出力形式
| # | セクション | 目的 | 読者の心理状態 | 掲載要素 |
の表形式で全セクション。最後に「このLPの勝ち筋(一言)」を添える
```

## Prompt 2: セクション別コピー執筆(構成承認後に実行)

```text
あなたはAI制作会社「Trigger Nexus Forge」のセールスコピーライターです。
承認済みのLP構成に沿って、各セクションのコピーを執筆してください。

# LP構成案
{素材}(Prompt 1 の出力を貼る)

# 商品情報・実績素材
{素材}

# 執筆ルール
- FV:キャッチコピー(15〜25字)+サブコピー(40字以内)+CTAボタン文言
  - キャッチはベネフィット(読者がどう変わるか)で書く。3案出す
- ボディ:1セクション見出し(20字以内)+本文(150字以内)。長文で説得しない
- CTAボタン:行動の心理的ハードルを下げる文言(「申し込む」→「まずは無料で相談する」)
- お客様の声・実績:提供された事実のみ使用。捏造禁止
- 価格提示:アンカリング(比較対象)→ 価格 → 価格の正当化、の順
- 「絶対」「100%」「業界No.1」等の保証・最上級表現は禁止

# 出力形式
セクションごとに:
### セクション名
- 見出し:
- 本文:
- ボタン/補足要素:
- 【画像・図解指示:○○】(Designer_AI への指示)
```

## Prompt 3: FVキャッチコピー集中改善

```text
あなたはAI制作会社「Trigger Nexus Forge」のセールスコピーライターです。
LPのファーストビューのキャッチコピーだけを集中的に作ってください。

# 商品・サービス
{素材}

# ターゲットと最も強い悩み
{ターゲット}

# ベネフィット(どう変わるか)
{素材}

# 執筆ルール
- 10案出す。型を変えて:
  ①ベネフィット直球型 ②数字型 ③Before/After型 ④問いかけ型 ⑤ターゲット呼びかけ型
  ⑥常識否定型 ⑦お悩み代弁型 ⑧限定型 ⑨実績型 ⑩ストーリー型
- 各案にサブコピー(補足40字)もセットで付ける
- 15〜25字。パッと見で意味が取れること(読み返させない)
- 誇大・断定表現は禁止。数字は事実のみ

# 出力形式
| # | 型 | キャッチコピー | サブコピー | 狙い |
最後に推奨TOP3と理由
```

## Prompt 4: LP改善診断(既存LPのCRO)

```text
あなたはAI制作会社「Trigger Nexus Forge」のセールスコピーライター兼CRO担当です。
既存のLPを診断し、改善案を出してください。

# 対象LP
{素材}(LPの全テキスト、またはURL+構成の説明)

# 現状データ(わかる範囲で)
{素材}(訪問数・CV率・離脱ポイント・流入経路など)

# 診断ルール
- 診断観点:①FVの3秒テスト ②ゴールの一貫性 ③ベネフィット訴求 ④証拠の量と質 ⑤CTA の文言と配置 ⑥不安解消の網羅性
- 改善案は「効果 × 実装の軽さ」で優先度を付ける
- 良い点も必ず挙げる(変えるべきでない箇所を明確にする)

# 出力形式
1. 診断サマリー(観点別:◎○△+一言)
2. 変えないほうがいい点
3. 改善アクション一覧(優先度順の表:箇所/問題/改善案/期待効果/実装の軽さ)
4. 最優先1件の具体的な改善後コピー
```
