# Blog 生成プロンプト集

<!-- ブログ(SEO記事)を生成するプロンプト。ブログは「検索意図への最適解」を積み上げる資産媒体 -->

## 媒体の特性(前提知識)

- 読者は**検索経由**。検索意図(なぜそのキーワードで調べたか)への回答が最優先
- E-E-A-T(経験・専門性・権威性・信頼性)。特に一次体験(Experience)が差別化になる
- 見出し(H2/H3)だけ読んでも内容がわかる構成にする
- 1記事1キーワード。欲張ると順位が付かない
- 記事は資産。公開後もリライトで育てる

---

## Prompt 1: 記事構成の設計(執筆前に必ず実行)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSEOライターです。
ブログ記事の構成案を設計してください。

# 狙うキーワード
{テーマ}(例:「Claude Code LP制作」)

# 想定読者
{ターゲット}

# 自社の一次情報(差別化素材)
{素材}(実体験・実績・独自の手順など)

# 設計ルール
- まず検索意図を3つに分解する(知りたいこと/できるようになりたいこと/比較・判断したいこと)
- 構成は「結論ファースト」:H2の1つ目で検索意図への答えを出す
- 一次体験を入れるH2を最低1つ設ける(ここが競合記事との差別化ポイント)
- 各H2に「そのセクションで読者が得るもの」を1行で定義する
- 記事のゴール(CTA)を決める:問い合わせ/関連記事/サービスページのどれか

# 出力形式
1. 検索意図の分解
2. タイトル案3つ(32文字以内、キーワードは前方に)
3. メタディスクリプション案(120字以内)
4. 構成案:
   | 見出し(H2/H3) | 内容の要点 | 読者が得るもの |
5. 記事のCTAと設置位置
```

## Prompt 2: 本文執筆(構成承認後に実行)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSEOライターです。
承認済みの構成案に沿って、ブログ記事の本文を執筆してください。

# 構成案
{素材}(Prompt 1 の出力を貼る)

# 一次情報(体験・数字)
{素材}

# 執筆ルール
- 文体:「です・ます」調。一文60文字以内。1段落3文以内
- 各H2の冒頭で、そのセクションの結論を先に書く
- 一次体験は「実際にやってみたところ〜」と体験として明示する
- 手順説明は番号付きリスト、比較は表を使う
- 画像・スクリーンショット挿入位置に【画像:○○】を置く
- 専門用語は初出時に一言補足
- 「絶対」「100%」「誰でも簡単に」等の断定・誇大表現禁止
- 数字・事実は提供された素材のみ使用。不明な点は【要確認:○○】と明示する

# 出力形式
Markdown形式の記事本文(タイトル、リード文、本文、まとめ、CTA)
```

## Prompt 3: リライト(既存記事の改善)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSEOライターです。
既存のブログ記事を分析し、リライト案を作ってください。

# 対象記事
{素材}(記事本文を貼る)

# 現状データ(わかる範囲で)
{素材}(順位・表示回数・CTR・滞在時間など)

# 分析・改善ルール
- 検索意図とのズレ、結論の遅さ、一次体験の不足、情報の古さ、の4観点で診断する
- 改善は優先度順に提示する(効果大×工数小を最優先)
- タイトル・メタディスクリプションのCTR改善案も出す
- 削るべき箇所も指摘する(足すだけがリライトではない)

# 出力形式
1. 診断結果(4観点それぞれ:問題なし/要改善+理由)
2. 改善アクション一覧(優先度順の表:箇所/問題/改善案/期待効果)
3. 新タイトル案・メタディスクリプション案
4. 書き直しが必要なセクションの改善後本文
```

## Prompt 4: 記事ネタ出し(月次の企画会議用)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコンテンツ企画担当です。
ブログの記事ネタを提案してください。

# 発信の軸
AI活用 × 一人会社経営 × 制作ノウハウ(コンテンツ制作・Web制作・自動化)

# 最近の実践・出来事
{素材}

# 既存記事(重複回避用)
{素材}(記事タイトル一覧を貼る)

# 提案ルール
- 10本提案する。それぞれ「狙うキーワード」「検索意図」「使える一次体験」をセットで
- 「今すぐ書ける度」を◎○△で付ける(一次体験が揃っているか基準)
- 検索需要だけでなく、問い合わせにつながるか(商業意図)も評価する

# 出力形式
| # | 記事タイトル案 | 狙うキーワード | 検索意図 | 使える一次体験 | 今すぐ書ける度 | 商業意図 |
```
