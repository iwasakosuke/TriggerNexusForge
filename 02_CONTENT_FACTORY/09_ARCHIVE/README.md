# 09_ARCHIVE — 記録庫

<!-- 工場の過去データと変更履歴。「なぜ今の形になったか」を辿れるようにする -->

Content Factory の**歴史**を保存します。過去データ・改善履歴・アップデート履歴の3種です。

## ファイル・フォルダ一覧

| 対象 | 内容 |
|------|------|
| [improvement_log.md](improvement_log.md) | 改善履歴 — 工場の工程・仕組みの改善記録(何を・なぜ変えたか) |
| [update_log.md](update_log.md) | アップデート履歴 — ルール・プロンプト・テンプレートの変更記録 |
| `past_data/`(必要時に作成) | 過去データ — 終了した施策・旧バージョンのファイル・古い分析 |

## 使い分け

- **improvement_log** = 工程の改善(「レビューを2段階にした」「媒体変換の順序を変えた」)
- **update_log** = 成果物の変更(「NGワードを追加した」「Xプロンプトのフック型を5→7種に」)
- **past_data/** = ファイルそのものの退避(現役フォルダから外すが、消したくないもの)

## 運用ルール

- 月1回の工場レビュー(→ 工場README「運用原則」)の結果を improvement_log に記録する
- ルール・プロンプトを変更したら、コミットと同時に update_log に1行追記する
- 「消す」判断のとき:履歴が git にあるので基本は削除でよい。ただし参照頻度が残るものは past_data/ へ
- アーカイブは倉庫であって墓場ではない。四半期の振り返りで必ず一度は開く
