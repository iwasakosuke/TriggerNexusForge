# Frameworks — 構成フレームワーク集

<!-- AIDA / PAS / QUEST / PREP など、文章構成の型の使い分け辞典 -->

## 使い分け早見表

| 型 | 流れ | 最適な用途 | 読者の状態 |
|----|------|-----------|-----------|
| **AIDA** | Attention → Interest → Desire → Action | 広告・SNS→LPの導線 | まだ何も知らない |
| **PAS** | Problem → Agitation → Solution | 短めのセールス文・LINE・広告文 | 悩みはあるが緊急性が低い |
| **PASONA** | Problem → Affinity → Solution → Offer → Narrow → Action | LP・セールスレター | 課題自覚が浅い |
| **QUEST** | Qualify → Understand → Educate → Stimulate → Transition | LP(比較検討層向け) | 解決策を探し始めている |
| **PREP** | Point → Reason → Example → Point | 主張・コラム・提案 | 論理で納得したい |
| **SDS** | Summary → Details → Summary | 報告・ノウハウ記事 | 情報を効率よく得たい |

## 各型のポイント

### AIDA(注意→興味→欲求→行動)
- 最古典。**Attentionに全体の50%の力**を注ぐ(1行目・サムネ・件名)
- Desire は機能ではなくベネフィットで作る(→ `copywriting.md` のSo What?変換)

### PAS(問題→かき立て→解決)
- 短文で効く。Agitation(かき立て)は**共感の深掘りまで**。恐怖を煽った時点でTNF失格
- 例:「LP、作ったのに問い合わせゼロ(P)。実は原稿を頑張るほど陥る罠があります(A)。◯◯を直すだけで変わります(S)」

### PASONA(新PASONA)
- Affinity(親近感)が肝。「私も同じでした」の一次体験を入れられるのがTNFの強み
- Narrow(絞込)は事実のみ(偽の限定は禁止)

### QUEST
- Qualify(絞込宣言)で「これはあなた向けの文章です」と最初に宣言する型
- 比較検討層には PASONA より QUEST(問題提起から始めると「知ってるよ」と離脱される)

### PREP
- ビジネス文書・提案の標準。CEO_AI / Sales_AI の報告フォーマットもこの型
- Example に一次体験・数字を置くと説得力が跳ね上がる

### SDS
- ノウハウ記事・報告向け。「結論ファースト」の実装形
- 詳細(D)が長くなるときは見出しで分割し、最後のSで必ず要点回収する

## 選び方(迷ったら)

1. 売る文章か? → 読者の検討度で PASONA(浅い)/ QUEST(深い)/ PAS(短文)
2. 伝える文章か? → 情報なら SDS、主張なら PREP
3. 導線の入口か? → AIDA(Attention 勝負)
