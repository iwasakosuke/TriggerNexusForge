# Writing Rules — 文章ルール

<!-- TNFの全文章に適用する文体・表記・推敲の実務ルール。検品時はこのファイルを基準にする -->

## 1. 文体の基本

| 項目 | ルール |
|------|--------|
| 基本文体 | 「です・ます」調(社内文書は「だ・である」も可) |
| 一文の長さ | 60字以内。超えたら分割する |
| 段落 | 1段落3文以内。1段落1メッセージ |
| 感嘆符 | 1コンテンツに「!」2回まで。「!!」「⁉」禁止 |
| 三点リーダ | 「…」は多用しない(自信のなさに見える) |

## 2. 構成の原則

- **結論から書く** — 前置き・自分語り・時候の挨拶で始めない
- **見出しだけで流れが分かる** — 見出しを並べて読んで意味が通るか確認する
- **1コンテンツ1ゴール** — 読後にとってほしい行動は1つに絞る

## 3. 表記ルール

### 漢字の開き(ひらがなにする)

| 開く | 例 |
|------|-----|
| 事 → こと | できること |
| 物 → もの(抽象) | 良いもの |
| 是非 → ぜひ | ぜひお試しください |
| 頂く → いただく | ご覧いただく |
| 出来る → できる | |
| 更に → さらに | |
| 沢山 → たくさん | |
| 様々 → さまざま | |

### 数字・単位

- 数字は半角(3時間、50%、12件中9件)
- 桁区切りは3桁カンマ(1,000万円)
- 日付は `YYYY-MM-DD`(文書内)/「2026年7月」(文章内)

### カタカナ語

- 定着した語のみ使用。言い換え例:ローンチ→公開/アジェンダ→議題/フィックス→確定
- 専門用語は初出時に一言補足(「CVR(成約率)」)

## 4. 冗長表現の削除(検品時の置換リスト)

| 冗長 | 修正 |
|------|------|
| することができます | できます |
| 〜という形になります | 〜です |
| 〜させていただきます | 〜します(敬意が必要な場面のみ残す) |
| 〜と思います(事実の場合) | 〜です |
| まず最初に | まず |
| 基本的には | (多くの場合削除可) |

## 5. 推敲チェックリスト(公開前に必ず)

- [ ] 結論が冒頭にあるか
- [ ] 一文60字以内・1段落3文以内か
- [ ] 音読してつかえる箇所がないか
- [ ] 同じ文末が3連続していないか(〜です。〜です。〜です。)
- [ ] 冗長表現リストの語が残っていないか
- [ ] 開き漢字ルールに従っているか
- [ ] NGワード(→ `brand_tone.md`)がないか
- [ ] 数字・事実はすべて裏が取れるか(【要確認】の残りゼロ)
