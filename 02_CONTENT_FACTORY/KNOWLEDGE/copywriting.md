# Copywriting — コピーライティングの型と原則

<!-- セールスコピー・フック・CTAの実務基準。「誠実に売る」ための技術集 -->

## 大原則

> **コピーの仕事は「買わせる」ことではなく、「必要な人に、正しく伝わる」こと。**
> 煽りで作った成約は、返金・不信・悪評で返ってくる。

## 1. 構成の型(用途で選ぶ)

| 型 | 流れ | 使いどころ |
|----|------|-----------|
| **PASONA** | 問題 → 共感 → 解決策 → 提案 → 絞込 → 行動 | 課題自覚が浅い読者(LP・セールス記事) |
| **QUEST** | 絞込 → 共感 → 啓発 → 興奮 → 行動 | 比較検討中の読者(指名検索・再訪) |
| **SDS** | 要約 → 詳細 → 要約 | 情報伝達(記事・報告) |
| **PREP** | 結論 → 理由 → 例 → 結論 | 主張の説得(コラム・提案) |

※「共感」パートで不安を煽らない。悩みの言語化までにとどめる(煽動と共感の境界)

## 2. ベネフィット変換(最重要スキル)

機能(Feature)ではなく便益(Benefit)で語る。変換の公式:

```
機能「〜ができます」
 → だから何?(So What?)を2回繰り返す
 → 便益「あなたの◯◯が、◯◯になります」
```

| 機能 | 変換後のベネフィット |
|------|---------------------|
| AIで制作します | 3日かかっていたLPが、3時間で手に入ります |
| テンプレートが50個付属 | 明日から「何を書くか」で迷う時間がなくなります |
| 修正2回無料 | 「思ってたのと違う」があっても、追加費用の心配がいりません |

## 3. フックの型(1行目の技術)

| 型 | 例 | 注意 |
|----|-----|------|
| 数字型 | 「LP制作、3日→3時間になりました」 | 数字は事実のみ |
| 逆説型 | 「デザインの勉強、やめました」 | 本文で回収できる逆説だけ |
| 失敗告白型 | 「初案件、正直かなり失敗しました」 | 学びとセットで |
| Before/After型 | 「先月:問い合わせ0件 → 今月:5件」 | 再現条件も書く |
| 問いかけ型 | 「あなたのLP、3秒で閉じられていませんか」 | 責める口調にしない |

## 4. CTAの設計

- **行動ハードルを下げる動詞にする**: 「申し込む」→「まずは無料で相談する」/「購入」→「内容を見てみる」
- **CTA直下に不安解消を1行**: 「しつこい営業はしません」「相談だけでもOKです」
- **1コンテンツ1CTA**: 選択肢を並べるほど行動率は下がる

## 5. 心理原則の使用基準(誠実ラインの明文化)

| 原則 | 使ってよい形 | 禁止の形 |
|------|-------------|---------|
| 社会的証明 | 実際の利用者の声・実数 | 捏造レビュー・水増し数字 |
| 希少性 | 事実の期限・定員の明示 | 偽カウントダウン・常設の「今だけ」 |
| 権威性 | 実績・経歴の事実 | 誇張肩書き・根拠なきNo.1 |
| 損失回避 | 現状維持のコストを事実で示す | 恐怖・不安を人質に取る表現 |

## 検品チェックリスト(コピー公開前)

- [ ] ベネフィットで書かれているか(機能の羅列になっていないか)
- [ ] ターゲットを1人に絞れているか(全員向けになっていないか)
- [ ] フックは本文で回収されているか(釣りタイトルになっていないか)
- [ ] CTAは1つか・動詞のハードルは低いか
- [ ] 心理原則の使用は「誠実ライン」の内側か
- [ ] NGワード(→ `brand_tone.md`)ゼロか
