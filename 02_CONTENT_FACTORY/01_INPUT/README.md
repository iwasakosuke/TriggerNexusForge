# 01_INPUT — 入力

<!-- 工場の投入口。ここで書いた1枚がすべての生成の源泉になる。入力の質=全アウトプットの質 -->

Content Factory への**入力(発注書)**を管理します。

> **入力なしに生成しない。** 曖昧な入力で工場を動かすと、10媒体分の無駄が生まれる。

## ファイル一覧

| ファイル | 内容 |
|---------|------|
| [input_template.md](input_template.md) | 入力テンプレート(テーマ・ターゲット・悩み・目的・媒体・CTA・検索キーワード) |

## 使い方

1. `input_template.md` をコピーする
2. `05_OUTPUTS/業種/テーマID/_input.md` として保存し、記入する
3. 記入済みシートを各AI社員・各プロンプトに「素材」として渡す

## 入力の品質基準

- **一次体験が書けないテーマは投入しない**(借り物の知識は工場の原材料にならない)
- **ターゲットは「1人の人物」まで絞る**(属性ではなく、悩みを持つ具体的な誰か)
- **目的は1つ**(認知もCVも、は両方失敗する)

## 担当

- 記入: オーナー(+ Sales_AI:顧客の悩み・売れる切り口の観点で補強)
- テーマ選定に迷ったら: Sales_AI に「今どの悩みが商談で多いか」を聞く
