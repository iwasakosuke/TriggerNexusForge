# Prohibitions — 禁止事項(全媒体共通)

<!-- Content Factory の絶対NG集。1つでも該当したら公開不可。検品の最初にここを通す -->

## レベル1: 絶対禁止(即差し戻し・例外なし)

| # | 禁止事項 | 理由 |
|---|---------|------|
| 1 | 事実でない数字・実績・体験談の使用 | 信頼は一度失うと戻らない |
| 2 | やっていないことを「やってみた」と書く | 実践者ブランドの根幹を破壊する |
| 3 | 他者コンテンツの盗用・剽窃 | 法的リスク+ブランド毀損 |
| 4 | クライアント情報の無許可使用 | 契約違反・信頼破壊 |
| 5 | オーナー承認なしの公開 | AI First, Human Final の根幹 |

## レベル2: NGワード(置換必須)

| NGワード | 代替 |
|---------|------|
| 絶対/100%/必ず〜できる | 「〜のケースでは」「私の場合は」 |
| 誰でも簡単に | 「◯◯の手順でできます(所要◯時間)」 |
| 業界No.1/日本一/最高品質 | 具体的な実績数字 |
| AIが全部やってくれる | 「AIが下書きし、人間が仕上げる」 |
| 今だけ/残りわずか(事実でない) | 事実の場合のみ期限・数量明記 |
| 月◯万円稼げます(断定) | 実例+「個人の結果です」 |

## レベル3: NG表現・NG行動

- ❌ 恐怖・不安を人質に取る訴求(「やらないと手遅れ」)
- ❌ 他者・競合への批判、対立を煽る構図
- ❌ 炎上狙いの逆張り
- ❌ 誇大なビフォーアフター(再現条件を書かない変化訴求)
- ❌ 買いフォロワー・相互フォロー等の数字の偽装
- ❌ ステルスマーケティング(PR・案件は必ず明示)

## 業種別の上乗せ規制(クライアント案件時)

| 業種 | 注意 |
|------|------|
| 美容・健康 | 薬機法:効果効能の断定禁止(「治る」「痩せる」) |
| 全業種 | 景表法:優良誤認・有利誤認(根拠なき優位性表示) |
| 士業 | 各士業法の広告規制・業際 |
| 金融・投資系 | 原則受けない(規制が重く専門外) |

## 迷ったときの原則

> **「掲載してよいか迷う」時点で、掲載しない側に倒す。**
> 機会損失は取り返せるが、信頼の損失は取り返せない。
