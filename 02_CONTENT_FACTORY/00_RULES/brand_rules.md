# Brand Tone — ブランドトーン運用基準

<!-- Brand.md のトーン&マナーをコンテンツ制作の実務に落としたもの。全AI社員の共通検品基準 -->

正典は `00_COMPANY/Brand.md`。このファイルは制作現場向けの運用版(矛盾したら Brand.md が勝つ)。

## ボイスの核:「一歩先を行く実践者」

- 先生ではない(教えを説かない)/評論家ではない(外から論評しない)
- **半歩〜一歩先で、実際にやっている人**として語る
- 読者との関係は「先輩と後輩」ではなく「少し先を歩く同志」

## 4原則(全コンテンツ共通)

| 原則 | OK | NG |
|------|-----|-----|
| 結論から書く | 「LP制作が3時間になりました。手順は3つです」 | 「今日はみなさんに伝えたいことがあって…」 |
| 実践ベース | 「やってみた結果、◯◯でした」 | 「〜らしいです」「〜と言われています」 |
| 数字で示す | 「12件中9件で効果がありました」 | 「多くのケースで効果があります」 |
| 煽らない | 「私の場合は3ヶ月かかりました」 | 「やらないと確実に損します」 |

## NGワード(検品で機械的に弾く)

| NGワード | 代替 |
|---------|------|
| 絶対/100%/必ず〜できる | 「〜のケースでは」「私の場合は」 |
| 誰でも簡単に | 「◯◯の手順でできます(所要◯時間)」 |
| 業界No.1/最高品質 | 具体的な実績数字 |
| AIが全部やってくれる | 「AIが下書きし、人間が仕上げる」 |
| 今だけ/残りわずか(事実でない) | 事実の場合のみ期限・数量を明記 |
| 稼げる系の断定(月◯万円稼げます) | 実例+「個人の結果です」の域を守る |

## 媒体別トーン調整表

同じボイスのまま、媒体ごとに「温度」だけ変える。

| 媒体 | 温度感 | 一人称・文体 | 絵文字 |
|------|--------|-------------|--------|
| Blog | 落ち着いた実務者 | です・ます、丁寧 | 使わない |
| note | 少し内面も見せる | です・ます、体温高め | 使わない |
| X | テンポの良い実践者 | 常体まじりOK、体言止めOK | 3つまで |
| Threads | 素の独り言に近い | 話し言葉(「〜なんですよね」) | 3つまで |
| Instagram | 丁寧で親しみやすい | です・ます、短文 | 3つまで |
| LP・提案書 | 信頼できる専門家 | です・ます、断定は事実のみ | 使わない |

## トーンのセルフテスト(迷ったら)

1. **実践者テスト**: この文は「やった人」にしか書けないか?(誰でも書ける一般論なら削る)
2. **同志テスト**: 読者を見下ろしていないか?(「〜すべき」が多いなら書き直し)
3. **誠実テスト**: この約束は、全読者に対して守れるか?(守れないなら表現を弱める)
4. **翌朝テスト**: 明日読み返して恥ずかしくないか?(勢いだけの文章の検知)
