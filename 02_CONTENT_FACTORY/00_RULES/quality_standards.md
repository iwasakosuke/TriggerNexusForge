# Quality Standards — 品質基準

<!-- 「公開してよい品質」の定義。感覚ではなく基準で判定する -->

## 品質の定義

> **TNFの品質 = 読者の時間に対して、確実にお釣りが返ってくること。**

「よく書けている」ではなく「読んだ人が得をする」が基準。

## 公開可能ラインの3条件(すべて必須)

| 条件 | 判定質問 |
|------|---------|
| **価値** | 読者は読了後、読む前より何か得をしているか?(学び・共感・行動の材料) |
| **誠実** | すべての事実・数字に裏が取れるか? 約束は守れる範囲か? |
| **らしさ** | 「一歩先を行く実践者」の声に聞こえるか?(→ `brand_rules.md`) |

## 媒体別の合格基準

| 媒体 | 合格基準 |
|------|---------|
| Blog | 検索意図に答えている+一次体験がある+SEOルール完走 |
| note | 読み物として最後まで読める+学びが最低1つ言語化されている |
| X・Threads | 1行目で止まる+その媒体の型(140字/問いかけ終わり)に合致 |
| Instagram | 表紙で内容が予想できる+保存する理由がある |
| LP | FVの3秒テスト通過+全セクションが1ゴールに向かっている |
| LINE・メルマガ | 開封の理由(件名)と読了の価値が両方ある |

## 品質のグレード(使い分け)

| グレード | 基準 | 適用 |
|---------|------|------|
| S: 代表作 | 実例集(08_EXAMPLES)に載せたい水準 | LP・有料note・ポートフォリオ |
| A: 標準 | 公開可能ライン+媒体別基準クリア | 通常のすべての公開物 |
| B: 実験 | 公開可能ラインのみクリア | 検証目的の投稿(仮説検証を明記) |
| 不合格 | 3条件のどれかを満たさない | 公開しない。差し戻し |

※B(実験)を言い訳にしない。3条件を下回るものはグレード外=非公開。

## 品質と速度のバランス

- **完了 > 完璧**(Mission.md Value 3)— ただし「公開可能ライン」より下は完了と呼ばない
- 磨く時間の上限を決める(タイムボックス)。上限が来たら「今の最善」で判定に出す
- 品質を上げる王道は推敲時間ではなく、**一次体験の濃さ**(入力の質)である

## 判定プロセス

1. 各媒体チェックリスト(`07_CHECKLIST/`)を通す
2. 3条件で判定(1つでも×なら差し戻し)
3. グレードを付けて `03_TEMPLATES` のメタ情報に記録
4. S判定が出たら `08_EXAMPLES/` に記録する
