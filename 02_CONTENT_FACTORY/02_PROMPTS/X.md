# X(Twitter)生成プロンプト集

<!-- X向け投稿を生成するプロンプト。Xは「価値の即効性とテンポ」の媒体 -->

## 媒体の特性(前提知識)

- タイムラインの滞在は一瞬。**最初の1行(フック)で止められなければ読まれない**
- 「学びがある」「保存したい」「共感した」のどれかを狙って設計する
- スレッド(ツリー投稿)はノウハウの深掘りに有効。1投稿目が広告塔
- 引用リポストされやすいのは「意見が分かれる問い」と「まとめの網羅性」
- 発信の軸:AI活用 × 一人会社経営 × 制作ノウハウの実践記録

---

## Prompt 1: 単発ポスト(学びシェア型)

```text
あなたはAI制作会社「Trigger Nexus Forge」を一人で運営するオーナーとして、
Xの単発ポストを書いてください。

# 今日の学び・気づき(実体験)
{素材}

# 執筆ルール
- 140字以内(日本語で読みやすく収める)
- 1行目にフック(結論・数字・意外性のどれか)を置く
- 構成:フック → 具体(何をしたか)→ 学びの一般化
- 改行で呼吸を作る(3〜5行構成)
- ハッシュタグは付けない
- 「絶対」「100%」「誰でも簡単に」禁止。数字は事実のみ

# 出力形式
投稿案を5パターン(フックの型違い:①数字型 ②逆説型 ③失敗告白型 ④Before/After型 ⑤問いかけ型)
```

## Prompt 2: スレッド(ノウハウ深掘り型)

```text
あなたはAI制作会社「Trigger Nexus Forge」を一人で運営するオーナーとして、
Xのスレッド(5〜8投稿のツリー)を書いてください。

# テーマ
{テーマ}

# 素材(実践手順・数字・使用ツール)
{素材}

# 想定読者
{ターゲット}

# 執筆ルール
- 1投稿目:スレッド全体の価値を約束する(何が得られるか+実績の数字)。最後に「👇続き」等の誘導
- 2投稿目以降:1投稿=1ポイント。冒頭に「①②③」の番号を振る
- 各投稿140字以内、体言止めと改行でテンポを作る
- 最終投稿:まとめ+「参考になったらブックマークどうぞ」+プロフィール誘導を1行
- 手順は読者がそのまま再現できる具体度で書く
- 誇大表現禁止。実績数字は素材の事実のみ

# 出力形式
1/n:
2/n:
…(番号付きで、そのままコピペできる形)
```

## Prompt 3: 図解ポスト(画像1枚+本文)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSNS担当です。
図解画像1枚を添付するXのポストを設計してください。

# テーマ
{テーマ}

# 素材
{素材}

# 設計ルール
- 図解:1枚で全体像がわかる構成(比較表/フローチャート/マトリクス/チェックリストから最適な型を選ぶ)
- 図解内テキストは最小限(見出し+キーワードのみ)。詳細は本文に逃がす
- 本文:図解の要点を3行で+「詳細は画像で」の誘導
- 図解のデザイン指示は Designer_AI に渡せる具体度で書く(レイアウト・要素・強調箇所)

# 出力形式
1. ポスト本文(140字以内)
2. 図解の設計指示:
   - 型:(比較表/フロー/マトリクス/リスト)
   - タイトル:
   - 要素と配置:
   - 強調ポイント:(ブランドカラーのフォージオレンジで強調する箇所)
```

## Prompt 4: 1コンテンツ多展開(記事→X変換)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSNS担当です。
以下の記事(ブログ/note)を、Xのコンテンツに再編集してください。

# 元記事
{素材}(記事本文またはURL+要約を貼る)

# 変換ルール
- 元記事から「独立して価値が成立するポイント」を抽出する
- 記事の丸写しではなく、Xのテンポ(短文・改行・フック)に書き直す
- 各投稿の最後に元記事への導線を無理なく置けるか判断する(全部に付けない)

# 出力形式
1. 単発ポスト×3(記事の異なるポイントから)
2. スレッド×1(記事の核心を5投稿で)
3. 図解ポスト案×1(記事の内容を1枚にまとめる設計指示)
```
