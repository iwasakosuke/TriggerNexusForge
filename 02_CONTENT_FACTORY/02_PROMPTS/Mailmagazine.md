# メルマガ 生成プロンプト集

<!-- メールマガジンの生成プロンプト。メルマガは「開封させてから、じっくり読ませる」媒体 -->

## 媒体の特性(前提知識)

- 勝負は2段階:**件名で開封させる → 本文で読了させる**。件名が5割
- LINEより長文が許される(800〜1,500字)。「読み物」として成立させる
- 読者は受信箱で他の数十通と並んでいる。件名は「自分に関係ある」が3秒で分かること
- 配信解除は健全な代謝。解除を恐れて当たり障りなくする方が致命的

---

## Prompt 1: 通常号(コラム型)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
メルマガの1通を書いてください。

# 入力
【テーマ・素材】{素材}(01_INPUT の入力シートを貼る)
【読者】{ターゲット}
【CTA】{ゴール}

# 執筆ルール
- 件名:15〜25字。具体・数字・自分事化のどれかで開封理由を作る。釣らない
- 構成:フック(1〜2行)→ 本題(一次体験ベースの学び)→ まとめ → CTA → 追伸
- 800〜1,200字。1段落3行以内、適度な空行でスマホの可読性を確保
- トーン:読者1人に宛てた手紙(「皆さん」ではなく「あなた」)
- 追伸(P.S.)を必ず付ける(意外と読まれる位置。近況や次回予告に使う)

# 出力形式
1. 件名3案(それぞれ狙い付き)+プリヘッダー文
2. 本文
3. CTA文言
```

## Prompt 2: セールス号(商品案内型)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
商品・サービスを案内するメルマガを書いてください。

# 入力
【商品・オファー】{素材}
【読者の悩み】{ターゲット}
【実績・事例】{素材}

# 執筆ルール
- 構成はPASONA(問題→共感→解決策→提案→絞込→行動)。ただし「煽らない共感」まで
- セールス号でも冒頭に小さな学びを置く(いきなり売り始めない)
- 価格・期限・条件は明記(クリック後のがっかりを作らない)
- 1,000〜1,500字。CTAリンクは本文中に2箇所(中盤・末尾)

# 出力形式
件名3案 → 本文 → CTA文言
```

## Prompt 3: 記事→メルマガ変換(多展開用)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
以下の記事をメルマガ向けに再編集してください。

# 入力
【元記事】{素材}(Blog/note の本文を貼る)

# 変換ルール
- 丸写し禁止。メルマガは「手紙」なので、記事より個人的な語りに変える
- 記事の要点1つに絞り、深掘りは記事へのリンクで誘導する
- 記事にない「舞台裏・本音」を1つ加える(メルマガ読者だけの特典感)
- 800字以内

# 出力形式
件名3案 → 本文(記事リンク誘導込み)
```
