# note 生成プロンプト集

<!-- note向け記事を生成するプロンプト。noteは「体験と学びのストーリー」が読まれる媒体 -->

## 媒体の特性(前提知識)

- 読者は検索ではなく**フォロー・おすすめ経由**で来る。SEOよりも「読み物としての面白さ」が重要
- 一次体験・失敗談・プロセスの公開が最も好まれる
- タイトルと冒頭3行で読むかが決まる。「スキ」されやすいのは共感と学びのセット
- 有料noteは「再現手順の具体性」が価値になる

---

## Prompt 1: 体験記事(実践レポート型)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
一人でAI社員チームを率いて制作会社を運営する実践者として、noteの記事を書いてください。

# テーマ
{テーマ}

# 素材(実際の体験・数字)
{素材}

# 想定読者
{ターゲット}

# 執筆ルール
- 構成:①結論と数字を先に見せる導入 → ②やったことの時系列 → ③つまずきと対処 → ④学びの一般化 → ⑤読者への次の一歩
- 文体:「です・ます」調。一文は60文字以内。見出しごとに1つの具体例を入れる
- 一次体験として語る(「〜らしい」ではなく「やってみた結果」)
- 数字は素材にあるものだけを使い、捏造しない
- 数字・比率は素材に明記されているものだけを使う。計算・推測で新しい数字(割合など)を作らない(例:件数から割合を合成しない)
- このテーマの素材(入力シート)以外の事実は使わない。似た話でも他のテーマ・他の案件の数字を混ぜない
- 煽らない。「絶対」「100%」「誰でも簡単に」は使用禁止
- 文字数:2,000〜3,000字

# 出力形式
1. タイトル案を3つ(それぞれ狙いを一言添える)
2. 記事本文(Markdown、見出しはH2/H3)
3. 記事末尾に置くCTA文(プロフィール・サービスへの自然な誘導)
```

## Prompt 2: ノウハウ記事(手順解説型)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
実践者として、読者が再現できるノウハウnoteを書いてください。

# テーマ
{テーマ}

# 素材(実際の手順・使ったツール・かかった時間)
{素材}

# 想定読者
{ターゲット}(前提知識レベル:初心者/中級者 から選択して指定)

# 執筆ルール
- 冒頭で「この記事でできるようになること」と「所要時間」を明示する
- 手順は番号付きリストで、1ステップ=1アクションに分解する
- 各ステップに「つまずきポイント」の注意書きを入れる
- スクリーンショットを入れるべき箇所に【画像:○○】とプレースホルダを置く
- 専門用語は初出時に一言で補足する
- 文字数:2,500〜4,000字

# 出力形式
1. タイトル案3つ
2. 記事本文(Markdown)
3. この記事から派生できる次の記事ネタ3つ
```

## Prompt 3: 有料note(商品化用)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライター兼営業担当です。
販売用の有料noteの「無料部分」と「有料部分の構成」を設計してください。

# 商品テーマ
{テーマ}

# 提供できる価値(実績・素材)
{素材}

# 想定購入者
{ターゲット}

# 価格帯
{価格}(例:980円)

# 設計ルール
- 無料部分:読者の課題への共感 → 解決後の姿 → 有料部分の目次と得られるもの → 購入の後押し、の順
- 「買わない理由」を先回りして潰す(返金不安、再現性への疑問、レベル感の不一致)
- 有料部分の構成は、章ごとに「読者ができるようになること」を1行で定義する
- 誇大表現禁止。実績は事実のみ。「稼げる」系の断定は使わない

# 出力形式
1. 商品タイトル案3つ(価格に見合う具体性を持たせる)
2. 無料部分の本文(1,000〜1,500字)
3. 有料部分の章構成(章タイトル+各章のゴール)
4. 販売開始時の告知文(note/SNS用、3パターン)
```
