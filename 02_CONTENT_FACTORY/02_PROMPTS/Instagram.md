# Instagram 生成プロンプト集

<!-- Instagram向けコンテンツを生成するプロンプト。Instagramは「保存される図解と世界観」の媒体 -->

## 媒体の特性(前提知識)

- 重要指標は**保存率**。「あとで見返したい」と思われるまとめ・図解が強い
- カルーセル(複数枚画像)はノウハウ系と相性が良い。1枚目の表紙で9割決まる
- リールは冒頭1秒のフックと、テンポの良い展開が命
- キャプションは1行目しか表示されない → 1行目に結論かフックを置く
- デザインは `04_DESIGN_SYSTEM` のテンプレート・ブランドカラーに従う

---

## Prompt 1: カルーセル投稿(図解ノウハウ型)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSNS担当兼デザイナーです。
Instagramのカルーセル投稿(8〜10枚)の構成案を作ってください。

# テーマ
{テーマ}

# 素材(実践内容・数字)
{素材}

# 想定読者
{ターゲット}

# 設計ルール
- 1枚目(表紙):13文字以内のタイトル+補足1行。「保存したくなる網羅感」を予感させる
- 2枚目:この投稿で得られることの一覧(目次)
- 3〜8枚目:1枚1メッセージ。見出し(15字以内)+本文(50字以内)+図解の指示
- 9枚目:まとめ(全体の要点を1枚に集約)
- 10枚目:CTA(保存の呼びかけ+プロフィール誘導)
- 各枚に【図解イメージ:○○】としてデザイナーへの指示を書く
- 煽り・誇大表現禁止

# 出力形式
| 枚数 | 見出し | 本文 | 図解イメージ |
|------|--------|------|-------------|
の表形式で全枚数分。その後にキャプション文(下記ルール)も出力:
- 1行目:フックまたは結論
- 本文:投稿の要約+ひとこと体験談(300字以内)
- ハッシュタグ:ビッグ3つ+ミドル4つ+スモール3つ(計10個)
```

## Prompt 2: リール台本(30秒ノウハウ型)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSNS担当です。
30秒のInstagramリール台本を書いてください。

# テーマ
{テーマ}

# 素材(実践内容・ビフォーアフターの数字)
{素材}

# 台本ルール
- 冒頭1秒:結果 or 意外性のフック(例:「LP制作、3日かかってたのが3時間になりました」)
- 展開:ステップを3つまでに絞る。1ステップ5秒以内
- 終わり:要約1行+「保存してあとで試してみて」
- テロップは1画面15文字以内
- 数字は素材の事実のみ。「誰でも」「絶対」禁止

# 出力形式
| 秒数 | 映像(画面に映すもの) | テロップ | ナレーション/セリフ |
|------|---------------------|---------|-------------------|
の表形式。その後にキャプション文+ハッシュタグ10個も出力
```

## Prompt 3: フィード単発投稿(実績・制作物紹介型)

```text
あなたはAI制作会社「Trigger Nexus Forge」のSNS担当です。
制作実績・制作物を紹介するInstagramフィード投稿を作ってください。

# 紹介する制作物
{素材}(何を・誰のために・どんな工夫で作ったか)

# 設計ルール
- 画像:ビフォーアフター or 制作物のキービジュアル(【画像指示:○○】で指定)
- キャプション構成:
  1行目:制作物の一言紹介(結論)
  本文:制作の背景 → こだわった点(2つまで)→ 使用ツール・制作時間
  締め:「制作のご相談はプロフィールのリンクから」(自然に、控えめに)
- クライアント案件の場合は「公開許可の確認」を注意書きとして必ず添える
- 300字以内

# 出力形式
1. 画像指示(1〜3枚分)
2. キャプション文
3. ハッシュタグ10個
```
