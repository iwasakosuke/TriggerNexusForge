# 動画台本 生成プロンプト集

<!-- YouTube・リール・ショート動画の台本を生成するプロンプト -->

## 媒体の特性(前提知識)

- **ショート(リール・YouTube Shorts)**: 冒頭1秒が命。30〜60秒。テンポ最優先
- **YouTube(横型・長尺)**: 冒頭30秒で「この動画で得られるもの」を約束。8〜15分
- 台本は「読む文章」ではなく「話す言葉」で書く(一文を短く、口語で)
- 視聴維持率が命。「次が気になる」接続を各パートの終わりに置く

---

## Prompt 1: ショート動画台本(30〜60秒)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
ショート動画(リール/YouTube Shorts)の台本を書いてください。

# 入力
【テーマ・素材】{素材}(01_INPUT の入力シートを貼る)
【尺】30秒 / 60秒
【CTA】{ゴール}

# 台本ルール
- 冒頭1秒:結果 or 意外性のフック(例:「LP制作、3時間になりました」)
- 展開:ポイントは3つまで。1ポイント5〜10秒
- 終わり:要約1行+CTA(「保存してあとで試して」等の軽いもの)
- テロップは1画面15文字以内
- 話し言葉で書く(「〜です。で、ここからが本題なんですが」)
- 数字・事実は素材のみ。「誰でも」「絶対」禁止

# 出力形式
| 秒数 | 映像・画面 | テロップ | セリフ(話し言葉) |
の表形式+サムネイル用の一言(13字以内)
```

## Prompt 2: YouTube長尺台本(8〜15分)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
YouTube動画(横型・長尺)の台本を書いてください。

# 入力
【テーマ・素材】{素材}
【想定視聴者】{ターゲット}
【CTA】{ゴール}

# 台本ルール
- 構成:フック(15秒)→ この動画の約束(30秒)→ 本編(3〜5チャプター)→ まとめ → CTA
- 各チャプターの終わりに「次への接続」を1行入れる(視聴維持)
- 本編は一次体験ベース(画面共有・実演できる箇所を【画面:◯◯】で指定)
- 台本は一言一句ではなく「話す内容+キーフレーズ」レベルで(棒読み防止)
- 冒頭で結論を出し惜しみしない(隠すと離脱される)

# 出力形式
1. タイトル案3つ(釣らない・32字以内)
2. サムネイル文言案(13字以内)+構図メモ
3. 台本(チャプター見出し+話す内容+画面指定)
4. 概要欄テキスト(要約+CTAリンク+チャプター)
```

## Prompt 3: 記事→動画台本変換(多展開用)

```text
あなたはAI制作会社「Trigger Nexus Forge」のコピーライターです。
以下の記事を動画台本に変換してください。

# 入力
【元記事】{素材}(Blog/note の本文)
【形式】ショート / 長尺

# 変換ルール
- 記事の朗読にしない。「話し言葉への翻訳」+「見せられるものは見せる」に再設計
- ショートなら記事の1ポイントだけに絞る(全部入れない)
- 長尺なら記事の構成を活かしつつ、実演パート(画面共有)を追加する
- 記事への誘導を概要欄CTAに設定する

# 出力形式
Prompt 1 または 2 と同じ形式
```
