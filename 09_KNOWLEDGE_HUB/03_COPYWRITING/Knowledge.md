# COPYWRITING Knowledge(要点版)

## 1枚で思い出す要点

1. **コピーの仕事は「必要な人に、正しく伝わる」こと**(買わせることではない)
2. **ベネフィットで書く** — 機能→「So What?」を2回→変化(3日が3時間になる)
3. **ターゲットは1人** — 全員向けは誰にも刺さらない
4. **フックは結論で引く** — 隠して引くのは釣り。回収できる約束だけする
5. **CTAは1つ・低いハードルの動詞** — 「まずは無料で相談する」
6. **心理原則は誠実ラインの内側で** — 事実の希少性○、偽カウントダウン×

## 型の選び方(早見)

- 売る:検討浅い→PASONA / 検討深い→QUEST / 短文→PAS
- 伝える:情報→SDS / 主張→PREP / 導線入口→AIDA
