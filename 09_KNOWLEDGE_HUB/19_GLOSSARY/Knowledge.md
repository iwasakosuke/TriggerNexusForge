# GLOSSARY — 用語集本体

## TNF固有用語

| 用語 | 定義 |
|------|------|
| 一人AI会社 | オーナー1名+AI社員チームで運営する会社形態。TNFのコアコンセプト |
| 会社OS | このリポジトリ全体。経営文書からテンプレートまでの運営システム |
| AI社員 | 役割・知識・ルールを定義したAIエージェント(01_AI_EMPLOYEES) |
| AI First, Human Final | 作業はAI、公開・納品・約束の最終判断は人間、の原則 |
| 一次体験 | 自分で実際にやった経験。TNFの全コンテンツの原材料 |
| 軸コンテンツ | 1テーマの中心になる長文(Blog/note/LP)。派生の切り出し元 |
| 多展開 | 軸コンテンツを複数媒体へ変換すること(1テーマ→10媒体) |
| 静かな熱 | TNFのデザイン世界観(鋼の精密さ×炉の熱×工房の手触り) |
| 2回ルール | 同じ作業が2回発生したら3回目の前に仕組み化を検討する原則 |
| 検品 | 公開前の品質チェック(07_CHECKLIST を通すこと) |
| S級 | 実例集(08_EXAMPLES)に載せる水準の成果物 |

## 業務用語(制作・マーケ)

| 用語 | 定義 |
|------|------|
| FV(ファーストビュー) | ページを開いて最初に見える領域。3秒テストの対象 |
| CTA | Call To Action。読者にさせたい行動とそのボタン・文言 |
| CV / CVR | コンバージョン(成果地点到達)/ その率 |
| LP | ランディングページ。1ページ=1ゴールの説得ページ |
| リード | 見込み客。営業パイプラインの入口 |
| MRR | 月次経常収益。継続契約の月額合計 |
| LTV | 顧客生涯価値。1顧客が取引全体でもたらす利益 |
| スコープ | 契約に含まれる作業範囲。文書化が正 |
| スコープクリープ | 「ついでに」の積み重ねで範囲が膨らむこと |
| 検索意図 | キーワードの裏にある目的(Know/Do/Buy) |
| E-E-A-T | 経験・専門性・権威性・信頼性。Googleの品質観点 |
| ベネフィット | 機能がもたらす「読者の変化」。機能(Feature)と区別する |
| フック | 最初の1行・1秒。読み進める理由を作る装置 |
| デザイントークン | 色・余白等の設計値をCSS変数化したもの(tokens.css) |
| BEM | CSS命名規則(Block__Element--Modifier) |

## 用語の追加方法

新しい用語が2回以上会話・文書に登場したら、定義を1行で書いてここに追加する。
