# CLAUDE BestPractice

## ✅ Do

- 1セッション1タスク(役割の混線を避ける。営業文と記事執筆を同居させない)
- 長文生成は「構成→承認→本文」の2段階で依頼する
- 出力形式を先に見せる(テンプレートを貼ってから依頼)
- 疑問点は書き始める前に質問させる(Prompt.md の起動時動作に組込済み)
- リポジトリ変更は Claude Code に任せ、コミットメッセージまで書かせる

## ❌ Don't

- 会社の前提を毎回口頭説明する(CLAUDE.md・Prompt.mdに書く)
- 1つの会話でAI社員を何役も切り替える
- 検品なしで別のAIの出力を「事実」として渡す(伝言ゲームでの捏造増幅)
- 古いセッションの結論を、根拠ごと確認せずに引用する
