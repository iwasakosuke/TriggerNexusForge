# CLAUDE Knowledge — TNFでのClaude活用

## TNFでの位置づけ

- Claude は TNF の**主力AIエンジン**。AI社員(01_AI_EMPLOYEES)は Claude 上で起動する設計
- 使い分け:対話・執筆・レビュー=Claude チャット/リポジトリ作業=Claude Code

## CLAUDE.md の仕組み(重要)

- リポジトリ直下や各フォルダの `CLAUDE.md` は、Claude Code が自動で読み込む指示書
- TNFでは `00_COMPANY/CLAUDE.md` に会社の前提・ルールを集約している
- 新しい恒常ルールができたら、口頭で繰り返すのではなく CLAUDE.md に追記する

## AI社員の起動方法(標準手順)

```
1. 01_AI_EMPLOYEES/◯◯_AI/Prompt.md のシステムプロンプトを貼る
2. 該当する Knowledge Hub ドメインのファイルを添付する
3. 依頼テンプレート(各Prompt.md内)で仕事を渡す
4. 出力は Workflow.md の形式で受け取り、Rules.md で検品する
```

## コンテキスト(文脈)管理の知識

- 長い会話ほど初期の指示が薄れる → 長仕事はセッションを分け、要点を引き継ぐ
- 大事な制約は会話の冒頭か直近で再提示する
- 「この会話の結論を3行で」と要約させてから次セッションに渡すと劣化が少ない

## プロジェクト運用のコツ

- 定型業務ごとに「起動プロンプト+参照ファイル」のセットを固定する(=AI社員制度そのもの)
- Claude Code にはタスクを「完了定義つき」で渡す(「いい感じにして」を避ける)
