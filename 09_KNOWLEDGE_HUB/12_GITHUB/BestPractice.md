# GITHUB BestPractice

## ✅ Do

- 作業前に現在のブランチを確認する(git status を癖にする)
- ファイル移動は git mv(履歴が繋がる)
- 大きな再構築は、動く状態ごとにこまめにコミットする
- README・ドキュメントの更新を変更と同じコミットに含める
- .gitignore で生成物・一時ファイルを最初から除外する

## ❌ Don't

- main への直接の実験的変更
- 「fix」「update」だけのコミットメッセージ
- 認証情報・APIキー・顧客データのコミット(発生したら即ローテーション)
- コンフリクトの中身を理解せずに片方を捨てる
- 巨大バイナリ(動画・PSD等)の安易なコミット(必要なら保存場所を分ける)
