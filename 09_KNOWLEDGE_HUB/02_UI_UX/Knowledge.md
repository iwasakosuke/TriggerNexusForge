# UI/UX Knowledge

## UXの大原則

> **ユーザーは読まない、考えたくない、待たない。**
> 優れたUIは「説明が要らないUI」。考えさせた時点で負け(Don't Make Me Think)。

## ユーザビリティ10原則(ニールセンの要約+TNF実装)

| 原則 | TNFでの実装 |
|------|------------|
| 状態の可視化 | 送信中・読込中・完了を必ず表示する |
| 現実世界との一致 | 業界用語ではなくユーザーの言葉でラベルを書く |
| ユーザーの主導権 | 戻れる・やり直せる。行き止まりを作らない |
| 一貫性 | 同じ操作は同じ見た目・同じ場所(→ 反復の原則) |
| エラーの予防 | 入力例の提示・確認画面。エラーを出す前に防ぐ |
| 再認 > 想起 | 覚えさせない。選択肢を見せる |
| 効率性 | 主要動線は3タップ以内 |
| ミニマリズム | 1画面1目的。装飾的情報を足さない |
| エラー回復 | 「何が・どうすれば直るか」を平文で(コードだけ出さない) |
| ヘルプ | そもそもヘルプが要らない設計を先に |

## 状態設計(すべてのインタラクティブ要素)

Default / Hover / Focus / Active の4状態を必ず定義する(→ Brand.md UIルール)。
特に Focus:キーボード操作者を見捨てない(エンバーイエローのリング)。

## アクセシビリティの基礎

- コントラスト AA(4.5:1)/ タップ領域 44×44px 以上
- 色だけで情報を伝えない(色+文言・アイコン)
- 全画像に意味のある alt(装飾は alt="")
- prefers-reduced-motion を尊重する
