# UI/UX Checklist

- [ ] 1画面1目的になっているか
- [ ] 主要動線は3タップ以内か
- [ ] 全インタラクティブ要素に4状態(Default/Hover/Focus/Active)があるか
- [ ] フォームの入力項目は最小か・エラー文は「直し方」を示すか
- [ ] 処理中・完了のフィードバックがあるか
- [ ] タップ領域44px・コントラストAAを満たすか
- [ ] 色以外でも情報が伝わるか
- [ ] キーボードだけで操作できるか(Tab移動・フォーカスリング)
- [ ] スマホ実機(または実寸)で一通り操作したか
- [ ] 絵文字をUIアイコン代わりに使っていないか(SVGアイコンで統一)
- [ ] クリック・タップ可能な要素すべてに `cursor: pointer` があるか
- [ ] `prefers-reduced-motion` に対応しているか
