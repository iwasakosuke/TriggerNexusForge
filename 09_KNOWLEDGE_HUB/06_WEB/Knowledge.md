# WEB Knowledge — Web制作全般

## パフォーマンスの基礎

- 体感速度の8割は**画像**で決まる:適切なサイズ(表示幅の2倍まで)・WebP・`loading="lazy"`
- Core Web Vitals の3指標:LCP(2.5秒以内)/ INP(操作の応答)/ CLS(表示のガタつき)
- フォントは表示ブロックしない(`display=swap`)・ウェイトを絞る(TNFは3段)
- 計測は Lighthouse(Chrome DevTools)を標準とする

## 公開・ドメインの基礎

- HTTPS必須(証明書は Let's Encrypt / ホスティング標準機能)
- 静的サイト(LP)はホスティングサービス、CMS案件はWordPress系サーバーが基本線
- DNS変更は伝播に時間がかかる(最大48時間)→ 納期に織り込む
- 公開前にステージング(または限定URL)でクライアント確認を挟む

## セキュリティの基礎(制作会社として最低限)

- フォームは スパム対策(honeypot / reCAPTCHA)+ サーバ側バリデーション
- 認証情報(APIキー・パスワード)をコードにもリポジトリにも書かない
- 依存(ライブラリ・プラグイン)は最小限にし、更新を放置しない

## 運用・保守の基礎

- バックアップは「復元テストをして初めてバックアップ」
- 保守契約に含む範囲を明文化(更新・監視・軽微修正の回数)
- アクセス解析は目的(CV)から逆算して設定する(付けただけの解析は無意味)
