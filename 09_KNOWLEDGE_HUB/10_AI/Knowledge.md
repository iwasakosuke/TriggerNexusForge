# AI Knowledge — AI活用の一般知識

## プロンプト設計の基本構造

良い指示は人間の新人への指示と同じ。次の6要素で組む:

```
1. 役割    : あなたは◯◯です(専門性と立場)
2. 文脈    : 前提・背景・制約(会社・読者・目的)
3. タスク  : 何をするか(1プロンプト1タスク)
4. 素材    : 使ってよい情報(事実・一次体験)
5. 形式    : 出力の型(テンプレート・文字数・表)
6. 基準    : 良し悪しの判定基準・禁止事項
```

TNFのAI社員 Prompt.md はこの構造で書かれている。

## プロンプトの改善技法

- **例を見せる(Few-shot)**: 理想の出力例1〜3個が、説明10行に勝る
- **段階分割**: 構成→本文のように工程を分ける(1発出しより品質が安定)
- **逆質問させる**: 「不足情報があれば書き始める前に質問して」を入れる
- **自己検品させる**: 出力後にチェックリストで自己採点させる

## AIの限界(必ず前提に置く)

| 限界 | 対策 |
|------|------|
| 事実を捏造する(ハルシネーション) | 数字・固有名詞・引用は人間が必ず裏取り |
| 知識に鮮度の限界がある | 最新情報は検索・一次ソースで確認 |
| 「それらしい平均値」に寄る | 一次体験・独自視点は人間が注入する |
| 長い文脈の中間を忘れやすい | 重要な指示は冒頭か末尾に置く |
| 自信満々に間違える | 出力の確信度と正しさは無関係と心得る |

## レビュー原則(AI First, Human Final の実装)

- AI出力は「下書き」。公開・納品・約束に直結するものは人間が全文確認
- 検品は生成した本人(同じセッション)にさせない — 別セッション・別AI・翌日の自分
- 「良さそう」で通さない。チェックリスト(各ドメイン)で機械的に通す
