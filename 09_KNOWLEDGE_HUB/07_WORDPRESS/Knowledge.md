# WORDPRESS Knowledge

## テーマの基礎構造(tnf-starter 準拠)

- テンプレート階層:リクエスト → front-page.php > page.php / single.php > index.php(フォールバック)
- `functions.php` = テーマの機能定義(CSS読込・メニュー・テーマサポート)
- 子テーマ/自作テーマの使い分け:TNFは自作スターター(tnf-starter)をコピーして使う
- スタイルは tokens.css の変数差し替えでブランド対応(PHPは触らない)

## プラグイン方針(最小主義)

| 用途 | 方針 |
|------|------|
| SEO | 1つだけ入れる |
| フォーム | 1つだけ入れる |
| バックアップ | 1つだけ入れる |
| その他 | 原則入れない。コードで済むものはコードで |

- プラグインは「入れた数だけ、更新・脆弱性・競合のリスクが増える」
- 更新が1年止まっているプラグインは採用しない

## セキュリティの要点

- 管理者ユーザー名を `admin` にしない/ログインURLの保護を検討
- WP本体・テーマ・プラグインの自動更新方針を決めて納品時に説明する
- `wp_head` からバージョン情報を出さない(tnf-starter は対応済み)
- DBプレフィックスとファイルパーミッションの初期確認

## 運用の要点

- 更新前バックアップを習慣化(特にメジャーアップデート)
- 納品時:クライアント用に編集者権限ユーザーを発行(管理者を渡すかは契約次第)
- 保守契約なし納品の場合、更新リスクの説明を文書で残す
