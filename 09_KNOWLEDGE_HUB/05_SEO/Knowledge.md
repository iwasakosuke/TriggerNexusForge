# SEO Knowledge(要点版)

## 1枚で思い出す要点

1. **順位テクニックより検索意図への最適解**(E-E-A-Tは「読者に最良か」の代理指標)
2. **1記事1キーワード** — 検索意図は Know / Do / Buy で分類する
3. **TNFの勝ち筋は Experience** — 一次体験(スクショ・数字・失敗談)が最大の差別化
4. **結論ファースト** — リード文で検索意図に答える
5. **内部リンクは双方向** — 新記事公開時に既存記事も更新する
6. **記事は資産** — 3ヶ月時点でリライト判断(11〜30位が最優先)
