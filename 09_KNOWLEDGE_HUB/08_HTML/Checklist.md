# HTML Checklist

- [ ] h1は1つ・見出し階層は飛んでいないか
- [ ] main / nav / header / footer の大構造があるか
- [ ] 全画像に alt と width/height があるか
- [ ] リンクテキストは行き先が分かるか(「こちら」禁止)
- [ ] フォームの label は紐付いているか
- [ ] title / description / OGP / canonical は設定済みか
- [ ] {{ }} プレースホルダの残りがないか
- [ ] W3C validator(またはブラウザ検証)で致命的エラーがないか
