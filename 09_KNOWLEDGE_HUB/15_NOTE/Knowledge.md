# NOTE Knowledge

## noteの構造理解

- 流入:フォロー・おすすめ(編集部/アルゴリズム)・SNS導線・(弱めの)検索
- **SEOより「読み物としての引力」**。タイトルと冒頭3行で読むかが決まる
- スキ率と読了がおすすめ露出に効く。「スキ」は共感+学びのセットで生まれる
- マガジン機能でテーマ別に束ねると回遊が生まれる(資産化)

## 読まれるnoteの型

| 型 | 強み |
|------|------|
| 実践レポート(数字つき) | 信頼を作る。TNFの主力 |
| 失敗談+学び | 共感と保存。人柄が伝わる |
| ノウハウ(再現手順) | 保存・有料化の候補 |
| 決意・節目の表明 | ファン化。多用しない(年数回) |

## 収益化の知識(Roadmap 2027年実験)

- 有料noteの価値=**再現手順の具体性**(気持ちではなく手順に課金される)
- 価格帯の目安:入門 500〜980円 / 本格ノウハウ 1,980〜4,980円
- 無料部分で「買わない理由」を潰す(→ `02_PROMPTS/note.md` Prompt 3)
- 返金・返品性がない分、誇大な販売文句は将来の信頼をすべて焼く
- 売れ行きより先に「無料記事での信頼残高」が必要(信頼が先、販売が後)
