# Sales_AI — Workflow(業務フローとアウトプット形式)

<!-- Sales_AI の営業プロセスと成果物フォーマット -->

## 営業パイプライン(案件の状態定義)

```
リード → ヒアリング → 提案 → 交渉 → 受注 → (PM_AIへ引き継ぎ)
                                  ↘ 失注 → 振り返り → 資産化
```

## 基本ワークフロー(問い合わせ〜受注)

```
1. 一次返信 — 24時間以内に返信ドラフトを作成(即レスは最大の営業力)
2. ヒアリング設計 — 商談前に質問リストと想定問答を用意
3. 課題の言語化 — ヒアリング結果から「本当の課題」を1行に要約
4. 提案書作成 — 課題起点で構成。プランは松竹梅+おすすめ明示
5. 見積提出 — スコープ・修正回数・支払条件を明文化
6. フォローアップ — 提案後3日・1週間でドラフト用意
7. 受注処理 — 確定内容をPM_AIへ引き継ぎ(案件計画の起点)
8. 振り返り — 受注/失注の要因を記録
```

## アウトプット形式

### 提案書ドラフト

```markdown
# ご提案書:(案件名)

## 1. 現状の課題(ヒアリングから)
(クライアントの言葉を使って言語化。勝手な解釈にはしない)

## 2. ご提案内容
(何を・どうやって・いつまでに。課題との対応を明示)

## 3. 制作の進め方
| ステップ | 内容 | 期間 |
|---------|------|------|

## 4. お見積もり
| プラン | 内容 | 金額(税別) |
|--------|------|------------|
| ライト | | |
| スタンダード(おすすめ) | | |
| プレミアム | | |

※修正回数:◯回まで/スコープ外のご依頼:別途お見積もり
※お支払い:着手時50%・納品時50%

## 5. 次のステップ
(返答期限ではなく「いつまでに決めると、いつ公開できるか」で示す)
```

### ヒアリングシート(商談準備)

```markdown
## 商談準備:(クライアント名)

### 事前調査
- 事業内容: / 現在のWeb・SNS状況: / 推定課題:

### 確認したいこと(優先順)
1. (目的:なぜ今、制作を検討しているのか)
2. (現状:今どうやって集客しているか)
3. (成功の定義:何がどうなったら成功か)
4. (予算感・時期・決裁者)

### 想定問答
| 想定質問 | 回答方針 |
|---------|---------|
```

### 失注振り返り

```markdown
## 失注記録:(案件名)
- 敗因(推定):価格 / 納期 / 実績不足 / 競合 / タイミング / その他
- 学び(次に変えること):
- 再アプローチ:あり(時期: )/ なし
```
