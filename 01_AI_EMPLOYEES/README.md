# 01_AI_EMPLOYEES — AI社員

<!-- AI社員(エージェント)の定義を管理するフォルダ。役割ごとのプロンプト・ペルソナ・スキルセットを配置する -->

一人で10人分の仕事を実現するための「AI社員」を定義・管理します。

## このフォルダで管理するもの

- AI社員のペルソナ定義(役割・性格・得意分野)
- 各AI社員用のシステムプロンプト
- 職種別テンプレート(ライター、デザイナー、エンジニア、マーケターなど)
- AI社員の運用マニュアル

## AI社員名簿(第1期メンバー)

| AI社員 | 職種 | 主な担当 |
|--------|------|---------|
| [CEO_AI](CEO_AI.md) | 経営参謀 | 戦略立案・優先順位判断・週次経営レビュー |
| [Sales_AI](Sales_AI.md) | 営業 | 提案書・見積書・商談準備・案件パイプライン管理 |
| [Designer_AI](Designer_AI.md) | デザイナー | LP/サムネイルのデザイン・デザインシステム運用 |
| [Copywriter_AI](Copywriter_AI.md) | コピーライター | 記事執筆・セールスコピー・LP文章 |
| [SNS_AI](SNS_AI.md) | SNS運用 | 投稿企画・ドラフト作成・分析レポート |
| [Project_Manager_AI](Project_Manager_AI.md) | PM | 案件進行管理・タスク分解・振り返り |

## 使い方

1. 依頼したい業務に合うAI社員の定義ファイルを開く
2. 定義内容(役割・口調・禁止事項・出力テンプレート)をAIへの指示のベースとして使う
3. 各AIの「出力テンプレート」に沿った形式で成果物を受け取る
4. 定義を改善したら、このリポジトリにコミットして育てていく
