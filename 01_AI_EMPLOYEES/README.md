# 01_AI_EMPLOYEES — AI社員

<!-- AI社員(エージェント)の定義を管理するフォルダ。1社員=1フォルダ×5ファイルで人格から運用ルールまで定義する -->

一人で10人分の仕事を実現するための「AI社員」を定義・管理します。

## AI社員名簿(第1期メンバー・6名)

| AI社員 | 職種 | 主な担当 |
|--------|------|---------|
| [CEO_AI](CEO_AI/) | 経営参謀 | 戦略立案・優先順位判断・経営レビュー |
| [Sales_AI](Sales_AI/) | 営業 | 提案書・見積書・商談準備・パイプライン管理 |
| [Designer_AI](Designer_AI/) | デザイナー | LP/サムネイルのデザイン・ブランドの番人 |
| [Copywriter_AI](Copywriter_AI/) | コピーライター | 記事執筆・セールスコピー・言葉の品質管理 |
| [SNS_AI](SNS_AI/) | SNS運用 | 投稿企画・ドラフト作成・分析レポート |
| [PM_AI](PM_AI/) | プロジェクトマネージャー | 案件進行・タスク分解・遅延検知・振り返り |

## 各社員のファイル構成(共通)

各AI社員のフォルダには、以下の5ファイルが入っています。

| ファイル | 内容 |
|---------|------|
| `Identity.md` | 人格定義 — 役割・ミッション・話し方・得意分野・苦手分野 |
| `Knowledge.md` | 専門知識 — 判断に使う知識体系と参照ドキュメント |
| `Workflow.md` | 業務フロー — 仕事の進め方とアウトプット形式(テンプレート) |
| `Prompt.md` | 起動プロンプト — AIツールにそのまま貼れるシステムプロンプト+依頼テンプレート |
| `Rules.md` | ルール — 判断基準・禁止事項・エスカレーション基準・チェックリスト |

## 使い方

1. 依頼したい業務に合うAI社員の `Prompt.md` を開く
2. システムプロンプトをAIツール(Claude等)に貼り、依頼テンプレートで仕事を渡す
3. 成果物は各社員の `Workflow.md` のアウトプット形式で受け取る
4. 公開・納品前に、その社員の `Rules.md` のチェックリストを通す

## 運用ルール

- **改善はコミットで**: 使ってみて合わない口調・ルールは、該当ファイルを直接更新して育てる(このリポジトリが常に最新の「社員名簿」)
- **越境させない**: 各AIの苦手分野は `Identity.md` に委譲先を明記済み。餅は餅屋に振り直す
- **新入社員の追加**: `Roadmap.md` の年次採用計画に沿って、同じ5ファイル構成でフォルダを追加する(2027年:Engineer_AI / Marketer_AI / Support_AI 予定)

## AI社員間の連携マップ

```
      ┌─────────────┼─────────────┐
   Sales_AI ─────► PM_AI ◄───── (週次進捗)
  (受注を引き継ぐ)   │ (タスクを発注する)

       Designer_AI Copywriter_AI SNS_AI
        (デザイン)   (言葉)      (発信)
             └── 相互連携 ──┘
   (コピー確定→デザイン/記事→SNS多展開/図解指示→デザイン)
```
