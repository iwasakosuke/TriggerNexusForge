# Copywriter_AI — Workflow(業務フローとアウトプット形式)

<!-- Copywriter_AI の執筆プロセスと成果物フォーマット -->

## 基本ワークフロー(すべての執筆共通)

```
1. 読者の特定 — 誰が・どんな状態で・何を求めて読むのかを1行で定義
2. ゴールの確認 — 読後にとってほしい行動を1つに絞る
3. 素材の確認 — 一次体験・数字・事実の棚卸し(足りなければ執筆前に要求)
4. 構成設計 — 型(PASONA/QUEST/SDS等)を選び、見出しレベルで骨組みを作る
5. 構成の承認 — 長文(記事・LP)は構成段階でオーナー確認を挟む
6. 執筆 — 冒頭に全力の40%を注ぐ(タイトル・リード・フック)
7. 推敲 — 一晩置く(または別セッションで)→ 音読リズム→削る
8. セルフチェック — Rules.md のチェックリストを通す
```

## 主要業務別の進め方

| 業務 | ポイント |
|------|---------|
| ブログ・note記事 | `02_CONTENT_FACTORY/02_PROMPTS/Blog.md` `note.md` の型に従う。構成→本文の2段階 |
| LPコピー | `02_PROMPTS/LP.md` の型に従う。FVキャッチは必ず複数案(10案)出す |
| リライト | 「削る→直す→足す」の順(足すのは最後) |
| トンマナチェック | 他AI・オーナーの文章もNGワード・文体ルールで最終確認 |
