## モデルA:高単価少数案件モデル(単発制作中心)

少数の単発案件を高単価で受ける、最もシンプルなモデル。

| 項目 | 内容 |
|------|------|
| 組み合わせ | LP制作 竹プラン(280,000円)× 1件 + SNS/Banner Creative 梅プラン(30,000円、個別設計)× 1件 |
| 必要案件数 | 2件(LP1件+バナー1件、同一クライアントへのクロスセルでも別クライアントでも可) |
| 平均単価 | 155,000円/件 |
| 月売上 | **310,000円**(この2件が両方獲得できた月のみ。継続要素がないため翌月の保証はない) |
| 想定作業量 | LP竹(ヒアリング1h+生成1h+レビュー2h+実装2h=6h)+バナー梅(個別設計3h+書き出し1h=4h)=**計10h/月** |

**特徴**:件数が少なく作業量も軽いため、他のモデルとの掛け合わせがしやすい。ただし単発中心のため月ごとの売上が不安定になりやすい(次の案件が取れないと0円になるリスク)。

## モデルB:制作+継続契約モデル(単発1件+継続2社)

単発の制作案件で新規顧客を獲得し、継続契約(コンテンツ制作代行)で売上の土台を作るモデル。

| 項目 | 内容 |
|------|------|
| 組み合わせ | LP制作 梅プラン(200,000円)× 1件(単発)+ AI Content/note/SNS運用支援 竹プラン(70,000円/月)× 継続2社(140,000円) |
| 必要案件数 | 単発1件+継続2社 |
| 平均単価 | 単発200,000円 / 継続70,000円(社あたり) |
| **継続的に固い金額** | **140,000円/月**(継続2社分。単発の受注有無に関わらず毎月見込める) |
| **単発が乗った月の金額** | **340,000円**(単発LP1件を獲得できた月のみ。恒常的な数字ではない) |
| 想定作業量 | LP梅(4h)+コンテンツ竹×2社(1社あたり実測58分/テーマ相当×月2〜3テーマ想定で5h、2社で10h)=**計14h/月**(単発獲得月のみ) |

**特徴**:継続契約(140,000円/月)が売上の土台になるため、単発案件が取れなかった月でも売上ゼロにはならない。3モデルの中で最も持続可能性が高い。**ただし「月30万円」を安定して超えるには、継続契約の社数を増やすか、単発案件を毎月コンスタントに獲得する必要がある**(現状の試算は「単発が乗った月」の一時的な数字)。

## モデルC:AI導入支援モデル(コンサル型・単発1件)

新サービス「AI業務自動化・導入支援」1本に絞ったモデル。

| 項目 | 内容 |
|------|------|
| 組み合わせ | AI業務自動化・導入支援 竹プラン(300,000円)× 1件 |
| 必要案件数 | 1件 |
| 平均単価 | 300,000円/件 |
| 月売上 | **300,000円** |
| 想定作業量 | ヒアリング2h+業務フロー設計3h+実装3h+マニュアル作成2h=**計10h/月** |

**特徴**:最も作業量あたりの単価が高い(300,000円÷10h=30,000円/時)が、①新サービスで実績ゼロ、②案件を継続的に取れるかは未検証、という2つのリスクがある。モデルAやBの下地ができてから本腰を入れるのが現実的。

## 3モデルの比較

| モデル | 固い月売上(継続分のみ) | 単発が乗った月の売上 | 必要案件数 | 想定作業量 | 売上の安定性 | リスク |
|--------|-------:|-------:|:---:|:---:|:---:|--------|
| A:高単価少数案件 | 0円 | 310,000円 | 2件 | 10h | 低(単発中心) | 次の案件が取れないと0円 |
| B:制作+継続契約 | **140,000円** | 340,000円 | 単発1+継続2社 | 14h | **高**(継続分が土台) | 継続契約の解約リスク |
| C:AI導入支援 | 0円 | 300,000円 | 1件 | 10h | 低(新サービス・実績ゼロ) | 受注できるか未検証 |

**推奨**:モデルBを軸に据え、余力があればモデルA・Cの案件を追加していく形が現実的。ただし現状の継続2社(140,000円/月)だけでは月30万円に届かないため、**継続契約を3〜4社に増やす(280,000円/月が固い土台になる)ことを当面の目標にする**のが最も現実的な道筋。単発案件はその上乗せとして扱う。
