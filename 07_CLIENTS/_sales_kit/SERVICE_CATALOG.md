## 01. AI Web制作(コーポレートサイト)

| 項目 | 内容 |
|------|------|
| **対象顧客** | 複数ページ構成(会社概要・事業内容・実績・お問い合わせ等)のWebサイトを新規/刷新したい中小企業・士業事務所 |
| **顧客の課題** | 単一ページのLPでは事業の全体像を伝えきれない。既存サイトが古く、更新もされていない。制作会社に頼むと高額・長納期になりがち |
| **提供価値** | 業種別テンプレート(`03_WEB_STUDIO/INDUSTRY_TEMPLATES`)+AI制作フローで、複数ページでも短納期・明朗価格を実現 |
| **具体的な作業内容** | ヒアリング→サイトマップ設計(5〜8ページ)→構成承認→ページごとのコピー・デザイン→実装→検品 |
| **納品物** | HTML/CSS一式(またはWordPress実装)、サイトマップ、公開前チェックリスト |
| **納期目安** | 梅5営業日〜/竹10営業日〜/松15営業日〜 |
| **価格帯** | 梅350,000円 / 竹500,000円 / 松700,000円(下表参照) |
| **オプション** | 追加ページ(1ページ55,000円〜)、多言語対応、独自ドメイン取得代行 |
| **継続契約案** | 保守・更新代行(月額。05_CLIENT_PORTAL製品化ロードマップとも接続) |
| **アップセル** | 松プラン(WordPress実装+SEO設計+アクセス解析) |
| **クロスセル** | 04(バナー制作)、05(継続発信)との同時提案 |
| **使用するTNF資産** | `03_WEB_STUDIO/HTML_TEMPLATE`・`CSS_TEMPLATE`・`WORDPRESS_TEMPLATE`・`INDUSTRY_TEMPLATES`、`04_DESIGN_SYSTEM/DESIGN_ENGINE`(10エンジン)、`06_PRODUCTS/01_LP_BUILDER`のモジュール構造(複数ページに拡張適用) |
| **担当AI社員** | Sales_AI(受注)→PM_AI(進行管理)→Designer_AI(構成・デザイン)+Copywriter_AI(コピー) |

### 3プラン

| | 梅(ライト) | 竹(スタンダード) | 松(プレミアム) |
|---|---|---|---|
| **価格** | 350,000円 | 500,000円 | 700,000円 |
| **内容** | 5ページ構成・テンプレートベース(HTML/CSS納品) | 8ページ構成・ヒアリング1回+構成承認ステップ+実装 | 竹の内容+SEO設計+WordPress実装+アクセス解析セットアップ |
| **修正回数** | 1回 | 2回 | 3回 |
| **納期目安** | 5営業日〜 | 10営業日〜 | 15営業日〜 |

**時給換算セルフテスト(竹プラン)**:ヒアリング2h+AI生成2h+レビュー4h+実装調整4h=計12h。500,000円÷12h≒**時給41,700円**(LP制作竹プランの46,700円/時と近い水準で健全)。

## 03. AI業務自動化・導入支援

| 項目 | 内容 |
|------|------|
| **対象顧客** | 案件管理・問い合わせ対応・請求書作成などの定型業務を、AI・スクリプトで効率化したい一人〜数名規模の事業者 |
| **顧客の課題** | 繰り返し作業に時間を取られ、本業(接客・制作・営業)に集中できない。何を自動化すればいいか自分では分からない |
| **提供価値** | TNF自身が実践している「案件の状態管理(`master_flow.md`)→テンプレート化→スクリプト化」の型を、顧客の業務に応用する |
| **具体的な作業内容** | ヒアリングで繰り返し業務を特定→業務フローの可視化→テンプレート/スクリプト化→導入サポート |
| **納品物** | 業務フロー図、自動化スクリプトまたはテンプレート一式、運用マニュアル |
| **納期目安** | 梅3営業日〜(診断のみ)/竹10営業日〜/松は竹+1ヶ月伴走 |
| **価格帯** | 梅100,000円 / 竹300,000円 / 松450,000円(下表参照) |
| **オプション** | 追加業務の自動化(1件80,000円〜)、月次メンテナンス契約 |
| **継続契約案** | 月次保守(スクリプトの調整・追加自動化の相談窓口) |
| **アップセル** | 松プラン(1ヶ月の伴走サポート) |
| **クロスセル** | 01(Web制作)・02(LP制作)の問い合わせ導線と組み合わせた「集客〜業務効率化」一括提案 |
| **使用するTNF資産** | `05_AUTOMATION/00_WORKFLOWS/master_flow.md`(状態設計の型)、`05_AUTOMATION/scripts/init_project.sh`(スクリプト化の実例)、`05_AUTOMATION/01_CLIENT_INTAKE`・`02_PROJECT_MANAGEMENT`(テンプレート化の型) |
| **担当AI社員** | Sales_AI(受注)→PM_AI(業務フロー設計・主担当) |

### 3プラン

| | 梅(診断) | 竹(実装込み) | 松(伴走) |
|---|---|---|---|
| **価格** | 100,000円 | 300,000円 | 450,000円 |
| **内容** | 業務ヒアリング+改善提案書(実装なし) | 診断+スクリプト/テンプレート1〜2件実装+運用マニュアル | 竹の内容+導入後1ヶ月の週次確認・微調整 |
| **納期目安** | 3営業日〜 | 10営業日〜 | 竹+1ヶ月 |

**時給換算セルフテスト(竹プラン)**:ヒアリング2h+業務フロー設計3h+実装3h+マニュアル作成2h=計10h。300,000円÷10h≒**時給30,000円**(制作系サービスよりコンサル要素が強いため単価はやや低いが健全な水準)。

**注記**:このサービスはまだ実績ゼロの新規メニュー。`portfolio.md`の「実績、募集中です」の考え方を適用し、初回提案時は正直にその旨を伝える。

## 04. SNS / Banner Creative

| 項目 | 内容 |
|------|------|
| **対象顧客** | SNS広告・投稿用のバナー画像・クリエイティブがまとまって欲しい店舗・EC事業者 |
| **顧客の課題** | 毎回ゼロからデザインを発注すると時間もコストもかかる。文章(投稿文)はあっても画像がない |
| **提供価値** | `04_DESIGN_SYSTEM/DESIGN_ENGINE`のトークン(色・タイポグラフィ・レイアウト)を使い、テンプレート化された複数サイズのバナーをまとめて短納期で制作 |
| **具体的な作業内容** | ヒアリング(訴求・ブランドカラー確認)→デザイン設計→複数サイズ展開(SNS各媒体の規定サイズ) |
| **納品物** | バナー画像一式(指定サイズ×点数)、デザイン設計メモ |
| **納期目安** | 3営業日〜 |
| **価格帯** | 梅30,000円 / 竹60,000円 / 松80,000円/月(下表参照) |
| **オプション** | 追加サイズ展開、動画バナー(将来対応・現状スコープ外) |
| **継続契約案** | 月額(松プラン)での継続制作 |
| **アップセル** | 松(月額の継続提案) |
| **クロスセル** | 05(SNS運用支援)とセット提案(文章+画像のフルセット) |
| **使用するTNF資産** | `04_DESIGN_SYSTEM/DESIGN_ENGINE`(01_color/02_typography/03_layout/06_icon/10_export_rules)、`02_CONTENT_FACTORY/02_PROMPTS/ImagePrompt.md` |
| **担当AI社員** | Sales_AI(受注)→Designer_AI(主担当)+SNS_AI(展開先の確認) |

### 3プラン

| | 梅(単発5点) | 竹(単発10点) | 松(月額継続) |
|---|---|---|---|
| **価格** | 30,000円 | 60,000円 | 80,000円/月 |
| **内容** | 1テーマのバナー5点(1サイズ展開) | 2テーマ×5点、3サイズ展開込み | 月10点継続制作+新デザイン提案 |
| **納期目安** | 3営業日〜 | 5営業日〜 | 月次 |

**時給換算セルフテスト(竹プラン)**:デザイン設計1h+サイズ展開2h=計3h。60,000円÷3h≒**時給20,000円**(テンプレート化前提のバッチ制作のため妥当な水準)。

**注記**:このサービスも新規メニュー。`04_DESIGN_SYSTEM/DESIGN_ENGINE`は制作物の設計ロジックとしては存在するが、「バナーテンプレート」として具体的にプロンプト化・手順化されたものはまだない(→ Day27レポートの「未完成部分」参照)。

## Sales_AI連携ルール(問い合わせ→サービス推奨)

問い合わせ内容のキーワードから、一次返信時点でSales_AIが仮の推奨を出すためのルール。**あくまで初期仮説であり、ヒアリングで確定するまでは「概算」であることを必ず伝える**(Sales_AI Rules.mdの「根拠のない楽観スケジュール禁止」「価格の正当化は価値の言語化」に準拠)。

| 問い合わせの手がかり(キーワード) | おすすめサービス | おすすめプラン(初期仮説) | 追加オプション候補 | 概算価格帯 | 次のヒアリング項目 |
|---|---|---|---|---|---|
| 「ホームページ」「HP」「サイト」(複数ページ想定) | 01 AI Web制作 | 竹(スタンダード) | WordPress実装(松) | 35〜70万円 | 希望ページ数/現在のサイトの有無/更新頻度/決裁者 |
| 「LP」「集客ページ」「1枚のページ」 | 02 LP制作 | 竹(スタンダード) | WordPress実装(松) | 20〜40万円(初回150,000円あり) | 現在の集客経路/強み・実績の裏付け/ITリテラシー |
| 「事務作業」「業務効率化」「AI導入」「自動化」 | 03 AI業務自動化・導入支援 | 竹(実装込み) | 松(伴走サポート) | 10〜45万円 | 現在の作業フロー/繰り返し作業の頻度・時間/使用中のツール |
| 「バナー」「広告画像」「SNS用の画像」 | 04 SNS/Banner Creative | 竹(単発10点) | 松(月額継続) | 3〜8万円 | 使用媒体・サイズ/既存ブランドカラーの有無/更新頻度 |
| 「SNS」「note」「発信」「継続的に」 | 05 AI Content/note/SNS運用支援 | 竹(月額) | 04とのセット提案 | 月5〜10万円 | 発信媒体の優先順位/更新頻度/既存ブランドガイドの有無 |

**判断に迷う場合(複数キーワードが混在する等)**:CEO_AIまたはオーナーへエスカレーション(Sales_AI Rules.md「迷う案件はCEO_AIへ」準拠)。
