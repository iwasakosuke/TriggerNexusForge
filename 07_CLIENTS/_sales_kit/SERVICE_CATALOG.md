## 01. AI Web制作(コーポレートサイト)

| 項目 | 内容 |
|------|------|
| **対象顧客** | 複数ページ構成(会社概要・事業内容・実績・お問い合わせ等)のWebサイトを新規/刷新したい中小企業・士業事務所 |
| **顧客の課題** | 単一ページのLPでは事業の全体像を伝えきれない。既存サイトが古く、更新もされていない。制作会社に頼むと高額・長納期になりがち |
| **提供価値** | LP制作で培った業種別テンプレートの考え方を複数ページ構成に応用し、ページ数に応じた明朗な価格・納期を事前に提示する。実績はまだないため、初回受注時は実測時間を計測し価格・納期の妥当性を検証する |
| **具体的な作業内容** | ヒアリング→サイトマップ設計(5〜8ページ)→構成承認→ページごとのコピー・デザイン→実装→検品 |
| **納品物** | HTML/CSS一式(またはWordPress実装)、サイトマップ、公開前チェックリスト |
| **納期目安** | 梅5営業日〜/竹10営業日〜/松15営業日〜 |
| **価格帯** | 梅350,000円 / 竹500,000円 / 松700,000円(下表参照) |
| **オプション** | 追加ページ(1ページ55,000円〜)、多言語対応、独自ドメイン取得代行 |
| **継続契約案** | 保守・更新代行(月額。05_CLIENT_PORTAL製品化ロードマップとも接続) |
| **アップセル** | 松プラン(WordPress実装+SEO設計+アクセス解析) |
| **クロスセル** | 04(バナー制作)、05(継続発信)との同時提案 |
| **使用するTNF資産** | `03_WEB_STUDIO/HTML_TEMPLATE`・`CSS_TEMPLATE`・`WORDPRESS_TEMPLATE`、`04_DESIGN_SYSTEM/DESIGN_ENGINE`(10エンジン)、`06_PRODUCTS/01_LP_BUILDER`のモジュール構造(複数ページに拡張適用)。**注**:`INDUSTRY_TEMPLATES`は単一ページLP向け(FV→CTA構成)の型であり、複数ページ構成にはそのまま使えない。訴求軸・ターゲット心理の部分だけを参考にし、ページ構成は別途設計する |
| **担当AI社員** | Sales_AI(受注)→PM_AI(進行管理)→Designer_AI(構成・デザイン)+Copywriter_AI(コピー) |

| | 梅(ライト) | 竹(スタンダード) | 松(プレミアム) |

### プラン(現状は梅のみ販売可)

| | 梅(単発5点・個別設計) | 竹(単発10点) | 松(月額継続) |
|---|---|---|---|
| **価格** | 30,000円 | ~~60,000円~~ 未提供 | ~~80,000円/月~~ 未提供 |
| **内容** | 1テーマのバナー5点(1サイズ、個別設計) | テンプレート整備後に提供 | テンプレート整備後に提供 |
| **納期目安** | 5営業日〜 | — | — |

**時給換算セルフテスト(梅プラン)**:デザイン設計3h(個別設計のため竹の当初想定より重い)+書き出し1h=計4h。30,000円÷4h≒**時給7,500円**。この水準では「安売りしない」原則に反するため、**テンプレート化が完了するまで梅プランを積極営業しない**(問い合わせがあれば個別見積で対応)。

**独立レビューでの指摘と対応**:当初案は「テンプレート化された複数サイズのバナーを短納期で制作」と謳いながら、同時に「テンプレートは未整備」と書く自己矛盾があった。この状態で竹・松を受注すると実質は個別設計になり時給が崩壊するため、**竹・松の販売を停止し、梅のみ(それも消極的に)提供する形に修正した**。テンプレート化(`04_DESIGN_SYSTEM`のバナー用プロンプト整備)が完了してから、当初想定の価格・工数で再展開する。
