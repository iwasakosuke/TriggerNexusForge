## よくあるトラブル → 防ぐ文言

受注後のトラブルは、事前に文書で期待値を揃えておけば多くが防げる。よくあるパターンと、それを防ぐための標準文言を対応表にした。

| よくあるトラブル | 防ぐ文言(標準条件) |
|---|---|
| ついで修正の増殖(スコープクリープ) | 修正は本見積の範囲内で2回までとします。修正の対象は「初回納品時にご確認いただいた構成・文言の調整」に限り、新規ページの追加や構成の作り直しは別途お見積りとします |
| 「これも直して」で範囲外の依頼が次々来る | ご契約時に「含むもの/含まないもの」を明文化し、双方で確認します。含まれない項目のご依頼は、着手前に金額と納期への影響をご提示し、ご了承いただいてから対応します |
| 検収の返事がない(確認待ちが長期化) | 納品後7営業日以内にご確認・ご返信がない場合、検収完了とみなします(みなし検収)。ご多忙の場合は事前にご一報ください |
| 支払いの遅延 | 着手金は契約後7日以内、残金は納品後14日以内のお支払いをお願いします。期日を過ぎた場合、以降の作業を一時停止させていただくことがあります |
| 追加費用が発生する条件があいまい | スコープ外の対応・追加ページ・大幅な方向転換は、着手前に必ず金額と納期への影響をご提示し、書面(メール等)でご了承をいただいてから着手します |
| 着手後のキャンセル・中断 | 着手後のキャンセルは、それまでの制作工数分をご請求します(着手金は返金対象外)。契約後・作業着手前のキャンセルは、着手金の扱いについて個別にご相談に応じます |
| 制作物の権利・実績公開でのトラブル | 納品物の著作権は、残金完済時点でクライアントに譲渡します。TNF側の実績・ポートフォリオとしての掲載可否は、契約時に確認します(掲載NGの場合は非公開扱いとします) |
| 値引き要求への対応があいまいで安売りになる | 価格は据え置き、提供範囲(ページ数・修正回数など)を調整してご予算に合わせます。価格だけを下げることはいたしません |
| 「もっと早くできないか」という納期短縮要求 | 標準納期より早めるご希望には、対応可否と追加費用の有無を個別にご案内します。無条件でのお約束はいたしません |

## 標準条件(まとめ)

### スコープの書き方
- 「含むもの」「含まないもの」を必ず両方明文化する(project_sheet.mdの「スコープ」欄に準拠)
- 含まないものの例:独自ドメイン取得代行、撮影・素材制作、公開後の運用・更新代行、既存システムとの連携

### 修正回数
- 標準2回まで(プランにより1〜3回、`service_menu.md`のプラン差を参照)
- 超過分は都度お見積り。修正対象は「初回納品時に確認いただいた範囲の調整」に限る

### 支払条件
- 着手時50%・納品時50%が基本
- 着手金:契約後7日以内 / 残金:納品後14日以内
- 継続契約(コンテンツ制作代行など)は月初請求

### 検収期限
- 納品後7営業日以内にご確認・ご返信がない場合、検収完了とみなす(みなし検収)

### 追加費用の条件
- スコープ外の依頼は、着手前に金額・納期影響を提示し、書面での了承後に着手する
- 事後承諾・口頭のみでの追加対応はしない

### キャンセル規定
- 着手後:それまでの制作工数分を請求(着手金は返金対象外)
- 契約後・未着手:着手金の扱いは個別相談

### 実績公開の許可確認
- 契約時に「実績・ポートフォリオとして掲載してよいか」を必ず確認する
- 掲載NGの場合は、社名・ロゴを伏せた形での掲載可否も別途確認する

## 3問テスト(送信前チェック)

DAY17のテスト方法「もし◯◯と言われたら」に、上記の文言で答えられるかを確認した。

| 想定される発言 | 対応する標準条件の文言 | 回答可否 |
|---|---|---|
| 「値引きしてもらえますか?」 | 「価格は据え置き、提供範囲を調整してご予算に合わせます」 | ✓ 回答可能 |
| 「ついでにバナーも作ってもらえますか?」 | 「含まないものの明文化」+「追加費用の条件」の文言で、範囲外である旨と見積り提示の流れを説明できる | ✓ 回答可能 |
| 「検収の返事がまだできていません(確認が進まない)」 | 「みなし検収(納品後7営業日)」の文言で、期限と扱いを事前に説明できていれば対応できる | ✓ 回答可能 |

## レビュー(DAY17レビュー方法:クライアント視点での読み直し)

「自分がクライアントだったら不快でないか」の視点で全文を読み直した。

- みなし検収・着手後キャンセルの条項は、理由を添えて説明する文体にし、一方的な通告に見えないようにした
- 値引き拒否は「価格は下げないが、予算に合わせる方法(スコープ調整)は用意している」という代案とセットで書いており、単なる拒絶にはなっていない
- 追加費用の条件は「事前に金額を提示してから着手する」という順序を明記し、後から一方的に請求される印象を避けた

守りの条件が攻撃的にならないよう、事実の説明+代案の提示、という構成に統一している。
