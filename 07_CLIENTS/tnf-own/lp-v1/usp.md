# Module 03 出力 — USP(project.usp)

## 1. 競合(Web制作会社)が共通して言っていること(=差別化にならない要素)

- 「丁寧なヒアリングで対応します」
- 「デザイン性の高いLPを制作します」
- 「SEOにも配慮した制作を行います」

## 2. 強み × 悩み・ブレーキの対応表

| 強み(事実) | 解消する悩み/ブレーキ |
|------------|----------------------|
| 業種別の勝ちパターン | 「美容室のこと全然分かってなくて、結局使えないLPが来た」(pain1)/「また同じ失敗をするのでは」(brake) |
| 誠実な価格 | 「あとから『これは追加です』が何個も出てきて結局高くついた」(pain2)/「追加費用への警戒」(brake) |
| AI活用による短納期 | 「自分で作る時間なんてない」(pain3) |

## 3. USP候補3案

1. **業種別の勝ちパターンをもとに設計する、テンプレ感のないLP。価格は着手前に確定、追加費用なし。**(業種理解+価格の2軸)
2. AIで短納期、業種の勝ちパターンで作るLP制作(短納期+業種理解の2軸)
3. 丁寧なヒアリングから始める、あなたの店舗に合わせたLP制作(ヒアリング訴求)

## 4. 推奨と理由

**候補1を採用。**

- persona.brake(最大の不安=「また同じ失敗をするのでは」「追加費用への警戒」)を最も強く外す
- 競合の共通項(丁寧なヒアリング/デザイン性/SEO)と被らない。候補3はまさにその共通項そのもの
- 候補2(短納期押し)は、外注失敗経験者にとって「早い=雑」という新たな不安を招くリスクがあるため、短納期はサポートポイントに格下げし、主軸には据えない

## 5. サポートポイント(3つ・FVの安心要素/ベネフィットの種)

1. 整体・美容・ジムなど複数業種で使ってきた「勝ちパターン」を土台に、店舗ごとの強み・実績を反映してカスタマイズ(プリセット=そのまま流用ではなく出発点) — 業種を知らない制作会社にありがちな的外れなLPを避ける
2. 見積もりは着手前に確定。あとから「これは追加です」が出ない明朗価格
3. AI活用による制作フローで、通常より短い納期で形にする(具体的な納期日数は【要記入】— 案件ごとに提示)

**根拠メモ**:「業種別の勝ちパターン」は、TNF Core Engine / LP Builderが実装済みの業種プリセット(整体・美容・ジム・士業・講座・飲食)という製品事実に基づく。
クライアント実績・お客様の声は現時点で存在しないため、【要記入】枠で保留するのではなく「実績、募集中です」と正直に
開示する方針に変更した(オーナー決定・2026-07-10。詳細は`copy.md`参照)。

**別セッション検品での指摘と対応(2026-07-09)**:「テンプレ感のないLP」という主張と「業種別プリセット」という裏付けが、
読み手にとって矛盾して見えるリスクを指摘された(プリセット=結局テンプレでは?という新たな不信を招きかねない)。
→ サポートポイント1に「プリセットは出発点であり、店舗ごとにカスタマイズする」旨を明記して解消(上記反映済み)。
LP本文(`section_copy.md`/`index.html`「対応業種と勝ちパターン」セクション)にも同旨の一文を追加する。
なお「競合が共通して言っていること」(セクション1)は正式な競合調査ではなくTNFの一般的業界知識に基づく判断であり、
厳密な調査根拠は無い(指摘✗-2。今回は致命的ではないため許容し、クライアント案件では調査プロセスの明文化を検討する)。

## 6. 不採用案

- 候補2「AIで短納期、業種の勝ちパターンで作るLP制作」— 短納期を主軸にすると「早い=雑」という新たな不安を招くリスク。サポートポイント3に格下げして採用
- 候補3「丁寧なヒアリングから始める〜」— 競合の共通項と完全に被り、差別化にならないため不採用
