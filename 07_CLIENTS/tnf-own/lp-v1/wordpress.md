## ページ設定

| 項目 | 値 |
|------|-----|
| ページタイトル | 一度、外注で失敗した経営者の方へ。\|Trigger Nexus Forge |
| パーマリンク | lp-production-service |
| メタディスクリプション | 業種別の実績パターンをもとに設計するLP制作。価格は着手前に確定、追加費用なし。AI活用で短納期。小規模事業者のオーナー様へ。 |
| ページテンプレート | 固定ページ(フルワイドがあれば推奨) |

## 貼り付け手順(3行)

1. 固定ページを新規作成し、下のセクションを上から順にブロックとして貼る
2. 「H2」は見出しブロック、本文は段落ブロック、CTAはボタンブロックを使う
3. 【画像】の位置に画像ブロックを挿入し、代替テキストをコピーする

---

### セクション1:FV

- 見出し(H1=ページタイトルで代用):一度、外注で失敗した経営者の方へ。
- 段落(小・バッジ代わり):小規模事業者のオーナー様へ
- 段落:業種別の実績パターンと、着手前に確定する価格で、今度こそ届く1本を。
- リスト:整体・美容・ジムなど複数業種の勝ちパターンをベースに設計 / 見積もりは着手前に確定。追加費用なし / AI活用の制作フローで、最短3日から
- ボタン:まずは相談してみる → リンク先:【要記入:問い合わせフォームURL】
- 段落(小):しつこい営業は行いません。まずは現状とご要望をお伺いするだけです。

### セクション2:他の制作会社との違い

- 見出し(H2):他の制作会社との違い
- 段落:多くの制作会社は業種を問わず同じ型でLPを作ります。TNFは業種別の実績パターンをベースに設計するため、テンプレ感のあるLPになりません。価格は着手前に確定し、追加費用は発生しません。AIを活用した制作フローで、最短3日からお届けします。

### セクション3:課題共感

- 見出し(H2):こんな心当たり、ありませんか?
- リスト:前に頼んだ制作会社が業種を分かっておらず、結局使えないLPになった / 見積もりは安かったのに、後から追加費用が何度も発生した / 自分で作る時間はない。日々の業務だけで一日が終わってしまう
- 段落:その全部、業種特化の型と確定価格で解決できます。

### セクション4:解決策

- 見出し(H2):業種別パターンで作る、明朗価格のLP制作
- 段落:業種別の実績パターンをもとに設計するから、テンプレ感のあるLPになりません。価格は着手前に確定し、追加費用は発生しません。

### セクション5:対応業種と実績パターン

- 見出し(H2):対応業種と実績パターン
- 段落:これらの型はそのまま流用するテンプレートではなく、店舗ごとの強み・実績を反映してカスタマイズする出発点です。
- リスト(6項目):整体・治療院=信頼と回復を伝える型 / 美容・サロン=柔らかさと清潔感を伝える型 / フィットネス・ジム=活力を伝えつつ圧の強さを避ける型 / 士業・専門職=信頼と堅実さを伝える型 / 教育・講座=知性と前進を伝える型 / 飲食=食欲・温度感を写真中心で伝える型
- 段落(小):上記以外の業種も、ヒアリングをもとに個別に設計します
- ボタン:まずは相談してみる → リンク先:【要記入:問い合わせフォームURL】

### セクション6:実績・お客様の声

- 見出し(H2):実績・お客様の声
- 段落×2(引用形式):【要記入:お客様の声1(掲載許可を得た実際の声)】/属性【要記入】/ 【要記入:お客様の声2】/属性【要記入】

### セクション7:価格と制作期間

- 見出し(H2):価格と制作期間
- 段落(プラン):実績作り特別価格プラン/5,000円(税込)/LP制作一式(構成〜HTML/CSS納品)。実績作りのための特別価格につき、通常価格とは異なります
- 段落(小):料金は着手前のヒアリングで確定し、その後の追加費用は発生しません。
- 見出し(H3):制作の流れ
- リスト:ヒアリング(業種・強み・目的の確認)/ 構成設計(ペルソナ・USP・LP構成をご確認いただき、承認後に執筆)/ コピー・デザイン制作(AI活用により短期間で初期案を作成)/ 検品・納品(公開前チェックリストを通した最終確認)
- 段落(小):最短3日から納品します(案件内容により変動する場合があります)

### セクション8:よくあるご質問

WordPress標準の「よくある質問」ブロックが無いテーマの場合は、見出し(H3)+段落の繰り返しで代用する。

1. Q. 以前も外注でLPを作って失敗しました。今回は大丈夫でしょうか? / A. 業種別の実績パターンをもとに設計するため、業種を理解しないまま作られるテンプレLPにはなりません。構成案は着手前にご確認いただけます。
2. Q. 見積もり以外に追加費用が発生することはありますか? / A. 着手前のヒアリングで料金を確定してご提示します。ご依頼いただいた範囲内での追加費用は発生しません。範囲を超えるご依頼は事前にご相談します。
3. Q. 料金はいくらくらいですか? / A. 現在は実績作りのための特別価格として、LP制作一式5,000円でご案内しています。
4. Q. どのくらいの期間で完成しますか? / A. AIを活用した制作フローにより、最短3日から納品可能です。案件内容により変動する場合があります。
5. Q. 自分の業種(美容室・整体・士業など以外)でも対応してもらえますか? / A. 整体・美容・ジム・士業・講座・飲食以外の業種も、ヒアリングをもとに個別に設計しますので、まずはご相談ください。
6. Q. 問い合わせたら、その場で契約を迫られませんか? / A. しつこい営業や即決を求めることはありません。まずは現状とご要望をお伺いし、ご検討いただいてからのご判断で構いません。

### セクション9:最終CTA

- 見出し(H2):まずは、話を聞いてみませんか
- 段落:業種に合わせたLP制作について、まずはお気軽にお問い合わせください。
- ボタン:まずは相談してみる → リンク先:【要記入:問い合わせフォームURL】
- 段落(小):無理な営業や即決を迫ることはありません。まずは現状とご要望をお伺いします。
- 段落(小・任意):電話でのお問い合わせ:【要記入:電話番号】(スマホ発信用に `tel:0000000000` 形式のリンクを設定する)
