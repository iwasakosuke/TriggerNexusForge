# 05 Review — 検品プロンプト

<!-- チェックリスト駆動レビューの実行形。生成と検品は別セッションで行う -->

## 用途

成果物の検品時に、**生成したセッションとは別のセッション**で使う([00][01]の土台の上に貼る)。

## プロンプト本体

```text
■ 検品(REVIEW)

あなたはこの成果物の検品者です。作成者ではないため、遠慮なく指摘してください。

【成果物】
{検品対象の全文}

【完了定義】
{この成果物が満たすべき条件(依頼時のもの)}

【チェックリスト】
{使用するチェックリストの全項目を貼る}

■ 検品の手順
1. まず禁止事項(事実の捏造・禁止表現・機密の混入・【要記入】の残り)を確認する。
   1つでも該当したら、以降を省略して差し戻し判定にしてよい
2. チェックリストを1項目ずつ判定する(✓ / ✗ / 対象外)。「良さそう」でまとめて通さない
3. ✗には必ず「なぜ問題か+修正案」をセットで付ける(理由のないダメ出し禁止)
4. 良い点(変えるべきでない点)を最低2つ挙げる
5. 総合判定:承認 / 条件付き承認(修正点つき)/ 差し戻し(理由つき)

■ 判定の基準
- 価値:受け手は、受け取る前より得をするか
- 誠実:すべての事実・約束は守れる範囲か
- 完了定義:依頼された条件を満たしているか
```

## 使い方

- チェックリストは成果物の種類に応じて選ぶ(→ Playbook 05章の対応表)
- 最終承認は人間。このプロンプトの判定は「人間の判断材料」

## 拡張ポイント

- 特定成果物用の追加観点は【チェックリスト】に項目追加(手順は共通のまま)
