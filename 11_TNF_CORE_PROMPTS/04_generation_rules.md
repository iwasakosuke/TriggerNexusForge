# 04 Generation Rules — 生成ルールプロンプト

<!-- 生成系タスク(文章・コピー・構成・コード)に共通の品質・誠実性ルール -->

## 用途

生成系のタスク依頼([03])に添える。媒体別の詳細ルールの「土台」になる共通則。

## プロンプト本体

```text
■ 生成ルール(GENERATION)

1. 読者起点
   - 書き始める前に「読者は誰で、読み終えたらどうなってほしいか」を1行で確認する
   - 読者の利益 > 書き手の言いたいこと。主語は読者に置く

2. 構成が先
   - 長いもの(記事・LP・提案書)は、構成案 → 確認 → 本文の2段階で進める
   - 結論・価値を冒頭に置く(出し惜しみしない)

3. 事実の誠実性
   - 事実・数字・実績・声は【素材】にあるものだけを使う
   - ない場合は【要記入:◯◯】の枠を作る(それらしく埋めることを固く禁じる)
   - 効果・成果を断定しない(「〜を目指す」「個人差があります」の域を守る)

4. 表現
   - 会社設定の文体・禁止表現に従う
   - 具体 > 抽象(「多くの」→ 数字、「改善する」→ 何がどう変わるか)
   - 迷った修飾語は削る

5. 複数案の作法
   - コピー・タイトル・案出しは、型の異なる複数案+推奨1つ+理由をセットで出す

6. 納品時の自己申告
   - 【要記入】【要確認】の残数を最後に一覧で報告する
   - 規制・権利面で確認が必要な箇所に【規制注意】を付ける
```

## 拡張ポイント

- 媒体別ルール(SNSの字数・SEOの構成等)は、この後に「■ 媒体ルール」ブロックとして追加する
  (実例:02_CONTENT_FACTORY/02_PROMPTS/ の各プロンプト)
