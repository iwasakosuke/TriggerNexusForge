# Trigger Nexus Forge

一人で10人分の仕事ができるAI制作会社OS

このリポジトリは、AI制作会社「Trigger Nexus Forge」の会社全体を管理するためのプロジェクトです。
AI社員・コンテンツ制作・Web制作・自動化などのすべての業務をここで一元管理します。

## フォルダ構成

```
TriggerNexusForge/
├── 00_COMPANY/          # 会社運営 — 経営理念・事業計画・社内ルール
├── 01_AI_EMPLOYEES/     # AI社員 — エージェント定義・プロンプト・職種テンプレート
├── 02_CONTENT_FACTORY/  # コンテンツ制作 — 記事・SNS・動画台本の量産拠点
├── 03_WEB_STUDIO/       # Web制作 — LP・Webサイト・Webアプリの開発
├── 04_DESIGN_SYSTEM/    # デザインシステム — カラー・フォント・素材・テンプレート
├── 05_AUTOMATION/       # 自動化 — スクリプト・ワークフロー・定期実行タスク
├── 06_PRODUCTS/         # 自社プロダクト — 販売する商品・サービス・教材
├── 07_CLIENTS/          # クライアントワーク — 受注案件・提案書・納品物
└── 08_DOCUMENTS/        # ドキュメント — マニュアル・ナレッジ・議事録
```

各フォルダの詳細は、それぞれのフォルダ内の `README.md` を参照してください。

## 各部門の概要

| フォルダ | 部門 | 役割 |
|---------|------|------|
| `00_COMPANY` | 会社運営 | 経営方針・ブランド・ルールなど会社の中枢情報を管理 |
| `01_AI_EMPLOYEES` | AI社員 | 役割ごとのAIエージェント(ペルソナ・プロンプト)を定義 |
| `02_CONTENT_FACTORY` | コンテンツ制作 | ブログ・SNS・動画などのコンテンツを効率的に量産 |
| `03_WEB_STUDIO` | Web制作 | LP・Webサイト・Webアプリの企画から開発まで |
| `04_DESIGN_SYSTEM` | デザイン | 制作物のデザインを統一する資産・基準を管理 |
| `05_AUTOMATION` | 自動化 | 繰り返し作業を自動化する仕組みを構築・運用 |
| `06_PRODUCTS` | プロダクト | 自社で開発・販売するプロダクトを管理 |
| `07_CLIENTS` | 営業・受託 | クライアント案件と納品物を管理 |
| `08_DOCUMENTS` | 総務・ナレッジ | 全社共通のドキュメント・ノウハウを蓄積 |

## コンセプト

- **AI社員による分業**: 職種ごとに定義したAIエージェントが、それぞれの専門業務を担当
- **テンプレート化**: 一度作った制作物の型を資産化し、次の案件で再利用
- **自動化ファースト**: 2回以上繰り返す作業は `05_AUTOMATION` で自動化を検討
